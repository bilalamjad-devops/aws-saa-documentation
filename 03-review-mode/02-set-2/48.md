48. Question

Category: CSAA – Design High-Performing Architectures

A company has developed public APIs hosted in Amazon EC2 instances behind an Elastic Load Balancer. The APIs will be used by various clients from respective on-premises data centers. A Solutions Architect received a report that the web service clients can only access trusted IP addresses whitelisted on the web service’s firewalls.

What should be done to accomplish the above requirement?

- `Associate an Elastic IP address to a Network Load Balancer.`
- Create an Amazon CloudFront distribution whose origin points to the private IP addresses of your web servers.
- Associate an Elastic IP address to an Application Load Balancer.
- Configure General Purpose SSD volumes on the load balancer nodes to provide static IP addresses.

## 🎯 What is the question asking?

The clients have **firewalls that whitelist specific IP addresses**.

So the API needs a **static IP address** that clients can whitelist.

👉 **Network Load Balancer (NLB) supports Elastic IP addresses.**

### ✅ Correct: Associate an Elastic IP address to an NLB

```text
On-prem clients
      ↓
Trusted Static IP
      ↓
     NLB
      ↓
     EC2
```

With **BYOIP**, the company can even use its existing trusted IP addresses, avoiding changes to client firewall whitelists.

### 🔍 Options

| Option                       | Why?                                                                           | Result |
| ---------------------------- | ------------------------------------------------------------------------------ | ------ |
| **Elastic IP → NLB**         | NLB supports static EIPs                                                       | ✅      |
| CloudFront → private EC2 IPs | CloudFront isn't the solution for providing the required whitelisted client IP | ❌      |
| Elastic IP → ALB             | ALB doesn't support assigning EIPs directly                                    | ❌      |
| gp3 EBS volumes              | Storage has nothing to do with IP addresses                                    | ❌      |

### 🔥 SAA shortcut

> **Need static IP on a Load Balancer → NLB**

> **ALB = Layer 7 / HTTP routing**

> **NLB = Layer 4 / TCP + static IP support**
