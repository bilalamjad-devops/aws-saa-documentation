11. Question

Category: CSAA – Design Cost-Optimized Architectures

A start-up company that offers an intuitive financial data analytics service has consulted about its AWS architecture. The company has a fleet of Amazon EC2 worker instances that process financial data and then output reports used by its clients. The reports must be stored in a durable storage. The number of files to be stored can grow over time as the start-up company is expanding rapidly overseas, and thus, it also needs a way to distribute the reports faster to clients located across the globe. Although Amazon S3 One Zone-IA saves storage cost, it does not support global distribution.

Which of the following is a cost-efficient and scalable storage option for this scenario?

- Use multiple EC2 instance stores for data storage and Amazon ElastiCache as the CDN.
- Use Amazon Redshift as the data storage and Amazon CloudFront as the CDN.
- Use S3 Glacier as the data storage and Amazon ElastiCache as the CDN.
- `Use S3 as the data storage and Amazon CloudFront as the CDN.`

Yes. This question is basically testing **“Where should I store files, and how should I deliver those files globally?”**

### What is the scenario?

Imagine your company has EC2 worker servers:

**EC2 workers → generate reports → reports need permanent storage → customers around the world download them**

There are **two separate requirements**:

1. **Store reports safely and durably** → **Amazon S3**
2. **Deliver reports quickly to customers worldwide** → **Amazon CloudFront**

So:

**EC2 → S3 → CloudFront → Customers 🌍**

### Why S3?

S3 is **object storage**.

You can keep millions/billions of files there, and it is designed for highly durable storage.

For example:

```text
reports/
  customer1/report.pdf
  customer2/report.pdf
  customer3/report.pdf
```

The number of reports can keep growing without you managing disks.

### Why CloudFront?

Suppose your S3 bucket is in one AWS Region, but customers are in:

* Pakistan 🇵🇰
* USA 🇺🇸
* UK 🇬🇧
* Australia 🇦🇺

You don't want every customer to repeatedly download the file all the way from the S3 origin.

CloudFront puts **cached copies at edge locations around the world**.

So:

```text
                    ┌── Customer Pakistan
                    │
S3 ──→ CloudFront ──┼── Customer USA
                    │
                    ├── Customer UK
                    │
                    └── Customer Australia
```

The customer gets the content from a nearby CloudFront edge location when available.

---

### Don't confuse CloudFront and ElastiCache

This is important for SAA:

| Service            | Think                           |
| ------------------ | ------------------------------- |
| **S3**             | Store files/objects             |
| **CloudFront**     | Deliver/cache content globally  |
| **ElastiCache**    | Cache application/database data |
| **Redshift**       | Data warehouse / analytics      |
| **Instance Store** | Temporary local EC2 storage     |
| **S3 Glacier**     | Long-term archive               |

So if the question says:

> **“Store files and distribute them globally”**

Think:

**S3 + CloudFront** ✅

### What does “S3 One Zone-IA doesn't support global distribution” mean?

Don't interpret this as **S3 One Zone-IA cannot be accessed globally**.

The point is that **One Zone-IA is a storage class**, not a CDN.

If the requirement is:

> “Customers around the world need fast access”

you need **CloudFront** for global caching/delivery.

---

### 🧠 Shortcut

| Requirement in question        | Immediately think  |
| ------------------------------ | ------------------ |
| Durable object storage         | **S3**             |
| Global content delivery        | **CloudFront**     |
| Application/database caching   | **ElastiCache**    |
| Data warehouse                 | **Redshift**       |
| Temporary EC2 local storage    | **Instance Store** |
| Archive/very infrequent access | **Glacier**        |

**Question 11 in one line:**

> “EC2 generates reports → where do I permanently store them? **S3** → how do I deliver them quickly worldwide? **CloudFront**.”
