37. Question

Category: CSAA – Design Resilient Architectures

A commercial bank has a forex trading application. They created an Auto Scaling group of EC2 instances that allow the bank to cope with the current traffic and achieve cost-efficiency. They want the Auto Scaling group to behave in such a way that it will follow a predefined set of parameters before it scales down the number of EC2 instances, which protects the system from unintended slowdown or unavailability.

Which of the following statements are true regarding the cooldown period? (Select TWO.)

- It ensures that the Auto Scaling group launches or terminates additional EC2 instances without any downtime.
- `It ensures that the Auto Scaling group does not launch or terminate additional EC2 instances before the previous scaling activity takes effect.`
- It ensures that before the Auto Scaling group scales out, the EC2 instances have an ample time to cooldown.
- `Its default value is 300 seconds.`
- Its default value is 600 seconds.

Is question mein **EC2 Auto Scaling Cooldown Period** ka concept test ho raha hai.

Aayein pehle bilkul simple technical terms mein samajhte hain ke **Cooldown Period kya hota hai**, phir options ko dekhte hain.

---

## 1. Cooldown Period Kya Hai?

Jab Auto Scaling Group (ASG) koi nayi EC2 instance **launch (scale out)** ya **terminate (scale in)** karta hai, toh us instance ko start hone aur app load hone mein thoda **waqt lagta hai (e.g., 2–3 minutes)**.

Agar **Cooldown Period** na ho, toh yeh masla hoga:

1. Traffic badha $\rightarrow$ ASG ne ek naya EC2 launch kar diya.
2. Naya EC2 abhi boot ho raha hai (trafic handle karne ke kabil nahi hua).
3. CloudWatch metrics abhi bhi High CPU dikha rahe hain $\rightarrow$ ASG bina wait kiye **ek aur EC2 launch kar dega**.
4. Result: Fazool mein extra EC2 instances launch ho jayenge aur billing barh jayegi!

Is chiz ko rokne ke liye AWS ek **Cooldown Period** rakhta hai.

> **Cooldown Period Definition:** Ek aisa **Pause / Wait Time** (pause period) jo Auto Scaling activity ke baad aata hai, taake previous scaling action ka asar (effect) metrics par nazar aa sake — is duration ke dauran ASG mazeed koi naye instances launch ya terminate **NAHI** karta.

---

## 2. Cooldown Period Ke Core AWS Rules

* **Default Value:** **300 Seconds (5 Minutes)**.
* **Purpose:** Multi-scaling loop / flapping (baar baar unnecessary instances launch ya delete hone) ko rokna.
* **Applies to:** Simple Scaling Policies (Target Tracking Policies instance warm-up time use karti hain).

---

## 3. Correct Options Breakdown (Select TWO)

#### ✅ **1. It ensures that the Auto Scaling group does not launch or terminate additional EC2 instances before the previous scaling activity takes effect.**

* **Reason:** Yeh Cooldown Period ki exact definition hai. Yeh ASG ko force karta hai ke pehle wale instance ko warm-up / stabilization ka time mile pehle ke woh koi aur scaling decision le.

#### ✅ **2. Its default value is 300 seconds.**

* **Reason:** AWS Auto Scaling mein default cooldown period **300 seconds (5 minutes)** hota hai (jise aap apni zaroorat ke mutabiq change kar sakte hain).

---

## 4. Incorrect Options Breakdown

| Incorrect Option | Why It Is Wrong |
| --- | --- |
| **Its default value is 600 seconds.** | Incorrect value. Default 300 seconds hota hai. |
| **It ensures that before the Auto Scaling group scales out, the EC2 instances have an ample time to cooldown.** | "Cooldown" ka matlab EC2 instance ka thanda hona (temperature drop) nahi hota! Yeh sirf ASG automation engine ke liye ek pause timer hai. |
| **It ensures that the Auto Scaling group launches or terminates additional EC2 instances without any downtime.** | Downtime handle karna Load Balancer, Multi-AZ, aur Health Checks ka kaam hai, Cooldown Period ka nahi. |

---

## 5. Decision Matrix (Exam Cheat Sheet)

* **Default Auto Scaling Cooldown:** $\rightarrow$ **300 seconds (5 minutes)**.
* **Main Objective of Cooldown:** $\rightarrow$ Prevent launch/termination of extra instances before previous scaling takes effect.
* **What happens during Cooldown?** $\rightarrow$ ASG pauses simple scaling activities until the timer expires.
