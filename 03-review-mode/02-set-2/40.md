40. Question

Category: CSAA – Design Cost-Optimized Architectures

An organization is currently using a tape backup solution to store its application data on-premises. Plans are in place to use a cloud storage service to preserve the backup data for up to 10 years, which may be accessed about once or twice a year.

Which of the following is the most cost-effective option to implement this solution?

- Use AWS Data Transfer Terminal to physically transfer the backup data into Amazon S3 Glacier Flexible Retrieval.
- Use Amazon S3 to store the backup data and add a lifecycle rule to transition the current version to S3 Glacier Flexible Retrieval.
- Use AWS Storage Gateway to backup the data directly to Amazon S3 Glacier Flexible Retrieval.
- `Use AWS Storage Gateway to backup the data and transition it to Amazon S3 Glacier Deep Archive.`

Exactly 😄 — **Q40 is another pattern-recognition question.** The important part is recognizing **existing tape backup → Tape Gateway → long-term archive → Deep Archive**.

### 🎯 The mental model

The company already has:

```text
On-premises
Tape Backup
     ↓
    AWS
```

They don't want to completely redesign their backup system.

**AWS Storage Gateway – Tape Gateway** is designed specifically for this situation:

```text
Existing Backup Application
          ↓
      Tape Gateway
          ↓
    Virtual Tape in AWS
          ↓
   ┌──────┴──────┐
   ↓             ↓
S3 Glacier    S3 Glacier
Flexible      Deep Archive
Retrieval
              ↑
          Best for this case
```

### Why Deep Archive?

The question gives you the clues:

* **10 years** retention
* Access only **once or twice a year**
* Cost-effective storage

That screams:

> **S3 Glacier Deep Archive**

It's designed for **very long-term archival where data is rarely accessed**.

---

### 📊 Quick comparison

| Requirement                      | Service                     |
| -------------------------------- | --------------------------- |
| Existing tape backup             | **Tape Gateway**            |
| Long-term archive                | **Glacier**                 |
| Very rarely accessed             | **Deep Archive**            |
| Cheapest long-term archival      | **S3 Glacier Deep Archive** |
| Frequent/rapid archive retrieval | Glacier Flexible Retrieval  |

### 🔥 SAA shortcut

When you see:

> **"We currently use tapes and want to move backup to AWS without changing our backup workflow."**

Think:

**Tape Gateway**

Then look at the retention/access pattern:

> **Years + rarely accessed → S3 Glacier Deep Archive**

So the complete pattern is:

**Tape backup → Tape Gateway → Glacier Deep Archive** ✅

And yes, you correctly recognized this one as easy. The exam is mainly checking whether you know **which Storage Gateway mode is designed for tape backups** and **which Glacier class is cheapest for extremely long-term, rarely accessed data**.
