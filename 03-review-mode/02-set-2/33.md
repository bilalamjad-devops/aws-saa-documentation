33. Question

Category: CSAA – Design High-Performing Architectures

A business has a network of surveillance cameras installed within the premises of its data center. Management wants to leverage Artificial Intelligence to monitor and detect unauthorized personnel entering restricted areas. Should an unauthorized person be detected, the security team must be alerted via SMS.

Which solution satisfies the requirement?

- Set up Amazon Managed Service for Prometheus to stream live feeds from the cameras. Use Amazon Fraud Detector to detect unauthorized personnel. Set the phone numbers of the security team as subscribers to an Amazon SNS topic.
- Configure Amazon Elastic Transcoder to stream live feeds from the cameras. Use Amazon Kendra to detect authorized personnel. Set the phone numbers of the security team as subscribers to an Amazon SNS topic.
- Utilize a custom containerized video processing application on Amazon Elastic Kubernetes Service (Amazon EKS). Integrate AWS App2Container (A2C) and Amazon SageMaker Autopilot to detect unauthorized personnel. Set the phone numbers of the security team as subscribers to an Amazon SNS topic.
- `Use Amazon Kinesis Video Streams to stream live feeds from the cameras. Use Amazon Rekognition to detect unauthorized personnel. Set the phone numbers of the security team as subscribers to an Amazon SNS topic.`

Yes — Q33 is a **service-matching question**, and the wording makes it look more complicated than it really is.

The whole question can be reduced to:

> **Camera video → AI analyzes people → SMS security team**

Once you see that pipeline, the answer becomes straightforward.

## 1. What is the question asking?

There are **3 jobs**:

### Job 1: Get the camera video into AWS

The cameras are producing **live video**.

AWS service for ingesting/streaming video from cameras:

👉 **Amazon Kinesis Video Streams**

```text
Security Cameras
       │
       │ live video
       ▼
Kinesis Video Streams
```

---

### Job 2: Use AI to recognize/detect people

Now AWS needs to analyze the video and identify people.

👉 **Amazon Rekognition**

Specifically, Rekognition Video can analyze video for things like faces, people, objects, etc.

```text
Camera
   │
   ▼
Kinesis Video Streams
   │
   ▼
Amazon Rekognition
   │
   ▼
Unauthorized person detected
```

---

### Job 3: Alert the security team

The question says:

> security team must be alerted via SMS.

AWS service for notifications/SMS:

👉 **Amazon SNS**

```text
Rekognition
     │
     │ detection
     ▼
    SNS
     │
     ├── SMS → Security person 1
     ├── SMS → Security person 2
     └── SMS → Security person 3
```

So the complete architecture is:

```text
┌──────────────────┐
│ Security Cameras │
└────────┬─────────┘
         │ Live video
         ▼
┌──────────────────────┐
│ Kinesis Video Streams│
└────────┬─────────────┘
         │
         ▼
┌──────────────────────┐
│    Rekognition       │
│   AI / Video analysis│
└────────┬─────────────┘
         │
         │ Unauthorized person
         ▼
┌──────────────────────┐
│         SNS          │
└────────┬─────────────┘
         │
         ▼
    📱 SMS Alert
```

That's **Option 4**.

---

# 2. Now let's understand the wrong options

This is where the question is trying to test whether you know what each AWS service actually does.

### Option 1 — EKS + App2Container + SageMaker ❌

It sounds impressive because it throws a lot of AWS services at you. 😄

But that's exactly the trap.

#### EKS

You could technically build your own video-processing application on EKS, but why would you?

The question doesn't ask you to build a custom Kubernetes-based video-processing platform.

AWS already has a service designed for streaming video:

👉 **Kinesis Video Streams**

So EKS would add unnecessary complexity and cost.

#### App2Container

You may remember this from the question:

> App2Container (A2C)

It's a tool for **containerizing existing .NET or Java applications**.

It has nothing to do with detecting unauthorized people.

```text
App2Container
      ↓
Existing .NET/Java application
      ↓
Container
```

Not:

```text
Camera → App2Container → Detect person ❌
```

#### SageMaker Autopilot

SageMaker is for machine learning.

But the important SAA lesson is:

> **Don't automatically choose SageMaker whenever you see "AI/ML."**

AWS already provides a specialized computer-vision service:

👉 **Rekognition**

So using SageMaker here would be unnecessary.

---

# 3. Option 2 — Elastic Transcoder + Kendra ❌

This one has two obvious service mismatches.

### Elastic Transcoder

It's for **converting/transcoding media files between formats**.

For example:

```text
Video format A
      ↓
Elastic Transcoder
      ↓
Video format B
```

It isn't the service for ingesting live camera feeds.

So:

**Live camera streaming → Kinesis Video Streams**

not Elastic Transcoder.

### Amazon Kendra

Kendra is an **intelligent enterprise search service**.

Think:

```text
Company documents
      ↓
Kendra
      ↓
Search / find information
```

It doesn't perform facial/person detection.

Therefore:

❌ Kendra for detecting unauthorized personnel.

---

# 4. Option 3 — Prometheus + Fraud Detector ❌

This is another "wrong service for the job" option.

### Amazon Managed Service for Prometheus

Prometheus is for **monitoring**.

Think:

```text
ECS / Kubernetes / infrastructure
             ↓
        Prometheus
             ↓
 CPU / memory / metrics / alerts
```

It doesn't ingest live surveillance video.

So:

**Monitoring metrics → Prometheus**

**Camera video → Kinesis Video Streams**

---

### Amazon Fraud Detector

The name gives you the clue:

> **Fraud** Detector.

It's for detecting things like:

* payment fraud
* fake accounts
* suspicious online activity

Not:

> "Is this person allowed to enter the restricted area?"

So:

```text
Online transaction
       ↓
Fraud Detector
       ↓
Possible fraud
```

versus:

```text
Camera video
       ↓
Rekognition
       ↓
Person / face detection
```

---

# 5. The most important distinction

You don't need to memorize all those services individually right now.

Build this mental mapping:

| Requirement                             | AWS Service                               |
| --------------------------------------- | ----------------------------------------- |
| 📹 Ingest/stream live camera video      | **Kinesis Video Streams**                 |
| 🤖 Analyze faces/people/video           | **Amazon Rekognition**                    |
| 📱 Send SMS notifications               | **Amazon SNS**                            |
| 📊 Monitor infrastructure/metrics       | **Amazon Managed Service for Prometheus** |
| 🔍 Intelligent document/search          | **Amazon Kendra**                         |
| 💳 Detect online fraud                  | **Amazon Fraud Detector**                 |
| 🎞️ Convert media formats               | **Elastic Transcoder**                    |
| 📦 Containerize existing .NET/Java apps | **App2Container**                         |
| 🤖 Build/train/manage ML models         | **SageMaker**                             |
| ☸️ Run containers/Kubernetes            | **EKS**                                   |
