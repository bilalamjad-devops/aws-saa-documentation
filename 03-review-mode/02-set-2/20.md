20. Question

Category: CSAA – Design High-Performing Architectures

A company owns a photo-sharing app that stores user uploads on Amazon S3. There has been an increase in the number of explicit and offensive images being reported. The company currently relies on human efforts to moderate content, and it wants to streamline this process by using Artificial Intelligence to only flag images for review. For added security, any communication with its resources on its Amazon VPC must not traverse the public Internet.

How can this task be accomplished with the LEAST amount of effort?

- Use an image classification model in Amazon SageMaker. Set up Amazon GuardDuty and connect it with SageMaker to ensure that all communications do not traverse the public Internet.
- `Use Amazon Rekognition to detect images with graphic nudity or violence in S3. Create an Interface VPC endpoint for Rekognition with the necessary policies to prevent any traffic from traversing the public Internet.`
- Use AWS Lambda to create custom image moderation logic. Deploy this Lambda function in a public VPC to ensure communication through the public Internet.
- Use Amazon Detective to detect images with graphic nudity or violence in S3. Ensure that all communications made by your AWS resources do not traverse the public Internet via the AWS Audit Manager service.

Absolutely. This question is actually testing **two concepts together**:

1. **Which AWS service can automatically detect inappropriate images?**
2. **How can we access that AWS service privately without the Internet?**

Let's break it down simply.

---

## 1. What is the question saying?

The company has:

```text
Users
  ↓
Photo-sharing App
  ↓
Amazon S3
  ↓
User uploads photos
```

Now users are uploading **offensive/explicit images**.

Currently:

> Humans look at the images → identify bad images → flag them.

The company wants:

> **AI looks at the images → flags suspicious images → human reviews only those.**

And there is another requirement:

> Communication with AWS resources inside the VPC **must NOT go through the public Internet**.

So we need:

**AI image moderation + private connectivity**

---

# 2. Amazon Rekognition = image/video understanding

This is the first major clue.

**Amazon Rekognition** is a ready-made AWS AI service for analyzing images and videos.

For this question:

```text
S3 image
   ↓
Amazon Rekognition
   ↓
"Possibly explicit"
"Violence"
"Nudity"
etc.
   ↓
Human reviews flagged images
```

You **don't need to build/train your own ML model**.

That's why Rekognition wins the **"least effort"** requirement.

### Remember:

> 🖼️ **Rekognition = AWS's ready-made image/video analysis service**

---

# 3. Why not SageMaker?

This is an important exam distinction.

**SageMaker** is for building/training/deploying your own machine-learning models.

You could theoretically build an image-classification system with SageMaker, but that's considerably more work.

Question says:

> **LEAST amount of effort**

Therefore:

**Rekognition ✅**

**SageMaker ❌**

Think:

```text
Need ready-made image analysis?
        ↓
   Rekognition

Need to build/train ML model?
        ↓
     SageMaker
```

---

# 4. What is an Interface VPC Endpoint?

This is the second major concept.

Normally, imagine your resource is inside a private subnet:

```text
Private VPC
    ↓
Internet/NAT
    ↓
Amazon Rekognition
```

But the question says:

> **Don't use the public Internet.**

So we create:

**Interface VPC Endpoint**

```text
Private VPC
     │
     │ private connection
     ↓
Interface VPC Endpoint
     │
     ↓
Amazon Rekognition
```

The endpoint gives your VPC a **private entry point** to the AWS service.

No Internet Gateway is required.

---

# 5. Why is it called "Interface"?

Because AWS creates an **ENI (Elastic Network Interface)** inside your subnet.

Conceptually:

```text
Your Private Subnet

┌──────────────────────────────┐
│                              │
│ EC2 / Lambda                 │
│      │                       │
│      ↓                       │
│ Interface Endpoint (ENI)    │
│      │                       │
└──────┼───────────────────────┘
       │
       ↓
Amazon Rekognition
```

The endpoint has a **private IP address**.

---

# 6. Gateway Endpoint vs Interface Endpoint

This connects directly to what you learned earlier.

### Gateway Endpoint

Used for:

> **S3 + DynamoDB**

```text
VPC
 ↓
Gateway Endpoint
 ↓
S3 / DynamoDB
```

### Interface Endpoint

Used for many other AWS services, such as Rekognition.

```text
VPC
 ↓
Interface Endpoint
 ↓
Rekognition
```

### 🧠 Exam shortcut

| Endpoint               | Main idea                                    |
| ---------------------- | -------------------------------------------- |
| **Gateway Endpoint**   | S3 + DynamoDB                                |
| **Interface Endpoint** | Many AWS services using private connectivity |

So when you see:

> **"Access Rekognition privately from a VPC"**

Think:

**Interface VPC Endpoint.** ✅

---

# 7. Let's eliminate the other answers

### ❌ Detective + Audit Manager

These services are completely wrong for the requirements.

**Amazon Detective**

> Investigates security findings/suspicious activity.

It does **not** analyze images for nudity.

**AWS Audit Manager**

> Helps with auditing/compliance evidence.

It does **not** make network traffic private.

So:

**Detective = security investigation**

**Audit Manager = compliance/audit**

Neither solves this problem.

---

### ❌ Lambda + custom image moderation

You *could* write your own Lambda code:

```text
S3
 ↓
Lambda
 ↓
Your own image-analysis logic
```

But the question says:

> **least amount of effort**

Why build your own image moderation system when AWS already provides **Rekognition**?

Also, the answer says to put Lambda in a **public VPC**, which conflicts with:

> Don't traverse the public Internet.

So ❌.

---

### ❌ SageMaker + GuardDuty

Two problems.

**SageMaker** → unnecessary effort because you're building/training your own model.

**GuardDuty** → security threat detection, **not networking/private connectivity**.

So ❌.
