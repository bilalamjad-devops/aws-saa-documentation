28. Question

Category: CSAA – Design High-Performing Architectures

An animation studio uses high-performance computing (HPC) servers for rendering gigabytes of video data. The studio are planning to migrate their environment to AWS and are in need of a highly available parallel file system for asset storage. The file system will be accessed concurrently by a fleet of EC2 instances and must be capable of sustained throughput.

Which AWS storage solution should the solutions architect recommend?

- Amazon File Cache
- `Amazon FSx for Lustre with Persistent file system`
- Amazon Elastic File System (EFS) with Elastic Throughput mode
- Amazon FSx for Lustre with Scratch file system


### Sahi Jawab:

**Option 2:** **Amazon FSx for Lustre with Persistent file system**

> **Exam Tip (FSx for Lustre Deployment Types):**
> * **HPC + Temporary / Short-term / Non-replicated (Cost Savings)** = **FSx for Lustre Scratch**
> * **HPC / Video Rendering + Long-term / Highly Available / Sustained Throughput** = **FSx for Lustre Persistent**
