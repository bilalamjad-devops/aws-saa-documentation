10. Question

Category: CSAA – Design Secure Architectures

A startup plans to scale out its cloud resources. With its rapid growth, the company needs an automated way of scanning its Amazon EC2 instances for security purposes. The company needs to automatically discover software vulnerabilities on its cloud resources and validate that its workloads meet security compliances.

Which of the following options should be implemented to meet the company requirements?

- Leverage Amazon Macie’s automated discovery and scanning to protect Amazon EC2 instances. Publish a notification on Amazon Simple Notification Service (Amazon SNS) for the results.
- Create a rule on Amazon EventBridge (Amazon CloudWatch Events) to detect changes on AWS Trusted Advisor checks. Publish a notification on Amazon Simple Notification Service (Amazon SNS).
- `Enable Amazon Inspector to publish results to Amazon EventBridge (Amazon CloudWatch Events) and send notifications using Amazon Simple Notification Service (Amazon SNS)`
- Enable Amazon GuardDuty to continuously monitor Amazon EC2 instances and publish notifications to Amazon Simple Notification Service (SNS).

Is question ka step-by-step breakdown Roman Urdu mein yeh hai:

---

### Question Ka Summary:

Rapidly growing startup ko apne **Amazon EC2 instances ko automatically scan** karna hai taake **software vulnerabilities (CVEs)** aur **security compliance issues** ko discover kiya ja sake, aur unki notifications bheji ja sakein.

---

### Options Ka Breakdown:

1. **Option 1 (Amazon Macie + Amazon SNS):**
* **Galat:** Macie Amazon S3 buckets ke andar sensitive data (PII, Credit Cards) aur privacy risks discover karne ke liye hota hai. Yeh EC2 instances par software vulnerability scanning nahi karta.


2. **Option 2 (Amazon EventBridge + AWS Trusted Advisor):**
* **Galat:** Trusted Advisor high-level account best practices (cost optimization, basic security limits, performance) check karta hai. Yeh OS-level software vulnerabilities aur CVEs ki detailed deep scanning nahi karta.


3. **Option 3 (Amazon Inspector + EventBridge + SNS):**
* **Sahi (Correct):** **Amazon Inspector** ek automated vulnerability management service hai jo Amazon EC2 instances, ECR container images, aur Lambda functions ko automatically aur continuously scan karti hai. Yeh **software vulnerabilities (CVEs)** aur **unintended network exposure** ko detect karti hai aur EventBridge ke zariye SNS notifications trigger kar sakti hai.


4. **Option 4 (Amazon GuardDuty + SNS):**
* **Galat:** GuardDuty ek **Threat Detection service** hai jo anomalous behavior, malicious activity, aur compromised instances/credentials (jaise crypto-mining ya unauthorized IP access) ko VPC Flow Logs, DNS Logs, aur CloudTrail ke zariye monitor karti hai. Yeh software code ya OS package ki *vulnerabilities scan* nahi karti.



---

### Sahi Jawab:

**Option 3:** **Enable Amazon Inspector to publish results to Amazon EventBridge (Amazon CloudWatch Events) and send notifications using Amazon Simple Notification Service (Amazon SNS)**

> **Exam Tip:**
> * **Software Vulnerabilities (CVEs) & Patch/Compliance Scanning** = **Amazon Inspector**
> * **Threat Detection, Malware, Compromised Instances/Keys** = **Amazon GuardDuty**
> * **PII / Sensitive Data in S3** = **Amazon Macie**
