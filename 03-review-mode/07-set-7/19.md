19. Question

Category: CSAA – Design High-Performing Architectures

A multinational corporation is expanding its operations and needs to efficiently monitor and analyze IAM-related errors, specifically Access Denied and Unauthorized errors in their AWS accounts. The company has AWS CloudTrail enabled for logging purposes.

Which solution would meet the requirements while requiring the least effort to implement?

- Utilize AWS Security Hub to aggregate and analyze security data, including CloudTrail logs, for IAM permission errors.
- `Query with AWS CloudTrail Lake to find specific errors in CloudTrail logs.`
- Use Amazon Athena to search for IAM-related errors within CloudTrail logs.
- Configure Amazon QuickSight to analyze CloudTrail logs and create a dashboard for monitoring IAM-related errors.

---

### Question Ka Summary:

Multinational corporation ko apne AWS accounts mein **IAM-related errors** (jaise `Access Denied` aur `UnauthorizedOperation`) ko **monitor aur analyze** karna hai. **AWS CloudTrail** already enabled hai.

Requirement: **Least effort to implement** (kam se kam setup/overhead) ke sath is requirement ko kaise poora kiya jaye?

---

### Options Ka Breakdown:

1. **Option 1 (AWS Security Hub):**
* **Galat:** Security Hub security standards compliance check karne aur security findings aggregate karne ke liye hai. Direct CloudTrail logs ke andar custom IAM error log querying/analysis ke liye yeh "least effort" log analysis tool nahi hai.


2. **Option 2 (AWS CloudTrail Lake):**
* **Sahi (Correct):**
* **AWS CloudTrail Lake** ek managed SQL-based query capability hai jo CloudTrail events ko ingest, analyze, aur query karti hai.
* CloudTrail Lake mein **Sample Queries / Built-in Templates** hotay hain (specifically IAM permission errors, Access Denied, aur Unauthorized operations ke liye). Isme Athena ki tarah Glue Data Catalog / Table schema manually setup karne ki zaroorat nahi hoti — **least implementation effort** lagta hai.




3. **Option 3 (Amazon Athena):**
* **Galat:** Athena se S3 logs query ho sakte hain, lekin iske liye pehle AWS Glue Data Catalog ya manual `CREATE TABLE` DDL queries execute karke schema define karna padta hai, partitions manage karne hote hain, aur manual SQL writing karni padti hai. Implementation effort CloudTrail Lake se zyada hai.


4. **Option 4 (Amazon QuickSight):**
* **Galat:** QuickSight dashboarding aur BI tool hai. CloudTrail logs ko QuickSight mein laane ke liye S3, Glue Data Catalog, aur Athena pipeline banani padegi, jisme boht zyada operational overhead aur setup effort lagta hai.



---

### Sahi Jawab:

**Option 2:** **Query with AWS CloudTrail Lake to find specific errors in CloudTrail logs.**

> **Exam Tip (CloudTrail Log Analysis):**
> * **CloudTrail Lake:** Built-in managed SQL log lake (Zero ETL / No schema creation required = **Least Effort**).
> * **Amazon Athena:** Requires manual S3 table schema creation / Glue crawler setup (**More Effort**).
