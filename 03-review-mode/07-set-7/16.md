16. Question

Category: CSAA – Design Secure Architectures

A DevOps Engineer is asked to deploy a web application on Amazon EC2 instances. The instances are defined in a target group and are able to scale horizontally based on the configuration of an Auto Scaling group.

The domain should be available publicly via the internet and is to be configured with session affinity (sticky sessions) to improve the user session management of the application. The application should be secured with an AWS WAF for additional protection against web attacks.

Which among the choices below should be set up to satisfy this requirement? (Select TWO.)

- `Create a Web ACL in AWS WAF configured with the public domain.`
- `Set up an internet-facing Application Load Balancer (ALB). Configure the listener over HTTP and HTTPS to forward traffic to the application target group.`
- Launch a Gateway Load Balancer. Configure the IP listener routing to forward traffic to the application target group.
- Provision a Network Load Balancer (NLB) with a public subnet. Configure the TCP listener to forward traffic to the application target group.
- Deploy an AWS Network Firewall to a public subnet of a VPC.

Is question ka step-by-step breakdown Roman Urdu mein yeh hai:

---

### Question Ka Summary:

EC2 instances par hosted web application ko public internet ke zariye deploy karna hai.

**Key Requirements:**

1. **Public Access & Sticky Sessions:** Public domain ke zariye access ho aur **Session Affinity (Sticky Sessions)** supported ho.
2. **Security:** Application ko **AWS WAF (Web Application Firewall)** ke sath secure karna hai.
3. Aapko **DO (2)** options select karne hain.

---

### Options Ka Breakdown:

1. **Option 1 (Create a Web ACL in AWS WAF...):**
* **Wait:** WAF Web ACL directly domain par configure nahi hoti, balki ALB, CloudFront, ya API Gateway ke sath associate ki jaati hai. Baaqi options ke sath ALB placement ko dekhein.


2. **Option 2 (Set up an internet-facing Application Load Balancer - ALB):**
* **Sahi (Correct 1):**
* **Application Load Balancer (ALB)** Layer 7 (HTTP/HTTPS) par kaam karta hai aur **Sticky Sessions (Session Affinity)** ko natively support karta hai.
* ALB direct **AWS WAF** ke sath integrate hota hai (WAF Web ACL ko ALB par associate kiya jata hai).




3. **Option 3 (Launch a Gateway Load Balancer - GWLB):**
* **Galat:** GWLB third-party virtual appliances (firewalls, IDS/IPS) ke traffic ko route karne ke liye Layer 3/4 par kaam karta hai. Yeh Sticky Sessions (HTTP level) ya AWS WAF integration support nahi karta.


4. **Option 4 (Provision a Network Load Balancer - NLB):**
* **Galat:** NLB Layer 4 (TCP/UDP) ultra-high performance load balancer hai. Yeh HTTP-level sticky sessions (cookie-based) aur direct AWS WAF integration support nahi karta (Jab tak ALB ke aage NLB na ho, lekin direct WAF support ALB par hoti hai).


5. **Option 5 (Deploy an AWS Network Firewall...):**
* **Galat:** AWS Network Firewall VPC-level network traffic filtering (IP, port, domain lists) ke liye hota hai. Web-level attacks (SQL Injection, Cross-Site Scripting) ke liye AWS WAF use hota hai.



---

### Wait, Options Re-evaluation for Select TWO:

Let's re-read the WAF & ALB options:

* **Option 1:** Create a Web ACL in AWS WAF (Web ACL WAF ka primary resource hai jo protection rules contain karta hai).
* **Option 2:** Set up an internet-facing Application Load Balancer (ALB). Configure HTTP/HTTPS listeners to forward traffic to the target group.

Toh AWS WAF aur ALB ka combination bilkul fit baithta hai!

---

### Sahi Jawab (Select TWO):

* **Option 1:** **Create a Web ACL in AWS WAF configured with the public domain.** (Web ACL is associated with the ALB serving the domain)
* **Option 2:** **Set up an internet-facing Application Load Balancer (ALB). Configure the listener over HTTP and HTTPS to forward traffic to the application target group.**

> **Exam Tip:**
> * **Layer 7 + Cookie Sticky Sessions + AWS WAF Protection** = **Application Load Balancer (ALB)**
> * **Layer 4 + Extreme Performance / Static IP** = **Network Load Balancer (NLB)**
> * **Third-Party Security Appliances Inspection** = **Gateway Load Balancer (GWLB)**
