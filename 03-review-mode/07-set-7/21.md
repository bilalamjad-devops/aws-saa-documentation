21. Question

Category: CSAA – Design Resilient Architectures

An advertising company is currently working on a proof of concept project that automatically provides SEO analytics for its clients. Your company has a VPC in AWS that operates in a dual-stack mode in which IPv4 and IPv6 communication is allowed. You deployed the application to an Auto Scaling group of EC2 instances with an Application Load Balancer in front that evenly distributes the incoming traffic. You are ready to go live but you need to point your domain name (tutorialsdojo.com) to the Application Load Balancer.

In Route 53, which record types will you use to point the DNS name of the Application Load Balancer? (Select TWO.)

- `Alias with a type "AAAA" record set`
- Alias with a type of “MX” record set
- `Alias with a type "A" record set`
- Alias with a type "CNAME" record set
- Non-Alias with a type "A" record set

### Question Ka Summary:

SEO analytics application ko **dual-stack VPC (IPv4 aur IPv6)** mein host kiya gaya hai jiske aage ek **Application Load Balancer (ALB)** laga hua hai. Apex domain name (`tutorialsdojo.com`) ko ALB ke DNS name par Route 53 ke zariye point karna hai.

**Key Requirements:**

1. **Domain:** Zone Apex (`tutorialsdojo.com`).
2. **IP Protocols:** Dual-stack mode (**IPv4** aur **IPv6** dono support required hain).
3. **AWS ALB Target:** ALB ko domain se point karna hai.
4. Aapko **DO (2)** record types select karne hain.

---

### Options Ka Breakdown:

1. **Option 1 (Alias with a type "AAAA" record set):**
* **Sahi (Correct 1):**
* **"AAAA" record** IPv6 addresses map karne ke liye use hota hai.
* Route 53 ka **Alias record** AWS resources (jaise ALB) par Route 53 se Direct mapping karta hai aur Dual-stack ALB ke IPv6 traffic ko handle karne ke liye **AAAA Alias** record required hota hai.




2. **Option 2 (Alias with a type "MX" record set):**
* **Galat:** MX (Mail Exchanger) records email servers route karne ke liye hote hain, web traffic load balancing ke liye nahi.


3. **Option 3 (Alias with a type "A" record set):**
* **Sahi (Correct 2):**
* **"A" record** IPv4 addresses map karne ke liye use hota hai.
* ALB ke IPv4 endpoint ko Route 53 mein Zone Apex domain (`tutorialsdojo.com`) par map karne ke liye **A Alias** record configure kiya jata hai.




4. **Option 4 (Alias with a type "CNAME" record set):**
* **Galat:** Route 53 mein ALB ke liye CNAME Alias nahi hota, aur na hi CNAME record DNS standard rules ke mutabiq **Zone Apex (`tutorialsdojo.com`)** par allow hota hai (Zone Apex par CNAME restriction hoti hai, isliye Route 53 Alias A / AAAA records feature provide karta hai).


5. **Option 5 (Non-Alias with a type "A" record set):**
* **Galat:** Standard Non-Alias "A" record ke liye static IP address zaroori hota hai. ALB ka IP address dynamic hota hai aur badalta rehta hai, isliye ALB par direct Non-Alias "A" record mapping kaam nahi karti.



---

### Sahi Jawab (Select TWO):

* **Option 1:** **Alias with a type "AAAA" record set** (For IPv6 traffic routing to ALB)
* **Option 3:** **Alias with a type "A" record set** (For IPv4 traffic routing to ALB)

> **Exam Tip:**
> * **Zone Apex Domain (`example.com`) to ALB Routing:** Standard CNAME ke bajaye hamesha **Alias Records** use hote hain.
> * **IPv4 Traffic** = **Alias "A" Record**
> * **IPv6 Traffic** = **Alias "AAAA" Record**
