31. Question

Category: CSAA – Design Resilient Architectures

A company has a running m5ad.large EC2 instance with a default attached 75 GB SSD instance-store backed volume. You shut it down and then start the instance. You noticed that the data which you saved earlier on the attached volume is no longer available.

What might be the cause of this?

- The EC2 instance was using EBS backed root volumes, which are ephemeral and only live for the life of the instance.
- `The EC2 instance was using instance store volumes, which are ephemeral and only live for the life of the instance.`
- The instance was hit by a virus that wipes out all data.
- The volume of the instance was not big enough to handle all of the processing data.

Is question ka step-by-step breakdown Roman Urdu mein yeh hai:

---

### Question Ka Summary:

Ek `m5ad.large` EC2 instance chal raha tha jisme 75 GB ka **instance-store backed volume** attached tha. Instance ko **shut down (stop)** karke dobara **start** kiya gaya, toh dekha ke saved data ghayab/delete ho gaya hai.

Requirement: Data ghayab hone ki **asal waja (cause)** kya hai?

---

### Options Ka Breakdown:

1. **Option 1 (EBS backed root volumes are ephemeral...):**
* **Galat:** EBS (Elastic Block Store) volumes persistent hote hain — instance stop/start karne par EBS ka data delete nahi hota. Plus, ephemeral storage Instance Store volumes hote hain, EBS nahi.


2. **Option 2 (The EC2 instance was using instance store volumes...):**
* **Sahi (Correct):**
* **Instance Store Volumes (Ephemeral Storage):** EC2 host server ke sath physically attached NVMe/SSD disks hoti hain.
* **Crucial Rule:** Jab bhi aap EC2 instance ko **STOP / SHUT DOWN** karte hain ya instance **TERMINATE** hota hai, toh Instance Store volume ka sara data **permanently lose (delete)** ho jata hai. Data sirf tab tak rehta hai jab tak instance running state mein ho ya OS reboot ho.




3. **Option 3 (Virus attack):**
* **Galat:** Yeh koi technical AWS architecture explanation nahi hai.


4. **Option 4 (Volume size too small):**
* **Galat:** Size chota hone se instance crash ya full disk error aa sakta hai, lekin stop/start karne par data wipe nahi hota.



---

### Sahi Jawab:

**Option 2:** **The EC2 instance was using instance store volumes, which are ephemeral and only live for the life of the instance.**

> **Exam Tip (Instance Store vs EBS Storage):**
> * **Instance Store (Ephemeral):** Ultra-high IOPS / Low latency temporary storage. Instance **STOP / TERMINATE** par data **PURA DELETE** ho jata hai. (Reboot par data rehta hai).
> * **EBS (Persistent):** Network-attached storage. Instance **STOP / START** karne par bhi data **SAFE / PERSISTENT** rehta hai.
