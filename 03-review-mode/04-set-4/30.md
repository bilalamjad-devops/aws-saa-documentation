30. Question

Category: CSAA – Design Resilient Architectures

A company has a fixed set of Amazon EC2 instances inside a VPC in the AWS cloud. The instances run a mission-critical application. In a recent incident, one of the EC2 instances suddenly powered down which affected the availability of the application. To avoid this incident in the future, the management wants to get notified of any upcoming AWS events that may affect these EC2 instances.

Which of the following options is the recommended action to meet the above requirements?

- Set up an Amazon EventBridge (Amazon CloudWatch Events) rule to check for any status change for Amazon EC2 instances. Set the target to an AWS Lambda function that will send a notification and restart the affected Amazon EC2 instances.
- Create an Amazon EventBridge (Amazon CloudWatch Events) rule that is scheduled to run every 24 hours. Set the target to an AWS Lambda function that will check AWS Service Health Dashboard and send notifications for any events that may affect Amazon EC2 instances.
- `Create an Amazon EventBridge (Amazon CloudWatch Events) rule to check for AWS Personal Health Dashboard events that are related to Amazon EC2 instances. To send notifications, set an Amazon SNS topic as a target for the rule.`
- Set up an Amazon EventBridge (Amazon CloudWatch Events) rule to check for AWS Service Health Dashboard events that are related to Amazon EC2 instances. To send notifications, set an Amazon SNS topic as a target for the rule.

Is question mein **AWS Health Notifications**, **AWS Personal Health Dashboard (PHD)** vs **AWS Service Health Dashboard (SHD)**, aur **Amazon EventBridge** ka event-driven alerting architecture test ho raha hai.

---

### 1. Requirement Breakdown

1. **Problem:** Pehle ek EC2 instance unexpected scheduled maintenance/event ki wajah se shutdown ho gaya tha.
2. **Goal:** Management ko **aane wale (upcoming) AWS events** ke baare mein pehle se **notifications** chahiye jo unki specific EC2 instances ko affect kar sakte hon.
3. **Key Distinction:** Notification specific company-owned resources (account-specific EC2 instances) ke liye honi chahiye, na ke global regional outage ke liye.

---

### 2. Technical Evaluation

```
[ AWS Maintenance / Incident Event on Your Instance ]
                          │
                          ▼
        [ AWS Personal Health Dashboard (PHD) ]
                          │
                          ▼
     [ Amazon EventBridge (Matches PHD Event) ]
                          │
                          ▼
            [ Amazon SNS Topic Notification ]

```

1. **AWS Personal Health Dashboard (PHD):**
* PHD aap ke **specific AWS account aur specific resources** (jaise aap ke EC2 instances ki upcoming hardware maintenance) ki health events show karta hai.
* EventBridge natively PHD events ko capture karta hai, jinhe direct **Amazon SNS** topic par bhej kar email/SMS notifications generate ki ja sakti hain.


2. **AWS Service Health Dashboard (SHD):**
* SHD (ab AWS Health Dashboard ka global view) general AWS service availability show karta hai (e.g., *"us-east-1 mein S3 down hai"*). Yeh aap ke specific EC2 instances ke upcoming maintenance events highlight nahi karta.



---

### 3. Correct Option Explanation

#### ✅ **Create an Amazon EventBridge (Amazon CloudWatch Events) rule to check for AWS Personal Health Dashboard events that are related to Amazon EC2 instances. To send notifications, set an Amazon SNS topic as a target for the rule.**

* **Why it works:** AWS Personal Health Dashboard specific EC2 instances ke hardware degradation ya upcoming maintenance ka advance notice deta hai. EventBridge is event ko capture karke SNS topic ke zariye team ko instantly notify kar deta hai.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **EC2 Status Change + Lambda restart...** | Yeh instance ke pehle se power down hone ke **baad** (reactive) kaam karta hai; upcoming planned events ka advance notification nahi deta. |
| **Scheduled Lambda + Service Health Dashboard...** | SHD generic global service availability dikhata hai, specific account resources ke maintenance events nahi. Polling waste of operational effort hai. |
| **EventBridge + Service Health Dashboard + SNS...** | Service Health Dashboard general region-level status dikhata hai, account-specific EC2 instances ke upcoming events notify nahi karta. |

---

### 5. Exam Decision Matrix (AWS Health Cheat Sheet)

* **Account-Specific / Resource-Specific Events & Scheduled Maintenance:** $\rightarrow$ **AWS Personal Health Dashboard (PHD)**
* **Global AWS Region / Service Outages (Public View):** $\rightarrow$ **AWS Service Health Dashboard (SHD)**
* **Automated Event Alerts for Maintenance / Issues:** $\rightarrow$ **AWS Health + Amazon EventBridge + Amazon SNS**
