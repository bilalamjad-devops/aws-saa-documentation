2. Question

Category: CSAA – Design High-Performing Architectures

A startup plans to develop a multiplayer game that uses UDP as the protocol for communication between clients and game servers. The data of the users will be stored in a key-value store. As the Solutions Architect, you need to implement a solution that will distribute the traffic across a number of servers.

Which of the following could help you achieve this requirement?

- `Distribute the traffic using Network Load Balancer and store the data in Amazon DynamoDB.`
- Distribute the traffic using Application Load Balancer and store the data in Amazon RDS.
- Distribute the traffic using Application Load Balancer and store the data in Amazon DynamoDB.
- Distribute the traffic using Network Load Balancer and store the data in Amazon Aurora.

### 🎯 What is being tested?

**UDP load balancing + key-value database.**

### ✅ Correct answer

**Network Load Balancer + Amazon DynamoDB**

### 🔑 Key concept

* **NLB** → supports **UDP** traffic.
* **DynamoDB** → managed **key-value NoSQL** database.

Flow:

**Game Clients (UDP) → NLB → Game Servers → DynamoDB**

### ❌ Others

* **ALB** → supports HTTP/HTTPS, not UDP.
* **RDS/Aurora** → relational databases, not key-value stores.

### 🔥 Exam shortcut

**UDP → NLB**
**Key-value → DynamoDB**


18-September-2026


Is question mein **Network Protocols (UDP vs HTTP/HTTPS)** aur **Database Types (Key-Value Store)** ka combination test ho raha hai.

Aayein scenario ko Roman Urdu mein simple steps mein analyze karte hain:

---

## 1. Requirement Breakdown

1. **Protocol Requirement:** Multiplayer game **UDP protocol** use karti hai.
2. **Database Requirement:** Users ka data ek **Key-Value Store** mein save karna hai.
3. **Goal:** Traffic ko multiple game servers par distribute karna aur sahi database engine choose karna.

---

## 2. Technical Evaluation

1. **UDP Traffic Distribution (Load Balancer Choice):**
* **Application Load Balancer (ALB):** Sirf **HTTP / HTTPS / HTTP/2 / gRPC** (Layer 7) protocols ko support karta hai. Yeh UDP traffic handle **nahi** kar sakta.
* **Network Load Balancer (NLB):** Ultra-high performance (Layer 4) load balancer hai jo **TCP, UDP, aur TLS** protocols ko support karta hai.


2. **Key-Value Database Choice:**
* **Amazon DynamoDB:** Fully managed, serverless **NoSQL Key-Value store** hai jo single-digit millisecond performance deta hai.
* **Amazon RDS / Aurora:** Relational (SQL / Structured) databases hain, Key-Value stores nahi.



---

## 3. Correct Option Explanation

#### ✅ **Distribute the traffic using Network Load Balancer and store the data in Amazon DynamoDB.**

* **Why it works:** **NLB** UDP traffic ko efficiently distribute karta hai, aur **DynamoDB** native AWS key-value database hai jo high-throughput gaming data ke liye ideal hai.

---

## 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **ALB + Amazon RDS** | ALB UDP protocol support nahi karta; RDS relational DB hai (key-value nahi). |
| **ALB + Amazon DynamoDB** | ALB UDP protocol support nahi karta. |
| **NLB + Amazon Aurora** | Aurora relational (SQL) database hai, key-value store nahi. |

---

## 5. Exam Decision Matrix (Load Balancer & Database Cheat Sheet)

* **UDP / Low Latency / Static IP Required:** $\rightarrow$ **Network Load Balancer (NLB)**
* **HTTP / HTTPS / Path-based Routing:** $\rightarrow$ **Application Load Balancer (ALB)**
* **Key-Value NoSQL Database:** $\rightarrow$ **Amazon DynamoDB**
* **Relational SQL Database:** $\rightarrow$ **Amazon RDS / Amazon Aurora**
