25. Question

Category: CSAA – Design Secure Architectures

A hospital has a mission-critical application that uses a RESTful API powered by Amazon API Gateway and AWS Lambda. The medical officers upload PDF reports to the system which are then stored as static media content in an Amazon S3 bucket.

The security team wants to improve its visibility when it comes to cyber-attacks and ensure HIPAA (Health Insurance Portability and Accountability Act) compliance. The company is searching for a solution that continuously monitors object-level S3 API operations and identifies protected health information (PHI) in the reports, with minimal changes in the existing Lambda function.

Which of the following solutions will meet these requirements with the LEAST operational overhead?

- `Use Amazon Textract to extract the text from the PDF reports. Integrate Amazon Comprehend Medical with the existing Lambda function to identify the PHI from the extracted text.`
- Use Amazon Transcribe to read and analyze the PDF reports using the StartTranscriptionJob API operation. Use Amazon CloudWatch Logs to detect protected health information (PHI) content by tracking access logs and security events.
- Use Amazon Textract with the StartDocumentTextDetection API operation to extract text from PDF reports. Analyze the extracted data with a custom-built PHI detection algorithm within the Lambda function.
- Use Amazon Textract Medical with PII redaction turned on to extract and filter sensitive text from the PDF reports. Create a new Lambda function that calls the regular Amazon Comprehend API to identify the PHI from the extracted text.

Aayein requirements ko Roman Urdu mein step-by-step analyze karte hain:

---

### 1. Requirement Breakdown

1. **Source Data:** Medical officers PDF reports upload karte hain jo **Amazon S3** mein store hoti hain.
2. **Security & Compliance Goal:** HIPAA compliance ensure karni hai aur reports ke andar se **Protected Health Information (PHI)** (jaise patient names, medical conditions, medications) ko automatically identify karna hai.
3. **Constraints:**
* **Least operational overhead** (custom ML models/algorithms nahi likhne).
* **Minimal changes** in the existing Lambda function architecture.



---

### 2. Technical Evaluation

```
[ PDF Reports in S3 ] ──► [ Amazon Textract ] ──► [ Amazon Comprehend Medical ] ──► Extracts PHI Entities
                            (Extracts Text)            (HIPAA-eligible NLP)

```

1. **Amazon Textract:**
* Standard PDF/Image files se text, tables, aur forms extract karne ke liye specialized AWS service hai.


2. **Amazon Comprehend Medical:**
* Yeh ek HIPAA-eligible Natural Language Processing (NLP) service hai jo medical text se PHI, medical conditions, medications, aur dosages ko automatically detect aur extract kar sakti hai.
* Built-in ML capability hone ki wajah se koi custom algorithm likhne ki zarurat nahi parti, jis se operational overhead zero ho jata hai.



---

### 3. Correct Option Explanation

#### ✅ **Use Amazon Textract to extract the text from the PDF reports. Integrate Amazon Comprehend Medical with the existing Lambda function to identify the PHI from the extracted text.**

* **Why it works:** Amazon Textract document/PDF se raw text nikalta hai, aur Amazon Comprehend Medical bina kisi ML overhead ke extracted text mein se PHI data identify kar leta hai (least operational overhead & HIPAA compliant).

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **Amazon Textract Medical + regular Amazon Comprehend...** | "Amazon Textract Medical" naam ki koi standalone API service nahi hai (Textract hi document extraction karta hai) aur regular Comprehend general text ke liye hai, specialized medical PHI ke liye **Comprehend Medical** required hota hai. |
| **Amazon Textract + custom-built PHI detection algorithm...** | Custom PHI detection algorithm likhna aur maintain karna heavy operational overhead aur development effort create karta hai. |
| **Amazon Transcribe + CloudWatch Logs...** | Amazon Transcribe **speech-to-text** (audio/speech) ke liye hota hai, PDF documents par kaam nahi karta. |

---

### 5. Exam Decision Matrix (AWS Machine Learning & Security Cheat Sheet)

* **Extract Text from PDFs / Images / Scanned Documents:** $\rightarrow$ **Amazon Textract**
* **Extract Protected Health Information (PHI) & Medical Data:** $\rightarrow$ **Amazon Comprehend Medical**
* **Convert Speech / Audio to Text:** $\rightarrow$ **Amazon Transcribe**
* **General Text Entity & Sentiment Analysis:** $\rightarrow$ **Amazon Comprehend**
