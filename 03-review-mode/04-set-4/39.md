39. Question

Category: CSAA – Design Cost-Optimized Architectures

A company conducts performance testing on a large instance MySQL RDS DB instance twice a week. They use Performance Insights to analyze and fine-tune expensive queries. The company needs to reduce its operational expenses in running the tests without compromising the tests’ integrity.

Which of the following is the most cost-effective solution?


- Perform a mysqldump to get a copy of the database on a local machine. Use MySQL Workbench to analyze the queries.
- Stop the database once the test is done and restart it only when necessary.
- Downgrade the database to a smaller instance.
- `Once the testing is completed, take a snapshot of the database and terminate it. Restore the database from the snapshot when necessary.`

Aayein is question ko bhi bilkul aasan aur simple example se samajhte hain:

---

### Question Ki Kahani (Real-World Context)

Ek company hai jo hafte mein **sirf 2 din** apne bade MySQL Database par performance testing karti hai (maslan Tuesday aur Friday ko).

1. **Problem (Masla):**
Database bohot **bada (Large Instance)** hai, jis ki waja se iska bill bohot ziada aata hai. Haalaanke hafte ke baki 5 din yeh database bilkul free/idle pada rehta hai, lekin company ko pure 7 dino ka bill bharna padta hai.
2. **Goal (Maqsad):**
Company ko test ke results kharab kiye bina (bade database ki power retain karte hue) **paise bachane (Cost-Optimize karne)** hain.

---

### In Options Mein Se Kya Sahi Aur Kya Galat Hai?

#### ❌ Option 1: Database ko Chhota (Downgrade) Kar Do

* **Kyun Galat Hai?** Agar aap testing chhote database par karenge, toh test ke results sahi nahi aayenge (Test integrity compromise ho jayegi).

#### ❌ Option 2: Database ko Sirf Stop Kar Do

* **Kyun Galat Hai?** AWS ka ek sakht usool hai: Agar aap RDS Database ko **Stop** karenge, toh **7 dino baad AWS usay khud hi wapis RESTART (ON) kar deta hai**. Phir se bill aana shuru ho jayega!

#### ✅ Option 3: Test Khatam Ho Toh Snapshot (Photo) Lo Aur Delete Kar Do

* **Kyun Sahi Hai?**
1. Test poora hote hi aap poore database ki ek **Snapshot (Backup Copy)** le lein.
2. Database ko **Terminate (Delete)** kar dein. Is se aap ka ghante ke hisaab se aane wala Compute Bill **Zero ($0)** ho jayega!
3. Agle hafte jab dobara test karna ho, us Snapshot se naya database **1-Click mein Wapis Restore** kar lein.



---

### AWS SAA-C03 Exam Rule (Yaad Rakhne Ke Liye)

* Jab bhi koi database **hafte/mahine mein sirf 1-2 baar** use ho raha ho $\rightarrow$ **Snapshot le kar Database Delete/Terminate kar do**, aur zarurat parne par Snapshot se Restore karo. Is se sab se ziada paise bachtay hain!
