40. Question

Category: CSAA – Design High-Performing Architectures

There is a new compliance rule in your company that audits every Windows and Linux EC2 instances each month to view any performance issues. They have more than a hundred EC2 instances running in production, and each must have a logging function that collects various system details regarding that instance. The SysOps team will periodically review these logs and analyze their contents using AWS Analytics tools, and the result will need to be retained in an S3 bucket.

In this scenario, what is the most efficient way to collect and analyze logs from the instances with minimal effort?

- `Install the unified CloudWatch Logs agent in each instance which will automatically collect and push data to CloudWatch Logs. Analyze the log data with CloudWatch Logs Insights.`
- Install AWS SDK in each instance and create a custom daemon script that would collect and push data to CloudWatch Logs periodically. Enable CloudWatch detailed monitoring and use CloudWatch Logs Insights to analyze the log data of all instances.
- Install the AWS Systems Manager Agent (SSM Agent) in each instance which will automatically collect and push data to CloudWatch Logs. Analyze the log data with CloudWatch Logs Insights.
- Install AWS Inspector Agent in each instance which will collect and push data to CloudWatch Logs periodically. Set up a CloudWatch dashboard to properly analyze the log data of all instances.


Is question mein **EC2 Log Collection at Scale**, **Unified CloudWatch Agent**, aur **Log Analysis using CloudWatch Logs Insights** ka architecture concept test ho raha hai.

Aayein requirements aur technical evaluation ko Roman Urdu mein analyze karte hain:

---

### 1. Requirement Breakdown

1. **Scale:** 100+ Windows aur Linux EC2 instances running in production.
2. **Task:** Har instance se system details / performance logs collect karke CloudWatch tak puhanchana.
3. **Log Analysis:** Logs ko review aur analyze karna efficiently using AWS native tools, with minimal operational effort.

---

### 2. Technical Evaluation

```
[ 100+ EC2 Instances (Linux & Windows) ]
                  │
                  ▼ (Unified CloudWatch Agent)
        [ Amazon CloudWatch Logs ]
                  │
                  ▼
   [ CloudWatch Logs Insights (Analysis) ]

```

1. **Unified CloudWatch Logs Agent:**
* Hybrid/Multi-OS (Linux & Windows) instances se OS-level metrics aur system log files ko automatically capture karke **Amazon CloudWatch Logs** par push karta hai.
* Native agent hone ki wajah se koi custom scripts ya daemons likhne ki zaroorat nahi hoti (minimal operational effort).


2. **CloudWatch Logs Insights:**
* Fast, interactive, aur serverless log query service hai jo CloudWatch Logs mein moojood log data ko instantly analyze/search karne ke liye dedicated AWS Analytics tool hai.



---

### 3. Correct Option Explanation

#### ✅ **Install the unified CloudWatch Logs agent in each instance which will automatically collect and push data to CloudWatch Logs. Analyze the log data with CloudWatch Logs Insights.**

* **Why it works:** **Unified CloudWatch Agent** both Windows aur Linux OS ko support karta hai aur automatically logs stream karta hai. **CloudWatch Logs Insights** native analytics tool hai jo in logs ko analyze karta hai without extra custom development.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **AWS SDK + Custom Daemon Script...** | Custom script likhna aur manage karna **high operational effort** create karta hai; native Unified Agent pehle se majood hai. |
| **AWS Systems Manager Agent (SSM Agent)...** | SSM Agent EC2 configuration management aur patch deployment ke liye hota hai; system logs ko CloudWatch tak stream karna SSM agent ka kaam nahi hai. |
| **AWS Inspector Agent...** | AWS Inspector ek **security vulnerability scanner** hai, custom system log collector/analytics tool nahi. |

---

### 5. Exam Decision Matrix (Monitoring & Logging Agents Cheat Sheet)

* **Collect OS Logs & Custom System Metrics (RAM, Disk Space):** $\rightarrow$ **Unified CloudWatch Agent**
* **Manage/Patch EC2 Instances & Run Remote Commands:** $\rightarrow$ **AWS SSM Agent**
* **Security & Vulnerability Assessment Scans:** $\rightarrow$ **Amazon Inspector Agent**
* **Analyze Logs within CloudWatch:** $\rightarrow$ **CloudWatch Logs Insights**
