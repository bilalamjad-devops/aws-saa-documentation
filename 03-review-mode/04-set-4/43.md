43. Question

Category: CSAA – Design Resilient Architectures

A data analytics company, which uses machine learning to collect and analyze consumer data, is using Redshift cluster as their data warehouse. You are instructed to implement a disaster recovery plan for their systems to ensure business continuity even in the event of an AWS region outage.

Which of the following is the best approach to meet this requirement?

- `Enable Cross-Region Snapshots Copy in your Amazon Redshift Cluster.`
- Do nothing because Amazon Redshift is a highly available, fully-managed data warehouse which can withstand an outage of an entire AWS region.
- Create a scheduled job that will automatically take the snapshot of your Redshift Cluster and store it to an S3 bucket. Restore the snapshot in case of an AWS region outage.
- Use Automated snapshots of your Redshift Cluster.

Is question mein **Amazon Redshift Disaster Recovery (DR)**, **Cross-Region Replication**, aur **Regional Resiliency** ka architecture concept test ho raha hai.

Aayein requirements aur options ko Roman Urdu mein analyze karte hain:

---

### 1. Requirement Breakdown

1. **Service:** Amazon Redshift Cluster (Data Warehouse).
2. **Goal:** **Disaster Recovery (DR)** plan implement karna hai taake poora AWS Region down (Region Outage) hone par bhi business continuity maintain rahe.
3. **Constraint:** Single region failures se protect hone ke liye cross-region capability zaroori hai.

---

### 2. Technical Evaluation

```
[ Primary AWS Region (e.g., us-east-1) ]           [ DR AWS Region (e.g., us-west-2) ]
┌──────────────────────────────────────┐          ┌──────────────────────────────────┐
│ Amazon Redshift Cluster              │          │                                  │
│   │                                  │          │                                  │
│   ▼                                  │          │                                  │
│ Automated Cluster Snapshot           │ ────────►│ Copied Snapshot                  │
│                                      │ (Cross-  │ (Can restore cluster instantly   │
│                                      │  Region) │  if primary region goes down)    │
└──────────────────────────────────────┘          └──────────────────────────────────┘

```

1. **Cross-Region Snapshot Copy:**
* Amazon Redshift mein ek built-in feature hota hai jo aap ke Automated ya Manual Snapshots ko automatically doosre **Secondary AWS Region** mein copy kar deta hai.
* Agar Primary Region complete outage ka shikar ho jaye, toh secondary region mein mojood copied snapshot se naya Redshift cluster restore karke reporting/analytics resume ki ja sakti hai.


2. **Redshift Regional Scope:**
* Amazon Redshift ek **Regional Service** hai (cluster specific VPC / Region mein hota hai). Agar poora region down ho jaye, toh cluster accessible nahi rehta jab tak Cross-Region backup mojood na ho.



---

### 3. Correct Option Explanation

#### ✅ **Enable Cross-Region Snapshots Copy in your Amazon Redshift Cluster.**

* **Why it works:** Yeh official AWS native mechanism hai jo Redshift snapshots ko automatically destination region mein replicate karta hai. Regional disaster ki soorat mein secondary region mein snapshot se instantly cluster build ho jata hai.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails |
| --- | --- |
| **Do nothing because Redshift withstands region outage...** | Factually Incorrect. Redshift Single-AZ ya Multi-AZ within a region hota hai, lekin Region-level failure se single region Redshift cluster protect nahi ho sakta. |
| **Scheduled job to take snapshot and store to S3...** | S3 buckets default regional hoti hain. Agar aap local region S3 bucket mein snapshot rakhenge, toh region down hone par S3 data bhi inaccessible ho jayega. Manual custom scripts se operational overhead bhi barhta hai. |
| **Use Automated snapshots...** | Automated snapshots by default **Same Region** mein store hote hain. Regional failure hone par in access nahi kiya ja sakta jab tak Cross-Region copy active na ho. |

---

### 5. Cheat Sheet for AWS Disaster Recovery (SAA-C03)

* **Cross-Region DR for Redshift:** $\rightarrow$ **Enable Cross-Region Snapshot Copy**
* **Cross-Region DR for RDS / Aurora:** $\rightarrow$ **Cross-Region Read Replicas** or **Aurora Global Database**
* **Cross-Region DR for S3:** $\rightarrow$ **S3 Cross-Region Replication (CRR)**
