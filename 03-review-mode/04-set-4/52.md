52. Question

Category: CSAA – Design High-Performing Architectures

A leading IT consulting company has an application which processes a large stream of financial data by an Amazon ECS Cluster then stores the result to a DynamoDB table. You have to design a solution to detect new entries in the DynamoDB table then automatically trigger a Lambda function to run some tests to verify the processed data.

What solution can be easily implemented to alert the Lambda function of new entries while requiring minimal configuration change to your architecture?

- Invoke the Lambda functions using SNS each time that the ECS Cluster successfully processed financial data.
- Use CloudWatch Alarms to trigger the Lambda function whenever a new entry is created in the DynamoDB table.
- Use Systems Manager Automation to detect new entries in the DynamoDB table then automatically invoke the Lambda function for processing.
- `Enable DynamoDB Streams to capture table activity and automatically trigger the Lambda function.`


Is question mein **DynamoDB Change Data Capture (CDC)**, **DynamoDB Streams**, aur **Event-Driven Lambda Architecture** ka concept test ho raha hai.

Aayein requirements aur options ko Roman Urdu mein Step-by-Step analyze karte hain:

---

### 1. Requirement Breakdown

1. **Architecture:** Amazon ECS Cluster data process karta hai aur results **Amazon DynamoDB table** mein store karta hai.
2. **Goal:** DynamoDB table mein jab bhi koi **naya entry/record add ho**, usay detect karke **automatically Lambda function trigger** karna hai jo test verification run kare.
3. **Constraint:** Solution aisa hona chahiye jo **easily implement ho shake aur minimal configuration changes** require kare.

---

### 2. Technical Evaluation

```
[ ECS Cluster ] ──Writes Data──► [ DynamoDB Table ] ──Item Created──► [ DynamoDB Streams ]
                                                                             │
                                                                       Triggers (Event)
                                                                             ▼
                                                                  [ AWS Lambda Function ]
                                                                  (Runs Data Verification)

```

1. **DynamoDB Streams:**
* DynamoDB Streams ek built-in feature hai jo DynamoDB table par hone wale har modifcation (Create, Update, Delete) ka time-ordered sequence/log capture karta hai.
* **Native Lambda Integration:** DynamoDB Streams natively AWS Lambda ke sath integrate ho jata hai. Jab bhi table mein naye items insert honge, DynamoDB Stream automatically event emit kar ke Lambda function ko trigger kar dega.
* **Minimal Configuration:** Is setup ke liye ECS code badalne ki zaroorat nahi parti, bas DynamoDB Streams enable karke Lambda ko Stream ke sath attach (Event Source Mapping) karna hota hai.



---

### 3. Correct Option Explanation

#### ✅ **Enable DynamoDB Streams to capture table activity and automatically trigger the Lambda function.**

* **Why it works:** DynamoDB Streams exact Change Data Capture (CDC) capability provide karta hai jo natively bina kisi extra infrastructure ya code change ke Lambda ko auto-trigger kar deta hai.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails |
| --- | --- |
| **Invoke Lambda using SNS each time ECS processes data...** | Is se ECS application ke code mein major configuration aur architecture change karna padega (ECS application ko SNS publish call add karni padegi), jo "minimal configuration change" rule ko violate karta hai. |
| **Use CloudWatch Alarms to trigger Lambda...** | CloudWatch Alarms aggregate metrics (jaise request count, CPU usage) par chalte hain. Individual item-level database inserts par Lambda trigger nahi kar sakte. |
| **Use Systems Manager Automation...** | Systems Manager Automation administrative/operational tasks (jaise OS patching, EC2 maintenance) ke liye hota hai; database insertion events par real-time Lambda triggering ke liye design nahi hua. |

---

### 5. Cheat Sheet for Database Event Triggers (SAA-C03)

* **Detect new items / updates in DynamoDB & trigger Lambda:** $\rightarrow$ **DynamoDB Streams**
* **Detect S3 object uploads & trigger Lambda:** $\rightarrow$ **S3 Event Notifications**
* **Detect AWS API calls / Resource state changes:** $\rightarrow$ **Amazon EventBridge (CloudWatch Events)**
