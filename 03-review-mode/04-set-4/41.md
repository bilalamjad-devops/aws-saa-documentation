41. Question

Category: CSAA – Design Cost-Optimized Architectures

To save costs, your manager instructed you to analyze and review the setup of your AWS cloud infrastructure. You should also provide an estimate of how much your company will pay for all of the AWS resources that they are using.

In this scenario, which of the following will incur costs? (Select TWO.)

- `EBS Volumes attached to stopped EC2 Instances`
- A stopped On-Demand EC2 Instance
- `A running EC2 Instance`
- Using an Amazon VPC
- Public Data Set

Is question mein **AWS Billing & Pricing Models** (specifically EC2, EBS, VPC, aur Data Transfer) ka basic cost optimization rule test ho raha hai.

Aayein options ko Roman Urdu mein Step-by-Step analyze karte hain:

---

### 1. Requirement Breakdown

* **Goal:** Aisa review karna jahan identify kiya ja sake ke konsay resources active billing incur kar rahe hain aur konsay free/unbilled hain.
* **Question Requirement:** Diye gaye 5 options mein se **DO (TWO)** aisi cheezein select karni hain jinka AWS monthly bill mein cost charge hota hai.

---

### 2. AWS Resource Billing Rules

1. **Running EC2 Instances:** Jab tak EC2 instance `Running` state mein hota hai, per-second/per-minute compute charges continue rehte hain.
2. **EBS Volumes (Attached to Stopped EC2s):** Jab aap EC2 instance ko `Stopped` state mein daalte hain, toh instance ka **Compute Charge $0** ho jata hai. **LEKIN** us instance ke sath jo **EBS Elastic Block Store Volume (Disk Storage)** judi hoti hai, uska storage cost continuously charge hota rehta hai jab tak volume delete na ho.
3. **Amazon VPC:** Amazon VPC create aur configure karna completely **Free** hota hai (charges sirf vpc ke andar chalne wale components jaise NAT Gateways ya VPC Endpoints ke hotay hain).
4. **Public Data Sets:** AWS par hosted public datasets ko access/explore karne ki koi charge nahi hoti jab tak aap unhe calculate/process na karein.

---

### 3. Correct Options Explanation

#### ✅ **EBS Volumes attached to stopped EC2 Instances**

* **Why:** EC2 stop hone se compute billing rukti hai, lekin disk space (EBS storage) data retain kar rahi hoti hai, is liye EBS Storage Rate (per GB-month) hamesha charge hota hai.

#### ✅ **A running EC2 Instance**

* **Why:** Running status par instance hours / seconds ke hisaab se compute capacity ka bill generate karta hai.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Billing Rule |
| --- | --- |
| **A stopped On-Demand EC2 Instance** | **No Cost ($0):** Stopped state mein compute charges bilkul pause ho jaate hain. |
| **Using an Amazon VPC** | **No Cost ($0):** VPC (Virtual Private Cloud) networking boundary create karna bilkul free hai. |
| **Public Data Set** | **No Cost ($0):** AWS ki taraf se host kiye gaye Public Datasets browse/access karne ki hosting fee nahi hoti. |

---

### 5. Exam Decision Matrix (AWS Free vs Charged Resources Cheat Sheet)

* **Running EC2 Instance:** $\rightarrow$ **Charged** (Compute Hours + Attached EBS)
* **Stopped EC2 Instance:** $\rightarrow$ **Compute Free ($0)**, lekin **EBS Storage Charged**
* **Amazon VPC / Subnets / Route Tables:** $\rightarrow$ **100% Free**
* **Inbound Data Transfer (Data coming into AWS):** $\rightarrow$ **100% Free**
