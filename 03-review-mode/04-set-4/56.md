56. Question

Category: CSAA – Design Cost-Optimized Architectures

A web application runs on an Auto Scaling group of Amazon EC2 instances deployed across multiple Availability Zones and is fronted by an Application Load Balancer. To enhance security, an SSL/TLS solution is required, and a certificate has been obtained from a third-party certificate authority (CA).

Which services can the SSL/TLS certificate be securely imported into for use with the application? (Select TWO.)

- A private Amazon S3 bucket with versioning enabled
- `AWS IAM certificate store`
- Use a custom client-side root key (CSE-C) encryption to securely store the SSL/TLS certificate
- `AWS Certificate Manager`
- An Amazon S3 bucket configured with server-side encryption with customer-provided encryption keys (SSE-C)

Is question mein **SSL/TLS Certificates Deployment**, **AWS Certificate Manager (ACM)**, aur **IAM Certificate Store** ka security integration test ho raha hai.

Aayein requirements aur options ko step-by-step analyze karte hain:

---

### 1. Requirement Breakdown

1. **Architecture:** Web app Auto Scaling EC2 instances par chal rahi hai behind an Application Load Balancer (ALB).
2. **Goal:** Third-party Certificate Authority (CA) se liya hua **SSL/TLS Certificate** securely import karna hai taake ALB par HTTPS termination setup ho sake.
3. **Question:** Kis **TWO AWS Services** mein yeh third-party certificate securely import kiya ja sakta hai?

---

### 2. Technical Evaluation

```
[ Third-Party CA Certificate ]
              │
              ├─── Import ───► [ AWS Certificate Manager (ACM) ] ───► Attach to ALB
              │
              └─── Import ───► [ AWS IAM Certificate Store ]     ───► Attach to ALB / CloudFront

```

1. **AWS Certificate Manager (ACM):**
* ACM AWS ki primary service hai for provision, management, aur importing SSL/TLS certificates. External/Third-party CAs ke certificates ko ACM mein **Import** kiya ja sakta hai aur ALBs, CloudFront distributions, ya API Gateways par bind kiya ja sakta hai.


2. **AWS IAM Certificate Store:**
* AWS Certificate Manager ke aane se pehle, IAM ek central store provide karta tha SSL certificates ko upload karne ke liye (`aws iam upload-server-certificate`).
* Although ACM recommended path hai, **IAM Certificate Store abhi bhi supported hai** specifically un regions ke liye jahan ACM support nahi hai ya legacy setups ke liye.


3. **S3 Buckets (Private, SSE-C, etc.):**
* S3 buckets mein raw files/certificates store ho sakti hain, lekin Application Load Balancer (ALB) S3 bucket se directly SSL/TLS certificate decrypt/bind nahi kar sakta HTTPS termination ke liye.



---

### 3. Correct Options Explanation

#### ✅ **AWS Certificate Manager**

* **Why it works:** ACM is the primary and recommended managed service to import, manage, and attach third-party SSL/TLS certificates to ALBs, CloudFront, and API Gateways.

#### ✅ **AWS IAM certificate store**

* **Why it works:** IAM includes a legacy server certificate store designed specifically to hold third-party SSL/TLS certificates for deployment to load balancers and CloudFront when ACM is not used.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails |
| --- | --- |
| **A private Amazon S3 bucket...** | S3 only stores object data as files; it cannot integrate natively with ALB for SSL/TLS handshake/termination. |
| **Use a custom client-side root key...** | CSE-C certificate storage/management service nahi hai. |
| **An Amazon S3 bucket with SSE-C...** | Direct ALB integration support nahi milti SSL termination ke liye. |

---

### 5. Cheat Sheet for SSL/TLS Certificates in AWS (SAA-C03)

* **Primary & Recommended SSL/TLS Management:** $\rightarrow$ **AWS Certificate Manager (ACM)**
* **Legacy / Secondary SSL Import Store:** $\rightarrow$ **AWS IAM Certificate Store**
* **ACM Provisioned Certificates (Free):** Auto-rotate basic Public Certificates generated by AWS ACM.
* **Imported 3rd-Party Certificates:** Must be manually re-imported before expiration (ACM does not auto-rotate 3rd-party certs).
