36. Question

Category: CSAA – Design High-Performing Architectures

An automotive company is working on an autonomous vehicle development and deployment project using AWS. The solution requires High Performance Computing (HPC) in order to collect, store and manage massive amounts of data as well as to support deep learning frameworks. The Linux EC2 instances that will be used should have a lower latency and higher throughput than the TCP transport traditionally used in cloud-based HPC systems. It should also enhance the performance of inter-instance communication and must include an OS-bypass functionality to allow the HPC to communicate directly with the network interface hardware to provide low-latency, reliable transport functionality.

Which of the following is the MOST suitable solution that you should implement to achieve the above requirements?

- `Attach an Elastic Fabric Adapter (EFA) on each Amazon EC2 instance to accelerate High Performance Computing (HPC).`
- Attach an Elastic Network Adapter (ENA) on each Amazon EC2 instance to accelerate High Performance Computing (HPC).
- Attach an Elastic Network Interface (ENI) on each Amazon EC2 instance to accelerate High Performance Computing (HPC).
- Attach a Private Virtual Interface (VIF) on each Amazon EC2 instance to accelerate High Performance Computing (HPC).

Is question mein **High Performance Computing (HPC)**, **Inter-Instance Low-Latency Communication**, aur **OS-Bypass Technology** ka core networking concept test ho raha hai.

Aayein requirements ko Roman Urdu mein analyze karte hain:

---

### 1. Requirement Breakdown

1. **Workload:** High Performance Computing (HPC) aur Deep Learning frameworks ke liye fast inter-instance communication.
2. **Performance Goal:** Traditional TCP se kam latency aur ziada throughput.
3. **Key Architectural Constraint:** Network adapter mein **OS-bypass functionality** honi chahiye jo HPC applications ko EC2 instance ke Operating System kernel ko bypass karke direct network hardware (EFA) se communicate karne de.

---

### 2. Technical Evaluation

```
[ HPC Application (MPI / NCCL) ] 
               │
               ▼ (Bypasses OS Kernel via OS-Bypass)
    [ Elastic Fabric Adapter (EFA) ]
               │
               ▼
[ AWS Ultra-Low Latency Network Fabric ]

```

1. **Elastic Fabric Adapter (EFA):**
* EFA ek specialized **Elastic Network Adapter (ENA)** hai jisme **OS-bypass** capability hoti hai.
* Yeh HPC tools (jaise Message Passing Interface - MPI) aur Deep Learning libraries (jaise NVIDIA Collective Communications Library - NCCL) ko direct underlying network interface hardware se interact karne ki permission deta hai.
* Is se inter-node communication latency bohot drop ho jati hai aur scaling performance maximize ho jati hai.


2. **ENA vs ENI vs EFA:**
* **ENI (Elastic Network Interface):** Basic virtual network card for standard EC2 networking.
* **ENA (Elastic Network Adapter):** High-throughput Enhanced Networking interface (up to 100 Gbps), lekin isme HPC OS-bypass capabilities nahi hoti.
* **EFA (Elastic Fabric Adapter):** ENA ki tamam qualities + **OS-Bypass for HPC/ML**.



---

### 3. Correct Option Explanation

#### ✅ **Attach an Elastic Fabric Adapter (EFA) on each Amazon EC2 instance to accelerate High Performance Computing (HPC).**

* **Why it works:** EFA specifically HPC aur Machine Learning workloads ke liye design kiya gaya hai jahan **OS-bypass** ke zariye ultra-low latency aur reliable transport protocol (SRD - Scalable Reliable Datagram) required hota hai.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **Private Virtual Interface (VIF)** | VIF Direct Connect (DX) lines ke sath private networks ko AWS VPC se jodne ke liye hota hai; EC2 inter-instance OS-bypass adapter nahi hai. |
| **Elastic Network Interface (ENI)** | Standard virtual network card hai jo normal networking handling karta hai, low-latency HPC OS-bypass nahi deta. |
| **Elastic Network Adapter (ENA)** | Enhanced Networking provide karta hai (high throughput/IOPS), lekin isme HPC OS-bypass capability missing hoti hai. |

---

### 5. Exam Decision Matrix (EC2 Network Interfaces Cheat Sheet)

* **Standard EC2 Virtual Network Card:** $\rightarrow$ **ENI (Elastic Network Interface)**
* **High Throughput / Enhanced Networking (Up to 100 Gbps):** $\rightarrow$ **ENA (Elastic Network Adapter)**
* **HPC / Machine Learning / MPI Workloads + OS-Bypass:** $\rightarrow$ **EFA (Elastic Fabric Adapter)**
