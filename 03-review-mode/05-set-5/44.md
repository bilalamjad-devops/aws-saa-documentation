44. Question

Category: CSAA – Design High-Performing Architectures

A company plans to implement a hybrid architecture. A dedicated connection needs to be created from the Amazon Virtual Private Cloud (VPC) to the on-premises network. This connection must provide high bandwidth throughput and a more consistent network experience than Internet-based solutions.

Which of the following can be used to create a private connection between the VPC and the company’s on-premises network?

- `AWS Direct Connect`
- Transit Gateway with equal-cost multipath routing (ECMP)
- AWS Site-to-Site VPN
- Transit VPC

Yeh ek bohot hi important **AWS Exam Distinction** hai. SAA-C03 exam mein dono options distinct scenarios ke liye use hote hain:

---

### Key Comparison Matrix

| Feature | AWS Direct Connect (DX) | Direct Connect + Site-to-Site VPN |
| --- | --- | --- |
| **Primary Goal** | High Bandwidth & Dedicated Private Link | **IPsec Encryption** + High Bandwidth |
| **Encryption in Transit** | **Unencrypted** by default (at IP/Layer 3) | **Encrypted** (IPsec Tunnel over DX) |
| **Public Internet Used?** | No (Purely Private Fiber Link) | No (VPN runs *over* the DX Private VIF) |
| **Latency & Speed** | Consistent, Ultra-Low Latency | Consistent, Low Latency (slight overhead due to IPsec) |

---

### Scenario 1: Standalone AWS Direct Connect (DX)

Kab choose karna hai?

* **High Bandwidth / Heavy Data Transfer:** Jab huge datasets (terabytes/petabytes) corporate data center se AWS mein stream/migrate karne hon.
* **Consistent Network Performance:** Latency fluctuations aur public internet congestion ko avoid karna ho.
* **Cost Reduction:** Large volume data egress (AWS se baahar nikalne wali traffic) ke liye Direct Connect rates Internet egress se bohot saste hote hain.

> **Exam Trigger Keywords:** *"High bandwidth"*, *"Consistent latency"*, *"Bypass public internet"*, *"Dedicated physical connection"*.

---

### Scenario 2: Direct Connect + Site-to-Site VPN (Encrypted DX)

Kab choose karna hai?

* **Strict Security & Compliance Requirements:** Jab HIPAA, PCI-DSS, ya banking standards require karein ke data in-transit **100% IPsec Encrypted** hona chahiye *even over a private fiber line*.
* **Why not DX alone?** Standard Direct Connect traffic ko physically line-tap se protect karta hai lekin packets packet-level par **unencrypted** hotay hain (unless MACsec setup ho jo har jagah supported nahi hota). VPN tunnel add karne se end-to-end IPsec encryption milti hai.

> **Exam Trigger Keywords:** *"Secure AND private connection"*, *"IPsec encryption over dedicated link"*, *"Compliance requires encryption in transit over Direct Connect"*.

---

### Summary Cheat Sheet

* **Private + High Bandwidth:** $\rightarrow$ **AWS Direct Connect**
* **Private + High Bandwidth + IPsec Encrypted:** $\rightarrow$ **Direct Connect + Site-to-Site VPN**
* **Cheap + Fast Setup + Encrypted over Internet:** $\rightarrow$ **AWS Site-to-Site VPN**
