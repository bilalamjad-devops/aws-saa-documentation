51. Question

Category: CSAA – Design High-Performing Architectures

A company runs an application in an AWS Auto Scaling group of Amazon EC2 instances distributed across multiple Availability Zones behind an Application Load Balancer. The operations team regularly applies patches and maintenance to the fleet of EC2 instances using the <code>AWSEC2-PatchLoadBalancerInstance</code> AWS Systems Manager Automation document scheduled through Systems Manager Maintenance Windows.

On several occasions, some instances have been automatically terminated after failing HTTPS health checks in the Application Load Balancer, which results in the loss of ephemeral logs stored locally on the instance. A Solutions Architect must design a solution that ensures application and server logs are collected reliably. The solution must allow root cause analysis based on the logs, even if the Auto Scaling group immediately terminates the instance.

What is the EASIEST way for the Architect to automate the log collection from the EC2 instances?


- `Add a lifecycle hook to your Auto Scaling group to move instances in the Terminating state to the Terminating:Wait state to delay the termination of unhealthy EC2 instances. Configure an Amazon EventBridge rule for the EC2 Instance-terminate Lifecycle Action Auto Scaling Event with an associated AWS Lambda function. Trigger the Amazon CloudWatch agent to push the application logs and then resume the instance termination once all the logs are sent to CloudWatch Logs.`
- Add a lifecycle hook to your Auto Scaling group to move instances in the Terminating state to the Terminating:Wait state to delay the termination of the unhealthy EC2 instances. Configure an Amazon EventBridge rule for the EC2 Instance Terminate Successful Auto Scaling Event with an associated AWS Lambda function. Set up the Systems Manager Run Command service to run a script that collects and uploads the application logs from the instance to an Amazon CloudWatch Logs group. Resume the instance termination once all the logs are sent.
- Add a lifecycle hook to your Auto Scaling group to move instances in the Terminating state to the Terminating:Wait state to delay the termination of the unhealthy EC2 instances. Set up AWS Step Functions to collect the application logs and send them to an Amazon CloudWatch Log group. Configure the solution to resume the instance termination as soon as all the logs were successfully sent to CloudWatch Logs.
- Add a lifecycle hook to your Auto Scaling group to move instances in the Terminating state to the Pending:Wait state to delay the termination of the unhealthy EC2 instances. Configure an Amazon EventBridge rule for the EC2 Instance-terminate Lifecycle Action Auto Scaling Event with an associated AWS Lambda function. Set up a Systems Manager Automation script that collects and uploads the application logs from the instance to an Amazon CloudWatch Logs group. Configure the solution to only resume the instance termination once all the logs were successfully sent.

Aap ne **99% bilkul sahi samjha hai!** Bas choti si detail add kar lein:

1. **ASG + ALB Health Check:**
Jab EC2 instance ALB ke health check par fail hota hai, toh ASG usay fauran marne (terminate karne) nikal padta hai. Aur terminate hote hi local disk ke logs **del (delete)** ho jate hain.
2. **Hum Kya Chahte Hain?**
Hum chahte hain ke *"Bhai, pehle thair (pause) ja! Pehle mere logs CloudWatch par bhej, phir terminate hona!"*
3. **Lifecycle Hook Ka Kaam:**
Hum ASG par **Lifecycle Hook** lagate hain. Yeh Hook instance ko khatam karne ke bajaye **`Terminating:Wait`** state (waiting room) mein daal deta hai.
4. **EventBridge + Lambda Process:**
* Instance waiting room mein gaya $\rightarrow$ **EventBridge** ko pata chala.
* EventBridge ne **Lambda** ko ishara kiya.
* Lambda ne EC2 ke CloudWatch Agent ko bola *"Jaldi se bache hue logs CloudWatch par push kar!"*
* Jab logs CloudWatch par chale gaye, Lambda ne ASG ko bola *"Mera kaam ho gaya, ab instance ko terminate kar do!"*



---

### Key Takeaway for Exam

* **Termination Rrokne / Delay Karne Ke Liye:** $\rightarrow$ Auto Scaling **Lifecycle Hook** (`Terminating:Wait`).
* **Wait State Ko Detect Karne Ke Liye:** $\rightarrow$ **EventBridge Rule** (Jo **`EC2 Instance-terminate Lifecycle Action`** event pakadti hai).
