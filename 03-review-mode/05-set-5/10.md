10. Question

Category: CSAA – Design Cost-Optimized Architectures

A company needs to use Amazon S3 to store irreproducible financial documents. For their quarterly reporting, the files are required to be retrieved after a period of 3 months. There will be some occasions when a surprise audit will be held, which requires access to the archived data that they need to present immediately.

What will you do to satisfy this requirement in a cost-effective way?

- Use Amazon S3 -Intelligent Tiering
- `Use Amazon S3 Standard – Infrequent Access`
- Use Amazon Glacier Deep Archive
- Use Amazon S3 Standard

Is question mein data ki **Irreproducibility (Resilience requirement)**, **Access Pattern (Quarterly / 3 Months)**, aur **Surprise Audit (Immediate / Millisecond Access)** ka combination test ho raha hai.

Aayein requirements aur options ko step-by-step analyze karte hain:

---

### 1. Requirement Breakdown

1. **Data Nature:** Financial documents jo **irreproducible** hain (yaani lost hone par wapis nahi ban sakte). High durability aur multi-AZ resilience zaroori hai.
2. **Planned Access:** Quarterly reporting ke liye har **3 months (90 days)** ke baad retrieve hote hain.
3. **Surprise Audit Requirement:** High-priority requirement yeh hai ke surprise audit ke waqt data **immediately (milliseconds mein)** retrieve ho sake.
4. **Goal:** Sab se **cost-effective** solution select karna jo in saari conditions ko meet kare.

---

### 2. Technical Evaluation

```
[ Upload Financial Documents ] ──► [ Amazon S3 Standard-IA ] 
                                          │
                               (Infrequent Access / Immediate Retrieval)
                                          │
                   ┌──────────────────────┴──────────────────────┐
                   ▼                                             ▼
       [ 3-Month Scheduled Audits ]                  [ Surprise Audits ]
      (Infrequent Access Rates Apply)             (Immediate / Millisecond Access)

```

1. **S3 Standard-IA (Infrequent Access):**
* **Minimum Retention Period:** 30 days.
* **Retrieval Speed:** **Immediate / Millisecond access** (Surprise audit requirement ke liye perfect).
* **Storage Cost:** S3 Standard se kafi sasta (terabytes store karne ke liye cost-effective).
* **Durability:** Multi-AZ (Irreproducible data safe rehta hai).


2. **Why S3 One Zone-IA is NOT selected (Even though it's cheaper):**
* S3 One Zone-IA data ko sirf 1 Availability Zone mein rakhta hai. Agar woh AZ destroy ho jaye, toh **irreproducible data permanently lost** ho jayega.


3. **Why S3 Glacier / Deep Archive is NOT selected:**
* Glacier Flexible Retrieval ya Deep Archive retrieval mein minutes se hours lagte hain (3-5 hours ya 12 hours). Subah surprise audit mein immediate documents pesh karna Glacier se possible nahi ho payega.



---

### 3. Correct Option Explanation

#### ✅ **Use Amazon S3 Standard – Infrequent Access**

* **Why it works:** S3 Standard-IA multi-AZ storage (11 9's durability) deta hai taake irreproducible data secure rahe, quarterly/infrequent access ke liye storage cost reduce karta hai, aur surprise audits ke liye **instant / millisecond retrieval** guarantee karta hai.

---

### 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails |
| --- | --- |
| **Amazon S3 - Intelligent Tiering** | Intelligent-Tiering automatic monitoring fee charge karta hai. Jab access pattern pehle se pata ho (every 3 months + rare surprise audits), toh S3 Standard-IA ziada cost-effective rehta hai. |
| **Amazon Glacier Deep Archive** | Deep Archive ki minimum retrieval time 12 hours hai; surprise audit ke **immediate access** requirement ko fulfill nahi karta. |
| **Amazon S3 Standard** | Storage cost high hoti hai. Jab data 3 months tak touch nahi hona, toh S3 Standard par rakhna unnecessary expensive hai. |

---

### 5. Instant Retrieval vs Glacier Rule (Exam Cheat Sheet)

* **Data needed in Milliseconds + Infrequently Accessed (30+ days):** $\rightarrow$ **S3 Standard-IA**.
* **Data needed in Milliseconds + Single AZ acceptable (Reproducible Data):** $\rightarrow$ **S3 One Zone-IA**.
* **Data needed in 3-12 Hours + Archival Data:** $\rightarrow$ **S3 Glacier Flexible Retrieval**.
* **Data needed in 12-48 Hours + Lowest Storage Cost:** $\rightarrow$ **S3 Glacier Deep Archive**.
