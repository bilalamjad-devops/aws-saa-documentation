13. Question

Category: CSAA – Design High-Performing Architectures

A financial company wants to store its data in Amazon S3 while also keeping frequently accessed data locally on its on-premises server. The company does not have the option to extend its on-premises storage, so it is looking for a durable and scalable storage service to use in AWS.

What is the best solution for this scenario?

- `Use AWS Storage Gateway – Cached Volumes.`
- Use a fleet of Amazon EC2 instances with Amazon EBS volumes to store the commonly used data.
- Use Amazon Glacier.
- Use Amazon ElastiCache with a lazy loading (cache-aside) pattern while storing the primary data in S3.

Is question mein pehle se parha hua concept hi test ho raha hai.

Aayein requirements aur options ko quickly review karte hain:

---

### 1. Requirement Breakdown

1. **Storage Hybrid Setup:** Primary data ko **Amazon S3** mein store karna hai.
2. **Local Access:** Frequently accessed (hot) data ko **on-premises server** par locally cache karke rakhna hai.
3. **Constraint:** Company ke paas **on-premises storage capacity expand karne ka option nahi hai**.

---

### 2. Technical Evaluation

* **AWS Storage Gateway – Cached Volumes:** Saara main data **Amazon S3** mein primary storage ke tor par store karta hai aur local server par sirf **frequently accessed data** ko local cache disk par rakhta hai. Is se on-premises storage hardware expand karne ki zaroorat nahi parhti.
* **EBS / EC2 Fleet:** Local on-premises servers ke liye storage issue resolve nahi karta.
* **Amazon Glacier:** Archival storage hai, local caching aur low-latency access ke liye suitable nahi hai.
* **Amazon ElastiCache:** In-memory caching layer hai jo database queries ke liye use hoti hai, on-premises block/file storage extension ke liye nahi.

---

### 3. Correct Option Explanation

#### ✅ **Use AWS Storage Gateway – Cached Volumes.**

* **Why it works:** Cached Volumes primary data S3 mein store karte hain aur frequently used data local disk cache par rakhte hain, jis se local storage scale kiye bina fast local performance milti hai.
