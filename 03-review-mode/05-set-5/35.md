35. Question

Category: CSAA – Design Secure Architectures

A business plans to deploy an application on EC2 instances within an Amazon VPC and is considering adopting a Network Load Balancer to distribute incoming traffic among the instances. A solutions architect needs to suggest a solution that will enable the security team to inspect traffic entering and exiting their VPC.

Which approach satisfies the requirements?

- Create a firewall at the subnet level using the Amazon Detective service. Inspect the ingress and egress traffic using the VPC Reachability Analyzer.
- Enable Traffic Mirroring on the Network Load Balancer and forward traffic to the instances. Create a traffic mirror filter to inspect the ingress and egress of data that traverses your Amazon VPC.
- `Create a firewall using the AWS Network Firewall service at the VPC level then add custom rule groups for inspecting ingress and egress traffic. Update the necessary VPC route tables.`
- Use the Network Access Analyzer service on the application’s VPC for inspecting ingress and egress traffic. Create a new Network Access Scope to filter and analyze all incoming and outgoing requests.

Is question ka correct answer **Create a firewall using the AWS Network Firewall service at the VPC level then add custom rule groups for inspecting ingress and egress traffic. Update the necessary VPC route tables.** hai.

Aayein scenario breakdown aur elimination ko detail se samajhte hain:

---

### Key Scenario Breakdown

* **Setup:** Application EC2 instances par running hai aur traffic distribute karne ke liye **Network Load Balancer (NLB)** use ho raha hai.
* **Goal:** Security team ko VPC mein aane wale (Ingress) aur jane wale (Egress) poore traffic ko **inspect** (deep packet inspection, filtering, threat detection) karna hai.

---

### Correct Option Explanation

#### ✅ **AWS Network Firewall + VPC Route Tables update**

* **Why it works:**
1. **VPC-Level Security:** **AWS Network Firewall** ek fully managed stateful & stateless firewall service hai jo pure VPC ke border par lagti hai.
2. **Traffic Inspection:** Yeh layer 3 se layer 7 tak deep packet inspection (DPI), domain name filtering, aur intrusion prevention system (IPS) rules provide karti hai taake active ingress/egress traffic ko inspect aur block kiya ja sake.
3. **Routing Configuration:** Traffic ko Network Firewall se guzarne ke liye VPC Route Tables mein firewall endpoint ka route add karna padta hai.



---

### Incorrect Options Breakdown (Elimination)

* ❌ **Amazon Detective:** Investigation service hai jo SecurityHub/GuardDuty logs analyze karke root cause batati hai, live traffic inspection/filtering nahi karti.
* ❌ **Traffic Mirroring on NLB:** Traffic Mirroring **Elastic Network Interfaces (ENI)** par enable hoti hai, direct NLB par nahi. Plus, yeh sirf packet copy (mirroring) karti hai, inline active firewall/inspection solution nahi hai.
* ❌ **Network Access Analyzer:** Network path analysis tool hai jo yeh check karta hai ke network routes/configurations security compliance par hain ya nahi (static analysis), yeh live network traffic ko inspect ya filter nahi karta.

---

### Exam Cheat Sheet for Traffic Inspection

> * **Deep Packet Inspection / Active Firewall for VPC:** **AWS Network Firewall**
> * **Web Application Layer 7 Attack Protection (SQLi, XSS):** **AWS WAF** (ALB, CloudFront, API Gateway par lagta hai, NLB par nahi)
> * **Packet Copy / Auditing:** **VPC Traffic Mirroring** (ENIs par lagta hai)
