37. Question

Category: CSAA – Design High-Performing Architectures

A company needs to accelerate the development of its GraphQL APIs for its new customer service portal. The solution must be serverless to lower the monthly operating cost of the business. Their GraphQL APIs must be accessible via HTTPS and have a custom domain.

What solution should the Solutions Architect implement to meet the above requirements?

- Launch an AWS Elastic Beanstalk environment and use Amazon Route 53 for the custom domain. Configure Domain Name System Security Extensions (DNSSEC) in the Route 53 hosted zone to enable HTTPS communication.
- `Develop the application using the AWS AppSync service and use its built-in custom domain feature. Associate an SSL certificate to the AWS AppSync API using the AWS Certificate Manager (ACM) service to enable HTTPS communication.`
- Host the application in the VMware Cloud on AWS service. Associate a custom domain to the GraphSQL APIs via the AWS Directory Service for Microsoft Active Directory and provide multiple domain controllers to enable HTTPS communication.
- Deploy the GraphQL APIs as Kubernetes pods to AWS Fargate and AWS Outposts using Amazon EKS Anywhere for deployment. Create a custom domain using Amazon CloudFront and enable the Origin Shield feature to allow HTTPS communication to the GraphQL APIs.

Is question ka correct answer **Develop the application using the AWS AppSync service and use its built-in custom domain feature. Associate an SSL certificate to the AWS AppSync API using the AWS Certificate Manager (ACM) service to enable HTTPS communication.** hai.

Aayein point-to-point concept aur elimination ko samajhte hain:

---

### Key Scenario Breakdown

* **Core Requirement:** **GraphQL APIs** ko accelerate aur develop karna hai.
* **Architecture:** Fully **Serverless** solution chahiye taake cost kam rahe aur operational overhead na ho.
* **Access & Security:** Custom domain name ke sath **HTTPS** over SSL enable hona chahiye.

---

### Correct Option Explanation

#### ✅ **AWS AppSync + Custom Domain + AWS Certificate Manager (ACM)**

* **Why it works:**
1. **Built for GraphQL:** **AWS AppSync** AWS ki dedicated fully managed, **serverless GraphQL service** hai.
2. **Custom Domain & HTTPS:** AppSync mein native support hota hai custom domains ke liye. Is ke sath **AWS Certificate Manager (ACM)** se SSL/TLS certificate associate karke HTTPS secure access mil jata hai.
3. **Zero Management:** Serverless hone ki waja se koi server, cluster, ya scaling manage nahi karni padti.



---

### Incorrect Options Breakdown (Elimination)

* ❌ **Elastic Beanstalk:** Beanstalk serverless nahi hai—is ke backend par EC2 instances launch hote hain aur unka management overhead hota hai.
* ❌ **VMware Cloud on AWS:** Yeh hybrid cloud infrastructure ke liye hai, serverless GraphQL APIs ke liye bilkul oversized aur expensive options hai.
* ❌ **AWS Outposts / EKS Anywhere:** Yeh hybrid/on-premises deployments ke liye hote hain aur in mein high operational overhead aur heavy cost hoti hai.

---

> **GraphQL Keyword Trigger:**
