22. Question

Category: CSAA – Design Secure Architectures

An application is hosted on an EC2 instance with multiple EBS Volumes attached and uses Amazon Neptune as its database. To improve data security, you encrypted all of the EBS volumes attached to the instance to protect the confidential data stored in the volumes.

Which of the following statements are true about encrypted Amazon Elastic Block Store volumes? (Select TWO.)

- Only the data in the volume is encrypted and not all the data moving between the volume and the instance.
- The volumes created from the encrypted snapshot are not encrypted.
- `All data moving between the volume and the instance are encrypted.`
- `Snapshots are automatically encrypted.`
- Snapshots are not automatically encrypted.

Haan, bilkul! **Dono waqt data encrypted hota hai.**

EBS encryption do cheezon ko ek sath handle karti hai:

1. **Data-at-Rest (Disk par pada hua data):** Volume ke andar jitna data save hai + us se banne wale **Snapshots**, yeh sab automatic encrypted hote hain.
2. **Data-in-Transit (Raste ka data):** Jab aapka EC2 instance EBS volume par kuch write karta hai ya read karta hai, toh **EC2 aur EBS ke darmayan network par behne wala data bhi completely encrypted hota hai.**

---

### Is ko asaan samajhne ke liye ek simple flowchart dekhein:

```
[ EC2 Instance ] ── ( Encrypted Network Tunnel ) ──► [ EBS Volume ] ──► [ Encrypted Snapshot ]
                         (Data-in-Transit)             (Data-at-Rest)         (Auto Encrypted)

```

> **Exam Tip:** SAA-C03 ke liye bas itna yaad rakhein ke jab aap EBS Encryption ka checkbox ON kar dete hain, toh aapko alag se koi SSL/TLS ya extra encryption script lagane ki zaroorat nahi padti. **Data inside volume, snapshots, and moving data—sab automatic encrypt ho jata hai.**
