39. Question

Category: CSAA – Design Resilient Architectures

A company needs to accelerate the performance of its AI-powered medical diagnostic application by running its machine learning workloads on the edge of telecommunication carriers’ 5G networks. The application must be deployed to a Kubernetes cluster and have role-based access control (RBAC) access to IAM users and roles for cluster authentication.

Which of the following should the Solutions Architect implement to ensure single-digit millisecond latency for the application?


- Launch the application to an Amazon Elastic Kubernetes Service (Amazon EKS) cluster. Configure the Amazon VPC CNI plugin for Kubernetes to manage pod networking in AWS Wavelength Zones. Install the AWS IAM Authenticator for Kubernetes (aws-iam-authenticator) to your cluster.
- Host the application to an Amazon Elastic Kubernetes Service (Amazon EKS) cluster. Set up node groups in AWS Wavelength Zones for the EKS cluster. Attach the EKS connector agent role (AmazonECSConnectorAgentRole) to your cluster and use AWS Control Tower for RBAC access.
- `Launch the application to an Amazon Elastic Kubernetes Service (Amazon EKS) cluster. Create node groups in AWS Wavelength Zones for the EKS cluster via the Wavelength service. Apply the AWS authenticator configuration map (aws-auth ConfigMap) to your cluster.`
- Host the application to an Amazon Elastic Kubernetes Service (Amazon EKS) cluster and run the Kubernetes pods on AWS Fargate. Create node groups in AWS Wavelength Zones for the EKS cluster. Add the EKS pod execution IAM role (AmazonEKSFargatePodExecutionRole) to your cluster and ensure that the Fargate profile has the same IAM role as your Amazon EC2 node groups.



Aap ne bilkul spot-on pakda hai! Real-life infrastructure kaise kaam karta hai, iski wazahat step-by-step parhte hain:

---

### Kya Telecommunications ke andar poora Data Center hota hai?

Nahi, Mumbai (`ap-south-1`) jaisa full-fledged AWS Region **bohot bada Data Center complex** hota hai (jisme hazaron physical servers, multiple Availability Zones, S3, RDS, DynamoDB, wagera sab hota hai).

**AWS Wavelength Zone** poora Region nahi hota. Yeh AWS ki taraf se telecom company ke existing data center ke andar lagaya gaya ek **Mini-Rack / Server Pod** hota hai:

* AWS apne standard EC2 compute aur EBS storage ke racks utha kar direct telecom provider (jaise US mein Verizon, Japan mein KDDI, UK mein Vodafone) ke **Data Center / 5G Edge Switching Center** ke andar install kar deta hai.
* Iska fayda yeh hota hai ke 5G mobile device ka traffic internet par Mumbai ya kisi doosre AWS Region tak jane ke bajaye **telecom company ke Tower/Switch se seedha wahi par paray AWS EC2 server par process ho jata hai**.

---

### Kya Pakistan ya local networks (Ufone, Jazz) mein yeh hain?

* **Pakistan mein filhal AWS Wavelength Zones nahi hain.** AWS ne Wavelength ke liye un countries aur telecom providers ke sath tie-up kiya hai jahan commercial **5G Infrastructure** aur High-Density Edge demand bohot ziada hai (e.g., US, US/Verizon, South Korea/SK Telecom, Japan/KDDI, UK/Vodafone).
* Agar kal ko Pakistan mein 5G rollout fully mature hota hai aur AWS Jazz/Ufone ke sath partner karta hai, tab ja kar local Wavelength Zone ban sakta hai. Currently nearest AWS Region humare paas Mumbai (`ap-south-1`) ya UAE/Bahrain hai.

---

### Key Summary (Mental Picture)

```
[ Full AWS Region ] ──► Huge Data Center (All AWS Services)
        │
[ AWS Wavelength ]  ──► Small AWS EC2/EBS Racks placed INSIDE 5G Telecom Switching Centers

```

Exam ke liye bas yeh yaad rakhna hai: **AWS Wavelength = 5G Edge + Single-Digit Millisecond Latency**.

Ghabranay ki bilkul zaroorat nahi hai! AWS exam mein kuch questions aise aate hain jo do alag-alag advanced services ko mila kar banaye jaate hain.

Is question ko simple alfaz mein **2 parts** mein break karte hain:

---

### Part 1: 5G Network Par Ultra-Fast Speed (Single-Digit Millisecond)

* **Problem:** Application 5G mobile network par chal rahi hai aur doctor/user ko bina kisi lag (single-digit millisecond) ke instant diagnostic report chahiye.
* **AWS Solution = AWS Wavelength:**
* AWS ne 5G telecom companies (jaise Verizon) ke sath partnership ki hui hai.
* AWS Wavelength ka matlab hai ke **AWS ke EC2 servers direct 5G tower / telecom data centers ke andar lage hote hain**.
* Is se traffic ko internet par travel nahi karna padta, seedha 5G tower se server tak chala jata hai — jisse **single-digit millisecond speed** milti hai.



---

### Part 2: EKS (Kubernetes) Mein IAM Users ko Access Dena

* **Problem:** AWS ke IAM Users/Roles ko Kubernetes (EKS) ke andar login/access kaise karwayen?
* **AWS Solution = `aws-auth` ConfigMap:**
* EKS mein ek special configuration file hoti hai jise **`aws-auth ConfigMap`** kehte hain.
* Is file ke andar hum likhte hain ke konsa **AWS IAM Role = Konsa Kubernetes Permission**.



---

### Visual Flow

```
[ 5G Mobile Device ] ──(Ultra Fast)──► [ AWS Wavelength Zone (EKS Node Group) ]
                                                        │

                                                        ▼

```

### Exam Rule (Yaad Rakhne Ke Liye Short Trick)

1. **5G Networks + Edge + Single-Digit Millisecond** $\rightarrow$ Answer hamesha **AWS Wavelength** hoga.
2. **EKS + IAM Authentication / RBAC** $\rightarrow$ Answer mein **`aws-auth` ConfigMap** zaroor hoga.

Dono points mil kar **Option C** ko correct banate hain.
