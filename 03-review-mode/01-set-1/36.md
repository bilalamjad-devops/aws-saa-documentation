36. Question

Category: CSAA – Design Secure Architectures

A company requires all the data stored in the cloud to be encrypted at rest. To easily integrate this with other AWS services, they must have full control over the encryption of the created keys and also the ability to immediately remove the key material from AWS KMS. The solution should also be able to audit the key usage independently of AWS CloudTrail.

Which of the following options will meet this requirement?

- Use AWS Key Management Service to create a KMS key in a custom key store and store the non-extractable key material in Amazon S3.
- Use AWS Key Management Service to create AWS owned Keys and store the non-extractable key material in AWS CloudHSM.
- Use AWS Key Management Service to create AWS managed keys and store the non-extractable key material in AWS CloudHSM.
- `Use AWS Key Management Service to create a KMS key in a custom key store and store the non-extractable key material in AWS CloudHSM.`

### Question 36 — Short revision version

**What is the question asking?**

They want **KMS**, but with **maximum control over the actual key material**.

### Core concept

**CloudHSM** = dedicated hardware where your cryptographic key material is stored.

Normally:

```text
KMS → AWS-managed HSM infrastructure → Key
```

Here they want:

```text
KMS
 ↓
Custom Key Store
 ↓
Your CloudHSM
 ↓
Key material
```

**Custom Key Store = bridge between KMS and CloudHSM.**

### Why is the answer correct?

The requirements are:

* Full control over key material → **CloudHSM**
* Key material stored in dedicated hardware → **CloudHSM**
* Integrate with AWS services through KMS → **KMS + Custom Key Store**
* Independent control/auditing → **CloudHSM**

Therefore:

✅ **KMS Custom Key Store + AWS CloudHSM**

### Why not the others?

* **S3** ❌ → storage, not a cryptographic HSM.
* **AWS-owned key** ❌ → AWS controls it.
* **AWS-managed key** ❌ → AWS manages the key material.

### 🧠 Exam shortcut

> **KMS + dedicated hardware + customer control of key material = Custom Key Store + CloudHSM**

That's the main thing you need to remember.
