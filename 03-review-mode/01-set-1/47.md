47. Question

Category: CSAA – Design High-Performing Architectures

A global IT company with offices around the world has multiple AWS accounts. To improve efficiency and drive costs down, the Chief Information Officer (CIO) wants to set up a solution that centrally manages their AWS resources. This will allow them to procure AWS resources centrally and share resources such as AWS Transit Gateways, AWS License Manager configurations, or Amazon Route 53 Resolver rules across their various accounts.

As the Solutions Architect, which combination of options should you implement in this scenario? (Select TWO.)

- `Use the AWS Resource Access Manager (RAM) service to easily and securely share your resources with your AWS accounts.`
- `Consolidate all of the company's accounts using AWS Organizations.`
- Use AWS Control Tower to easily and securely share your resources with your AWS accounts.
- Use the AWS Identity and Access Management service to set up cross-account access that will easily and securely share your resources with your AWS accounts.
- Consolidate all of the company's accounts using AWS ParallelCluster.

Yes. For this question, don't memorize the long explanation. Just understand **what job each service does**.

## 1. AWS Organizations 🏢

**What is it?**

A service to **manage multiple AWS accounts centrally**.

Think:

> **Organizations = manages accounts**

Example:

```text
              AWS Organizations
                     |
        ┌────────────┼────────────┐
      Dev          Prod         Security
     Account      Account        Account
```

You can:

* Group accounts into OUs
* Apply policies/SCPs
* Centrally manage accounts
* Consolidate billing

**Exam clue:**

> "multiple AWS accounts"
> "centrally manage accounts"
> "consolidate accounts"

➡️ **AWS Organizations**

---

## 2. AWS Resource Access Manager (RAM) 🤝

**What is it?**

RAM lets you **share AWS resources between AWS accounts**.

Example:

```text
Account A
   |
Transit Gateway
   |
  RAM
 /   \
Account B  Account C
```

Instead of creating 3 Transit Gateways, create **one** and share it.

Can share things such as:

* Transit Gateway
* Subnets
* Route 53 Resolver rules
* License Manager configurations

Think:

> **RAM = share resources**

**Exam clue:**

> "share resources between accounts"

➡️ **AWS RAM**

---

## 3. AWS Control Tower 🎛️

**What is it?**

Control Tower helps you **set up and govern a multi-account AWS environment**.

Think:

> **Control Tower = set up + govern your multi-account environment**

It helps with:

* Account creation
* Governance
* Guardrails
* Standardized account setup
* Landing Zone

Very simplified:

```text
Organizations
     ↓
accounts
     ↓
Control Tower
     ↓
standardized + governed environment
```

**Exam clue:**

> "set up a secure multi-account environment"
> "govern accounts"
> "guardrails"
> "landing zone"

➡️ **Control Tower**

---

## 4. IAM 🔐

**What is it?**

IAM controls:

> **Who can access what?**

Example:

```text
Developer
   ↓
IAM
   ↓
Can access S3
Cannot access billing
```

IAM deals with:

* Users
* Roles
* Policies
* Permissions
* Authentication/authorization

You **can** use IAM roles for cross-account access, but if the question is specifically about **sharing AWS resources**, RAM is usually the better answer.

Think:

> **IAM = permissions**

---

## 5. AWS ParallelCluster 🖥️

This one is unrelated to the question.

**ParallelCluster = HPC cluster deployment/management.**

Think:

> **ParallelCluster = High Performance Computing**

Used for workloads such as scientific computing, simulations, research, etc.

It is **not** for:

* Managing AWS accounts ❌
* Sharing resources between accounts ❌
* IAM permissions ❌

---

# 🧠 Memorize these 5 words

| Service               | Think                         |
| --------------------- | ----------------------------- |
| **AWS Organizations** | 🏢 **Manage accounts**        |
| **AWS RAM**           | 🤝 **Share resources**        |
| **Control Tower**     | 🎛️ **Govern/setup accounts** |
| **IAM**               | 🔐 **Manage permissions**     |
| **ParallelCluster**   | 🖥️ **HPC clusters**          |

### Question #47

The question says:

> Multiple AWS accounts → centrally manage them → share resources between them.

So:

**AWS Organizations** → manages/consolidates the accounts ✅

**AWS RAM** → shares resources between those accounts ✅

That's the entire logic.
