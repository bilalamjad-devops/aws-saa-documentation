52. Question

Category: CSAA – Design High-Performing Architectures

A company is looking for a way to analyze the calls between customers and service agents. Each conversation is transcribed, JSON-formatted, and saved to an Amazon S3 bucket. The company’s solutions architect is tasked to design a solution for extracting and visualizing sentiments from the transcribed files.

Which solution meets the requirements while minimizing the amount of operational overhead?

- Analyze the JSON files with Amazon Textract. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using Amazon Managed Grafana.
- `Create an Amazon Comprehend analysis job. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using the OpenSearch Dashboard.`
- Train a custom Natural Language Processing (NLP) model using Amazon SageMaker. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using the OpenSearch Dashboard.
- Create an Amazon Comprehend analysis job. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using Amazon Managed Grafana.


Is question ka correct answer **Create an Amazon Comprehend analysis job. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using the OpenSearch Dashboard.** hai.

---

### Scenario Breakdown & Key Requirements

1. **Input Data:** Transcribed JSON text files Amazon S3 bucket mein saved hain.
2. **Goal:** Transcripts se **sentiments (positive, negative, neutral)** extract karna aur unhe **visualize** karna hai.
3. **Constraint:** Solution aisi honi chahiye jo **operational overhead (manual mehnat/management) kam se kam** rakhe.

---

### Correct Option Explanation

#### ✅ **Amazon Comprehend + OpenSearch Cluster + OpenSearch Dashboards**

* **Amazon Comprehend:** Yeh AWS ki pre-trained Natural Language Processing (NLP) service hai jo text se sentiments, keyphrases, aur entities extract karne ke liye built-in models use karti hai. Is mein koi ML model khud train nahi karna parta (Zero Operational Overhead).
* **Amazon OpenSearch Cluster:** Transcribed JSON text aur extracted sentiment scores ko search-index karne ke liye ideal service hai.
* **OpenSearch Dashboards:** OpenSearch cluster ke sath native, built-in visualization tool ke taur par aata hai. Is ke liye alag se Grafana manage/configure karne ki zaroorat nahi parhti, jis se operational complexity mazeed kam ho jati hai.

---

### Incorrect Options Breakdown (Elimination)

* ❌ **Option 1 (Amazon Textract):** Amazon Textract scanned documents (PDFs, Images) se text aur tables extract karne ke liye hota hai (OCR tool). Phele se transcribed JSON text files ke sentiment analysis ke liye Textract ka koi kaam nahi hai.
* ❌ **Option 3 (Train custom NLP model in SageMaker):** Custom ML model train aur deploy karna boht ziada operational overhead (data labeling, model tuning, management) generate karta hai, jabke Comprehend aisi standard NLP tasks ke liye out-of-the-box available hai.
* ❌ **Option 4 (Visualize using Amazon Managed Grafana):** OpenSearch logs/text analytics visualization ke liye **OpenSearch Dashboards** native tool hai. Grafana zaroori na hone ke bawajood add karne se operational management barhti hai.

---

### SAA-C03 Sentiment Analysis & Text Analytics Cheat Sheet 💡

> * **Text Sentiment Analysis / Keyphrase Extraction:** $\rightarrow$ **Amazon Comprehend** (Pre-trained ML, Low Overhead).
> * **Document OCR / Text Extraction from Images/PDFs:** $\rightarrow$ **Amazon Textract**.
> * **Log & Text Indexing + Native Visualization:** $\rightarrow$ **Amazon OpenSearch + OpenSearch Dashboards**.
