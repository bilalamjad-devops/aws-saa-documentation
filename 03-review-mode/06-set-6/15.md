15. Question

Category: CSAA – Design High-Performing Architectures

A company plans to launch an application that tracks the GPS coordinates of delivery trucks in the country. The coordinates are transmitted from each delivery truck every five seconds. The must be able to process coordinates from multiple consumers in real-time. The aggregated data will be analyzed in a separate reporting application.

Which AWS service should you use for this scenario?

- `Amazon Kinesis`
- Amazon Simple Queue Service
- Amazon AppStream
- Amazon Elastic MapReduce (EMR)


Is question ka correct answer **Amazon Kinesis** hai.

---

### Scenario Breakdown & Key Requirements

1. **Real-time Data Streaming:** Delivery trucks har 5 seconds baad GPS coordinates bhejte hain (continuous stream of data).
2. **Multiple Consumers:** Data ko real-time mein **ek se zyaada consumers (multiple applications)** dwara process karna hai.
3. **Analytics Integration:** Aggregated data ko baad mein reporting application mein analyze karna hai.

---

### Correct Option Explanation

#### ✅ **Amazon Kinesis (Kinesis Data Streams / Data Firehose)**

* **Real-time Streaming Data:** Kinesis specially thousands of sources (IoT devices, GPS trackers, logs) se aane wale real-time streaming data ko capture aur process karne ke liye design kiya gaya hai.
* **Multiple Consumers:** Kinesis Data Streams ka sab se bada faida yeh hai ke ek hi data stream ko **multiple consumer applications concurrently (ek hi waqt mein) read aur process** kar sakti hain (Fan-out architecture).

---

### Incorrect Options Breakdown (Elimination)

* ❌ **Amazon SQS:** SQS ek queue hai jo decoupling ke liye achi hai, lekin is mein jab **ek consumer message read kar leta hai, toh woh delete ho jata hai** (ya hide ho jata hai). Yeh multiple independent real-time consumers ke liye built-in support nahi deta.
* ❌ **Amazon AppStream:** Yeh end-user desktop applications ko stream karne ki cloud service hai (VDI alternative), streaming data capture ke liye nahi.
* ❌ **Amazon Elastic MapReduce (EMR):** Yeh Big Data frameworks (Hadoop, Spark) chalane ke liye managed cluster platform hai. Yeh batch processing / heavy analytics ke liye use hota hai, high-frequency continuous streaming data capture layer ke taur par nahi.

---

### SAA-C03 Exam Rule

> **Streaming & Ingestion Rule:**
> * Continuous Real-time Data + Thousands of Devices + **Multiple Consumers**: $\rightarrow$ **Amazon Kinesis Data Streams**
> * Decoupled Messaging + Single Consumer Processing / Buffering: $\rightarrow$ **Amazon SQS**
