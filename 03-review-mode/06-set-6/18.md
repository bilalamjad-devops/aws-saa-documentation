18. Question

Category: CSAA – Design Secure Architectures

A company created a VPC with a single subnet then launched an On-Demand EC2 instance in that subnet. You have attached an Internet gateway (IGW) to the VPC and verified that the EC2 instance has a public IP. The main route table of the VPC is as shown below:

However, the instance still cannot be reached from the Internet when you tried to connect to it from your computer. Which of the following should be made to the route table to fix this issue?

- `Add this new entry to the route table: 0.0.0.0/0 -> Your Internet Gateway`
- Add the following entry to the route table: 10.0.0.0/27 -> Your Internet Gateway
- Modify the above route table: 10.0.0.0/27 -> Your Internet Gateway
- Add this new entry to the route table: 0.0.0.0/27 -> Your Internet Gateway

Is question ka correct answer **Add this new entry to the route table: 0.0.0.0/0 -> Your Internet Gateway** hai.

---

### Scenario Breakdown & Key Requirements

1. **Setup:** VPC ke andar ek Single Subnet hai jismein ek EC2 Instance deployed hai. Instance ke paas Public IP bhi majood hai aur VPC ke sath **Internet Gateway (IGW)** attached hai.
2. **Issue:** EC2 instance Internet se accessible nahi hai (reach nahi ho raha).
3. **Missing Piece:** Internet traffic ko routing path dene ke liye Route Table mein **Default Route (0.0.0.0/0)** missing hai jo Internet-bound traffic ko IGW ki taraf redirect kare.

---

### Correct Option Explanation

#### ✅ **Add 0.0.0.0/0 $\rightarrow$ Internet Gateway (IGW)**

* **Public Subnet Definition:** Subnet tab hi "Public Subnet" banta hai jab uski Route Table mein **Default Route (`0.0.0.0/0`)** Internet Gateway (`igw-xxxxxx`) ki taraf pointed ho.
* **Outbound/Inbound Internet Routing:** `0.0.0.0/0` (CIDR block representing all IPv4 addresses) add karne se EC2 instance Internet se traffic send aur receive kar sakta hai.

---

### Incorrect Options Breakdown (Elimination)

* ❌ **10.0.0.0/27 $\rightarrow$ IGW:** `10.0.0.0/27` VPC ka internal IP range (local CIDR) hota hai. Isay `local` route ke sath associate rehna chahiye. Isay IGW ki taraf point karna internal networking break kar dega.
* ❌ **Modify 10.0.0.0/27 $\rightarrow$ IGW:** Local VPC route ko modify nahi kiya ja sakta, aur na hi yeh external internet traffic ko route karta hai.
* ❌ **0.0.0.0/27 $\rightarrow$ IGW:** `0.0.0.0/27` ek invalid default internet route format hai. Full internet connectivity ke liye `0.0.0.0/0` zaroori hai.

---

### SAA-C03 VPC Networking Rule 💡

> **Public Subnet Requirements:**
> 1. Attached **Internet Gateway (IGW)** to the VPC.
> 2. Route Table entry: **`0.0.0.0/0` target `igw-xxxxxxxx**`.
> 3. EC2 Instance with a **Public IP / Elastic IP**.
> 4. Security Group & Network ACL allowing inbound/outbound traffic.
