17. Question

Category: CSAA – Design Secure Architectures

A Python application running on VMware Cloud on AWS must connect to an Amazon DynamoDB table called tutorialsdojo. Considering the principle of least privilege access, a solutions architect must form an IAM policy that allows the application to read, write, update and delete items from the tutorialsdojo table only.

---

### Key Requirements & Principle Breakdown

1. **Principle of Least Privilege Access:** Application ko sirf wahi permissions milni chahiyen jo zaroori hain — na zyaada actions, na zyaada resources.
2. **Specific Actions Required:**
* **Read Item:** `dynamodb:GetItem`
* **Write Item:** `dynamodb:PutItem`
* **Update Item:** `dynamodb:UpdateItem`
* **Delete Item:** `dynamodb:DeleteItem`


3. **Specific Resource:** Sirf `tutorialsdojo` naam ki DynamoDB table par scope hona chahiye (`arn:aws:dynamodb:us-east-2:123456789012:table/tutorialsdojo`).

---

### Correct Option Explanation

#### ✅ **Option 1 (Exact Match)**

* **Actions:** Explicitly target karta hai item-level actions ko (`GetItem`, `PutItem`, `UpdateItem`, `DeleteItem`).
* **Resource:** Resource ARN specific table `tutorialsdojo` ko target karta hai.
* Yeh policy **Least Privilege** principle ko 100% fulfill karti hai.

---

### Incorrect Options Breakdown (Elimination)

* ❌ **Option 2 (`dynamodb:Put*`, `dynamodb:Delete*`, etc.):** Wildcard `*` istemal karne se administrative/extra actions (jaise `DeleteTable`, `Purge` etc.) bhi allow ho jatay hain jo Security Compliance ke khilaf hain.
* ❌ **Option 3 (`"Action": "*"`):** DynamoDB ki tamaam administrative actions (jaise table delete karna) allow kar deta hai.
* ❌ **Option 4 (`"Resource": ".../table/*"`):** Target resource mein wildcard `*` istemal karne se account ki **saari DynamoDB tables** ka access mil jata hai, jabki requirement sirf `tutorialsdojo` table ke liye thi.

---

### SAA-C03 Exam Rule 💡

> **IAM Least Privilege Rule:**
> * Never use wildcards (`*`) for **Actions** or **Resources** when specific operations and specific target resources are explicitly listed in the scenario.
