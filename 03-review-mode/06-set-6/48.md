48. Question

Category: CSAA – Design Resilient Architectures

An airline company receives a lot of requests to book flights, update booking details, and flight check-ins. Since these requests flood the customer support teams, the management wants to build a self-service solution that can handle these requests without a human agent. This solution should be text-based, allowing users to type concerns in a chat box while AI analyzes intentions, provides answers, or fulfills predefined actions automatically.

Which of the following options is the recommended solution for the above requirements?

- Create a conversational chatbot using Amazon Comprehend for natural-language processing (NLP). Depending on the user’s intent, invoke AWS Lambda functions that can perform the needed actions.
- Deploy a conversational chatbot using Amazon Rekognition. Define conversation flow for specific user intentions. Create AWS Lambda functions that can be invoked depending on user intentions.
- Work with an AWS Managed Service Provider (MSP) to deploy a conversational chatbot using Amazon Polly for natural-language processing (NLP) and Speech Synthesis Markup Language (SSML) to enhance spoken responses. Integrate AWS Lambda functions as code hooks to perform actions based on user requests.
- `Deploy a conversational chatbot using Amazon Lex. Define conversation flow for specific user intentions. Integrate AWS Lambda functions as code hooks to perform actions based on user requests.`

Is question ka correct answer **Deploy a conversational chatbot using Amazon Lex. Define conversation flow for specific user intentions. Integrate AWS Lambda functions as code hooks to perform actions based on user requests.** hai.

---

### Scenario Breakdown & Key Requirements

1. **Requirement:** Airline customer support ke liye ek automated **conversational chatbot** (text-based self-service chat) banana hai jo user ke text input, intentions (intents) ko samjhe aur flight booking/check-in requests ko fulfillment action mein badle.
2. **Action Fulfillment:** Chatbot intent recognise karke background mein automated tasks (like booking update, DB queries) perform kare.

---

### Correct Option Explanation

#### ✅ **Amazon Lex + AWS Lambda**

* **Amazon Lex:** AWS ki dedicated service hai jo **conversational AI interfaces (chatbots)** banane ke liye use hoti hai (yeh same technology hai jo Amazon Alexa mein use hoti hai).
* **Intent & Slots:** Lex text/voice se user ka **Intent** (e.g., *BookFlight*, *CheckIn*) identify karta hai aur conversation flow define karta hai.
* **AWS Lambda Integration (Code Hooks):** Lex background mein **AWS Lambda functions** ko code hooks ke taur par invoke karta hai taake backend databases mein action perform ho sake (e.g., booking confirmation bhejná ya ticket update karna).

---

### Incorrect Options Breakdown (Elimination)

* ❌ **Amazon Comprehend:** Yeh NLP (Natural Language Processing) text analysis service hai (sentiment analysis, keyphrase extraction ke liye), lekinn yeh chatbot conversation management ya dialogue flow handle nahi karti.
* ❌ **Amazon Rekognition:** Yeh Computer Vision / Image and Video analysis service hai (face recognition, object detection). Iska chatbot se koi talaluq nahi hai.
* ❌ **Amazon Polly:** Yeh **Text-to-Speech (TTS)** service hai jo written text ko realistic spoken audio voice mein convert karti hai. Question mein specific **text-based chat box** maanga gaya hai, na ke speech synthesis.

---

### SAA-C03 AI/ML Services Cheat Sheet 💡

> * **Conversational Chatbot (Voice & Text):** $\rightarrow$ **Amazon Lex**
> * **Text-to-Speech (Read out text as speech):** $\rightarrow$ **Amazon Polly**
> * **Speech-to-Text (Transcribe audio to text):** $\rightarrow$ **Amazon Transcribe**
> * **Text Analysis / Sentiment Detection:** $\rightarrow$ **Amazon Comprehend**
> * **Image & Video Analysis:** $\rightarrow$ **Amazon Rekognition**
