7. Question

Category: CSAA – Design Cost-Optimized Architectures

A company uses Amazon EC2 instances, Amazon RDS, and Amazon S3 to run its application. During a recent review of its infrastructure costs, the company noticed unusual spending patterns.

The company wants to monitor usage costs and send alerts to the appropriate departments when there is unusual spending from its workload.

Which option will meet these requirements?

- `In the AWS Billing and Cost Management console, create a cost monitor using AWS Cost Anomaly Detection.`
- Use AWS Cost Explorer and enable multi-year data at monthly granularity.
- Create a zero spend budget template in AWS Budgets.
- Enable Amazon CloudWatch to monitor costs and detect unusual spending.

Exactly. **Q7 is mainly testing that you know the difference between AWS cost tools.**

### Think of it this way

| Service                    | Main purpose                                           | Example                                |
| -------------------------- | ------------------------------------------------------ | -------------------------------------- |
| **Cost Explorer**          | Analyze **past/current costs**                         | "How much did EC2 cost last month?"    |
| **AWS Budgets**            | Alert when you approach/exceed a **budget you define** | "Alert me when spending reaches $500." |
| **Cost Anomaly Detection** | Detect **unusual/unexpected spending automatically**   | "Why did my S3 bill suddenly spike?"   |
| **CloudWatch**             | Monitor **AWS resources/applications**                 | CPU, memory, latency, errors, etc.     |

### 🔥 The keyword in Q7

The question says:

> **"unusual spending patterns"**

That should immediately trigger:

**AWS Cost Anomaly Detection**

It uses machine learning to establish expected spending patterns and alert you when actual spending becomes anomalous.

So:

**Unusual / unexpected AWS spending → Cost Anomaly Detection**

---

### Don't confuse these two

**Budget:**

> "I have a $1,000 budget. Alert me when I reach $800."

You define the threshold.

**Anomaly Detection:**

> "I normally spend around $300, but suddenly I'm spending $700. Alert me."

AWS detects the unusual pattern.

---

### Your SAA mental shortcut

Remember these four:

> 💰 **Cost Explorer = LOOK** at costs
> 🎯 **Budgets = LIMIT** costs
> 🚨 **Anomaly Detection = UNUSUAL** costs
> 📊 **CloudWatch = MONITOR** resources

This distinction is very useful for SAA questions.
