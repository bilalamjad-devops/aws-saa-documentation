40. Question

Category: CSAA – Design High-Performing Architectures

A company needs to collect gigabytes of data per second from websites and social media feeds to gain insights into its product offerings and continuously improve the user experience. To meet this design requirement, an application is deployed on an Auto Scaling group of Spot instances in Amazon EC2, which processes the data and stores the results to Amazon DynamoDB and Amazon Redshift. The solution should have a built-in enhanced fan-out feature.

Which AWS solution can be used to collect and process large streams of data records in real-time with the LEAST amount of administrative overhead?

- `Amazon Kinesis Data Streams`
- AWS Data Exchange
- AWS Batch
- Amazon Managed Streaming for Apache Kafka (Amazon MSK)

### 🎯 What is being tested?

**Real-time streaming data + enhanced fan-out**

### ✅ Correct answer

**Amazon Kinesis Data Streams**

### 🔑 Key concept

**Kinesis Data Streams** is designed for collecting and processing **large volumes of streaming data in real time**.

It supports **Enhanced Fan-Out**, which lets multiple consumers read from the same stream with dedicated throughput.

```text
Websites / Social Media
        ↓
Kinesis Data Streams
        ↓
EC2 processing
   ↙         ↘
DynamoDB    Redshift
```

### ❌ Others

* **AWS Data Exchange** → exchanging third-party datasets.
* **AWS Batch** → batch processing, not real-time streams.
* **Amazon MSK** → managed Apache Kafka; more operational complexity than Kinesis for this requirement.

### 🔥 Exam shortcut

**Real-time streaming + Enhanced Fan-Out → Kinesis Data Streams.**

**Fan-out** simply means **one source sending data to multiple consumers**.

Example:

```text
          ┌── Consumer A
          │
Kinesis ──┼── Consumer B
          │
          └── Consumer C
```

In this question, the **Kinesis stream** receives the data, and multiple applications/consumers may need to process that same data.

### Enhanced Fan-Out

Normally, consumers share the stream's read capacity.

**Enhanced Fan-Out** gives each consumer **dedicated throughput**, so multiple consumers can read the same stream efficiently without competing as much for bandwidth.

### 🔥 Exam shortcut

**One stream → many consumers = fan-out**
**Dedicated consumer throughput = Enhanced Fan-Out**
