64. Question

Category: CSAA – Design Cost-Optimized Architectures

A company is building an automation tool for generating custom reports on its AWS usage. The company must be able to programmatically access and forecast usage costs on specific services.

Which of the following would meet the requirements with the LEAST amount of operational overhead?

- `Use the AWS Cost Explorer API with pagination to programmatically retrieve the usage cost-related data.`
- Utilize the downloadable AWS Cost Explorer report .csv files to access the cost-related data. Predict usage costs using AWS Budgets.
- Configure AWS Budgets to send usage cost data to the company via Amazon SNS.
- Generate AWS Budgets reports for usage cost data and deliver them via Amazon Simple Queue Service (SQS).

### 🎯 What is being tested?

**Programmatically access + forecast AWS costs.**

### ✅ Correct answer

**Use the AWS Cost Explorer API with pagination to programmatically retrieve usage cost-related data.**

Why?

* **Cost Explorer API** → programmatic access to cost/usage data.
* Can analyze costs by **service**, time period, etc.
* Supports **forecasting**.
* No need to manually download reports or build extra infrastructure.

---

### 🔑 Cost Explorer vs AWS Budgets

|                                   | **Cost Explorer** | **AWS Budgets**         |
| --------------------------------- | ----------------- | ----------------------- |
| Main purpose                      | **Analyze costs** | **Set limits & alerts** |
| Historical cost analysis          | ✅                 | Limited                 |
| Forecast costs                    | ✅                 | ✅                       |
| Programmatic API                  | ✅                 | ✅                       |
| "How much did we spend?"          | ⭐                 | —                       |
| "Alert me if spending exceeds $X" | —                 | ⭐                       |

### 🧠 Simple analogy

**Cost Explorer = Financial dashboard** 📊

> "Show me how much EC2 cost last month and forecast next month."

**AWS Budgets = Financial alarm** 🚨

> "Alert me when my EC2 spending reaches $500."

### 🔥 Exam shortcut

**Analyze / retrieve / forecast costs → Cost Explorer**

**Set budget / threshold / alert → AWS Budgets**
