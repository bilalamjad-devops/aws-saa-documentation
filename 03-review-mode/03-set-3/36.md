36. Question

Category: CSAA – Design High-Performing Architectures

A company has a global online trading platform in which users from all over the world regularly upload terabytes of transactional data to a centralized Amazon S3 bucket.

Which of the following should be used in the present system to improve throughput and ensure consistently fast data transfer to the S3 bucket, regardless of the user’s location?

- AWS Direct Connect
- Use Amazon CloudFront Origin Access Control (OAC)
- FTP
- `S3 Transfer Acceleration`

### 🎯 What is being tested?

**Fast global uploads to S3**

### ✅ Correct answer

**S3 Transfer Acceleration**

### 🔑 Key concept

**S3 Transfer Acceleration** uses AWS edge locations to speed up uploads from users around the world to a centralized S3 bucket.

```text
Users worldwide
      ↓
Nearest AWS Edge Location
      ↓
AWS optimized network
      ↓
Central S3 bucket
```

### ❌ Others

* **Direct Connect** → dedicated connection from on-premises to AWS, not global users.
* **CloudFront OAC** → secures CloudFront → S3 access; not for upload acceleration.
* **FTPS** → protocol, doesn't provide AWS global acceleration.

### 🔥 Exam shortcut

**Global users + large uploads + S3 + improve transfer speed → S3 Transfer Acceleration.**
