6. Question

Category: CSAA – Design High-Performing Architectures

An on-premises server uses an SMB network file share to store application data. The application produces around 50 MB of data per day, but it only needs to access some of it for daily processes. To save on storage costs, the company plans to copy all the application data to AWS. However, the goal is to retain the ability to retrieve data with the same low-latency access as the local file share. The company does not have the capacity to develop the needed tools for this operation. 

Which of the following should the company use?

- `AWS Storage Gateway`
- AWS Virtual Private Network (VPN)
- AWS DataSync
- Amazon FSx for Windows File Server

### 🔑 What is SMB?

**SMB = Server Message Block**

It is a **network file-sharing protocol** that lets computers access files and folders over a network as if they were on a local drive.

Simple example:

**On-premises server** → shares a folder over **SMB** → application accesses files through the network.

Think of it like:

> **SMB = a protocol for sharing files/folders over a network.**

### In this question

The important clue is:

> **“uses an SMB network file share”**

This means the company wants an AWS solution that can **work with the existing file-share style** and maintain **low-latency access**.

That's why **AWS Storage Gateway** becomes relevant.

🔥 **Exam shortcut:**
**SMB = Windows/network file sharing → think file shares, Storage Gateway, FSx for Windows.**
