43. Question

Category: CSAA – Design Secure Architectures

A company uses multiple AWS accounts consolidated under AWS Organizations. The company needs to copy multiple Amazon S3 objects to an S3 bucket in a different owned AWS account. The Solutions Architect must configure permissions to enable this transfer while ensuring the destination account owns the copied objects rather than the source account.

How can the Architect accomplish this requirement?


- Set up cross-origin resource sharing (CORS) in S3 by creating a bucket policy that includes AmazonS3FullAccess and allows an IAM user or role to copy objects from the source bucket in one account to the destination bucket in the other account.
- Enable the Requester Pays feature in the source S3 bucket. The fees would be waived through Consolidated Billing since both AWS accounts are part of the organization.
- `Configure cross-account permissions in S3 by creating an IAM customer-managed policy that allows an IAM user or role to copy objects from the source bucket in one account to the destination bucket in the other account. Then attach the policy to the IAM user or role that you want to use to copy objects between accounts.`
- Connect the two S3 buckets from two different AWS accounts to Amazon WorkDocs. Set up cross-account access to integrate the two S3 buckets. Use the WorkDocs console to copy the objects from one account to the other with modified object ownership assigned to the destination account.

### 🎯 What is being tested?

**Cross-account S3 access + object ownership**

### ✅ Correct answer

**Configure cross-account permissions in S3 by creating an IAM customer-managed policy that allows an IAM user/role to copy objects between the two accounts, then attach it to that user/role.**

### 🔑 Key concept

For cross-account copying:

```text
Account A (Source S3)
        ↓
IAM permissions
        ↓
Account B (Destination S3)
        ↓
Destination owns copied objects
```

The important part is that the **copy operation writes a new object into the destination bucket**, so with modern S3 Object Ownership (`Bucket owner enforced`), the **destination bucket owner owns the new object**.

### ❌ Others

* **CORS** → browser cross-origin access; not cross-account permissions.
* **Requester Pays** → controls who pays transfer/request costs; doesn't solve ownership.
* **WorkDocs** → irrelevant.

### 🔥 Exam shortcut

**S3 cross-account copy → IAM cross-account permissions + destination bucket ownership.**
