31. Question

Category: CSAA – Design High-Performing Architectures

A large telecommunications company needs to run analytics against all combined log files from the Application Load Balancer as part of the regulatory requirements.

Which AWS services can be used together to collect logs and then easily perform log analysis?

- Amazon DynamoDB for storing and EC2 for analyzing the logs.
- `Amazon S3 for storing ELB log files and Amazon Athena for analyzing the log files.`
- Amazon EC2 with EBS volumes for storing and analyzing the log files.
- Amazon S3 for storing the ELB log files and an EC2 instance for analyzing the log files using a custom-built application.

### 🎯 What is being tested?

**S3 + Athena for log analysis**

### ✅ Correct answer

**Amazon S3 for storing ELB log files and Amazon Athena for analyzing the log files.**

### 🔑 Key concept

**ALB logs → S3 → Athena → SQL queries/analysis**

* **S3** = cheap, durable storage for large amounts of logs.
* **Athena** = serverless SQL query service; analyzes data directly in S3.
* No EC2 servers to manage.

### ❌ Others

DynamoDB/EC2 or EC2/EBS/custom application → unnecessary infrastructure and management.

### 🔥 Exam shortcut

**Logs in S3 + analyze/query without servers → Athena.**
