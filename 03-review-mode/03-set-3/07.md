Category: CSAA – Design Resilient Architectures

A company plans to use a durable storage service to store on-premises database backups to the AWS Cloud. To move the backup data, the company needs a service that can store and retrieve objects via standard file storage protocols for quick recovery.

Which of the following options will meet this requirement?

- Use AWS DataSync to directly transfer the backup data to Amazon S3 Glacier.
- `Use the AWS Storage Gateway file gateway to store all the backup data in Amazon S3.`
- Use the AWS Storage Gateway volume gateway to store the backup data and directly access it using Amazon S3 API actions.
- Use Amazon EBS volumes to store all the backup data and attach it to an Amazon EC2 instance.
