25. Question

Category: CSAA – Design Secure Architectures

A company runs a multi-tier web application in the AWS Cloud. The application tier is hosted on Amazon EC2 instances and the backend database is hosted on an Amazon Aurora for MySQL DB cluster. For security compliance, all of the application variables such as DB hostnames, environment settings, product keys, and database passwords must be stored securely with encryption.

Which of the following options is the most cost-effective solution to meet the requirements?

- `Store the values by creating SecureString type parameters in AWS Systems Manager Parameter Store. Use AWS Key Management Service (AWS KMS) for the encryption. Update the application to retrieve the parameter values.`
- Store the values in a file saved in an Amazon S3 bucket. Enable encryption on the S3 bucket. Configure the application to download the file contents when it starts.
- Store the values by creating secrets in AWS Secrets Manager. Use AWS Key Management Service (AWS KMS) for the encryption. Use the BatchGetSecretValue API to retrieve multiple secrets efficiently. Update the application to retrieve the values of the secrets.
- Store the values as key-value pairs in AWS Systems Manager OpsCenter. By default, the key-value pairs will be encrypted at rest. Configure the application to retrieve the variables when it starts.

Is question mein **AWS Secrets Manager vs AWS Systems Manager (SSM) Parameter Store** ka comparison, **Cost-Effectiveness**, aur **Secure Configuration Management** test ho raha hai.

Aayein pehle requirement aur concepts ko step-by-step samajhte hain.

---

## 1. What Is Being Tested Here? (Core Exam Concepts)

Is question mein AWS 2 main secrets/parameter storage services ko compare kar raha hai:

1. **AWS SSM Parameter Store (Standard Parameters):**
* **Cost:** Standard Parameters **completely FREE** hote hain (no storage cost, no API charge for standard throughput).
* **Security:** `SecureString` parameter type supports **AWS KMS** encryption for sensitive data like DB passwords and API keys.
* **Use Case:** Storing environment variables, hostnames, product keys, and credentials cost-effectively.


2. **AWS Secrets Manager:**
* **Cost:** **$0.40 per secret per month** plus API request charges.
* **Key Feature:** Automatic DB password rotation (native integration with Aurora/RDS).
* **Context Rule:** If automatic password rotation is **NOT explicitly requested**, SSM Parameter Store (`SecureString`) is always preferred over Secrets Manager due to lower cost.



---

## 2. Correct Option Explanation

#### ✅ **Store the values by creating SecureString type parameters in AWS Systems Manager Parameter Store. Use AWS Key Management Service (AWS KMS) for the encryption. Update the application to retrieve the parameter values.**

* **Why it works:**
1. **Maximum Cost-Effectiveness:** SSM Parameter Store Standard Parameters are completely free to store, making it the most cost-effective option available.
2. **Security Compliance:** `SecureString` encrypts values at rest using AWS KMS keys.
3. **Meets All Requirements:** Easily holds DB hostnames, env settings, and DB passwords securely without adding per-secret monthly fees.



---

## 3. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **AWS Secrets Manager (`BatchGetSecretValue`)** | **Higher Cost:** Secrets Manager costs $0.40/secret/month. Question explicitly asks for the **most cost-effective** solution, and automatic password rotation wasn't requested. |
| **Amazon S3 Bucket with Encryption** | Unnecessary operational overhead. S3 isn't a dedicated key-value/parameter management store for application runtime configuration parameters. |
| **AWS Systems Manager OpsCenter** | **Wrong Service:** OpsCenter operational issues (ITIL tickets / operational work items) track karne ke liye hota hai, application configuration parameter storage ke liye nahi. |

---

## 4. Exam Decision Matrix (Secrets vs Parameters Cheat Sheet)

* **Store config, keys, passwords + Most Cost-Effective (FREE):** $\rightarrow$ **SSM Parameter Store (`SecureString`)**
* **Store DB credentials + Automatic Password Rotation Required:** $\rightarrow$ **AWS Secrets Manager**
* **Cross-Account Secret Sharing:** $\rightarrow$ **AWS Secrets Manager**
