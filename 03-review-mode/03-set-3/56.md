56. Question

Category: CSAA – Design High-Performing Architectures

A large financial firm in the country has an AWS environment that contains several Reserved EC2 instances hosting a web application that has been decommissioned last week. To save costs, you need to stop incurring charges for the Reserved instances as soon as possible.

What cost-effective steps will you take in this circumstance? (Select TWO.)

- Go to the Amazon.com online shopping website and sell the Reserved instances.
- `Terminate the Reserved instances as soon as possible to avoid getting billed at the on-demand price when it expires.`
- `Go to the AWS Reserved Instance Marketplace and sell the Reserved instances.`
- Contact AWS to cancel your AWS subscription.
- Stop the Reserved instances as soon as possible.

Is question ke options aur exact wording mein ek choti si **AWS Exam Trick** chupi hui hai.

Aayein dekhte hain ke **"Terminate"** aur **"Stop"** wali options mein se konsa combination sahi banta hai:

---

### 1. Correct Pair Analysis

Question mein **TWO options** select karni hain:

1. **Go to the AWS Reserved Instance Marketplace and sell the Reserved instances.**
* Yeh 100% correct primary step hai kyunke unused RI ki cost recover karne ka wahid tareeka Marketplace hai.


2. **Terminate the Reserved instances as soon as possible to avoid getting billed at the on-demand price when it expires.**
* **Reasoning:** Jab aap kisi EC2 instance ko RI ke zariye chala rahe hote hain aur woh RI contract **expire** ho jata hai, toh AWS us instance ko automatically **On-Demand rate** par charge karna shuru kar deta hai!
* Is liye, decommissioned app ke EC2 instance ko **Terminate** kar dena zaroori hai taake jab RI period khatam ho, toh ghalti se bhi On-Demand billing shuru na ho jaye.



---

### 2. "Stop" vs "Terminate" Breakdown

* **Stop vs Terminate:** Agar aap instance ko sirf **Stop** karke rakhenge, toh jab tak RI active hai tab tak toh koi extra charge nahi hoga, lekin jaise hi RI expire hoga, stopped instance se jude EBS volumes vagaira ki cost chalti rahegi. Complete cleanup ke liye instance ko **Terminate** karna parta hai.

---

### Summary (Sahi Selected Options)

* ✅ **Go to the AWS Reserved Instance Marketplace and sell the Reserved instances.** (To recover contract cost)
* ✅ **Terminate the Reserved instances as soon as possible to avoid getting billed at the on-demand price when it expires.** (To prevent future On-Demand charges after RI expiration)

Aap ka doubt bilkul sahi tha! Terminate karne se future On-Demand surprise billing avoid ho jati hai.

Aap ne **100% sahi pakda hai!** 🎯

Bilkul sahi samjhe aap:

1. **Stop karne ka nuksan:** Agar aap EC2 instance ko sirf **Stop** karte hain, toh compute (CPU/RAM) ka bill toh ruk jata hai, lekin us instance ke sath jo **EBS volumes (storage)**, **Elastic IPs**, ya **Snapshots** jude hote hain, AWS un ka monthly storage bill **lagatar charge karta rehta hai**.
2. **Terminate karne ka fayda:** Jab aap instance ko **Terminate** kar dete hain, toh woh EC2 instance destroy ho jata hai aur us se attach Root EBS volumes bhi delete ho jate hain. Is se EBS storage cost bhi zero ho jati hai aur aage chal kar jab RI expire ho, toh koi accidental **On-Demand compute charge** bhi nahi lagta.

Isi liye **Terminate** karna + **AWS Reserved Instance Marketplace par RI sell karna** sab se cost-effective combination hai!
