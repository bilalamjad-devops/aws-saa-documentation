30. Question

Category: CSAA – Design Resilient Architectures

A company is using Amazon VPC that has a CIDR block of 10.31.0.0/27 that is connected to the on-premises data center. There was a requirement to create a Lambda function that will process massive amounts of cryptocurrency transactions every minute and then store the results to EFS. After setting up the serverless architecture and connecting the Lambda function to the VPC, the Solutions Architect noticed an increase in invocation errors with EC2 error types such as EC2ThrottledException at certain times of the day.

Which of the following are the possible causes of this issue? (Select TWO.)

- Your VPC does not have a NAT gateway.
- The associated security group of your function does not allow outbound connections.
- `Your Lambda function exceeds the VPC quota for Elastic Network Interfaces (ENIs) or available IP addresses in the subnet.`
- `The Lambda function is placed in a VPC subnet with limited IP address capacity.`
- The attached IAM execution role of your function does not have the necessary permissions to access the resources of your VPC.

Is question mein **AWS Lambda in VPC Networking**, **Subnet IP Address Capacity**, aur **ENI / IP Limits** ka concept test ho raha hai.

Aayein pehle question ke technical numbers aur setup ko break down karte hain.

---

## 1. Question Requirements & Setup Breakdown

1. **VPC CIDR Block:** `10.31.0.0/27`
* `/27` Subnet/VPC mein total **32 IP addresses** hote hain.
* AWS hamesha har subnet mein **5 IP addresses reserve** karta hai (Network address, Router, DNS, Future use, Broadcast address).
* Total usable IPs = $32 - 5 = \mathbf{27\text{ usable IP addresses}}$.


2. **Workload:** Lambda function har minute **massive volume of cryptocurrency transactions** process karti hai.
3. **Problem:** Lambda High traffic spikes par scale hoti hai, lekin peak times par `EC2ThrottledException` / invocation errors aate hain.

---

## 2. Technical Concept: Lambda in a VPC

Jab aap AWS Lambda ko VPC se connect karte hain (EFS ya internal VPC resources access karne ke liye):

* Lambda VPC ke andar communicate karne ke liye **Hyperplane ENIs (Elastic Network Interfaces)** aur **Private Subnet IP addresses** allocate karti hai.
* Agar aap ki Lambda concurrency scale karti hai aur subnet mein **IP addresses khatam (exhaust)** ho jayein ya **VPC/ENI service quota limit reach** ho jaye, toh Lambda naye execution environments ke liye ENIs/IPs attach nahi kar pati.
* Result: AWS Lambda **`EC2ThrottledException`** error fekti hai kyunke EC2/VPC network interface create ya attach karne ke liye IP addresses available nahi hote.

---

## 3. Correct Options Explanation (Select TWO)

#### ✅ **The Lambda function is placed in a VPC subnet with limited IP address capacity.**

* **Why it works:** Total Usable IPs = 27 (jo ke massively scaling Lambda function ke liye bohot chhota subnet hai). High transaction load par IP addresses exhaust ho jate hain, jis se `EC2ThrottledException` error aata hai.

#### ✅ **Your Lambda function exceeds the VPC quota for Elastic Network Interfaces (ENIs) or available IP addresses in the subnet.**

* **Why it works:** Lambda functions scale hone par ENIs aur Subnet IPs require karti hain. Exceeding account/VPC ENI quotas or subnet IP capacity explicitly causes `EC2ThrottledException` during invocation bursts.

---

## 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **Your VPC does not have a NAT gateway.** | NAT Gateway Internet access ke liye zaroori hota hai, par missing NAT Gateway se `EC2ThrottledException` (IP/ENI limit error) nahi balki connection timeout error aata hai. |
| **Associated security group does not allow outbound connections.** | Security Group rule issues se traffic drop/timeout hoti hai, `EC2ThrottledException` trigger nahi hota. |
| **IAM execution role missing permissions...** | Missing permissions (`AWSLambdaVPCAccessExecutionRole`) se `AccessDeniedException` ya initialization failure hoti hai, throttling limit error nahi. |

---

## 5. Exam Decision Matrix (Lambda in VPC Cheat Sheet)

* **`EC2ThrottledException` in Lambda VPC:** $\rightarrow$ **Subnet IP exhaustion OR ENI Quota limit reached**
* **Lambda VPC Required IAM Role Policy:** $\rightarrow$ **`AWSLambdaVPCAccessExecutionRole`**
* **AWS Reserved IPs per Subnet:** $\rightarrow$ **5 IPs (Always subtract 5 from total $2^{(32-\text{prefix})}$)**

13-September-2026

### 🎯 What is being tested?

**Lambda + VPC IP/ENI limits**

### ✅ Correct answers

**1. Lambda function exceeds the VPC quota for ENIs or available IP addresses in the subnet.**

**2. Lambda function is placed in a VPC subnet with limited IP address capacity.**

### 🔑 Key concept

When Lambda runs inside a VPC, it needs **ENIs/IP addresses** in the selected subnets.

Here the VPC is only **`10.31.0.0/27`** → a small CIDR with limited IP addresses.

Massive transactions → many Lambda invocations → potentially more ENIs/IP usage → **IP/ENI exhaustion → invocation errors/throttling**.

### ❌ Others

* **No NAT Gateway** → only an issue if Lambda needs outbound internet access.
* **SG outbound** → would cause connectivity issues, not this quota/throttling scenario.
* **IAM role** → permissions to AWS resources, not VPC IP capacity.

### 🔥 Exam shortcut

**Lambda + VPC + massive/concurrent invocations + EC2ThrottledException → think ENI/IP address limits.**
