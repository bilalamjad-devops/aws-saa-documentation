34. Question

Category: CSAA – Design High-Performing Architectures

A web-based application must extract specific data from a large CSV file stored in an Amazon S3 bucket. The application requires filtering or transforming the data dynamically before returning it, ensuring that only the needed data is returned without downloading the entire object.

Which of the following actions should be implemented to achieve this?

- Use S3 Object Lambda with a Lambda function that processes the data based on the bucket's name and object tags.
- `Use S3 Object Lambda with a Lambda function that processes the data based on the bucket's name and object's key.`
- Use S3 Object Lambda with a Lambda function that processes the data based on the bucket’s name.
- Use S3 Object Lambda with a Lambda function that processes the data based on the bucket's name and object's metadata.

## 1. Question Ka Matlab (Simple Words)

* **Requirement:** Ek web application ko Amazon S3 mein pari hui ek bari CSV file se specific data extract/filter karna hai.
* **Goal:** Poori file download kiye bina, application ko data **on-the-fly (dynamically)** transform karke sirf required filtered data hi return karna hai.
* **Tool:** Is kaam ke liye **S3 Object Lambda** use hota hai, jo S3 `GetObject` request ke darmiyan AWS Lambda function execute karta hai.

---

## 2. Core AWS Technical Concept: S3 Object Lambda Context

Jab koi application S3 Object Lambda access point par `GetObject` ki request bhejti hai, toh AWS Lambda function ko ek payload event milta hai.

Lambda function ko S3 se original file fetch karne ke liye do primary identifiers ki zaroorat hoti hai:

1. **Bucket Name:** File kis S3 bucket mein pari hai.
2. **Object Key:** Target CSV file ka exact path/filename kya hai (e.g., `data/2026/financials.csv`).

Tags, metadata, ya sirf bucket name akela specific object ko uniquely identify nahi kar sakta. Lambda function **Bucket Name** aur **Object Key** ka use karke original CSV fetch karta hai, usay process/filter karta hai, aur app ko response bhejta hai.

---

## 3. Correct Option Explanation

#### ✅ **Use S3 Object Lambda with a Lambda function that processes the data based on the bucket's name and object's key.**

* **Why it works:** S3 Object Lambda function ko exact target file par dynamic transformation run karne ke liye **Bucket Name** aur **Object Key** dono ki exact combination zaroorat hoti hai.

---

## 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **...based on bucket's name and object tags** | Object tags filtering logic ke liye metadata ho sakte hain, par object ka exact source identity path (Object Key) replace nahi kar sakte. |
| **...based on the bucket's name** | Incomplete context. Bucket ke andar hazaron files ho sakti hain; sirf bucket name se Lambda ko pata nahi chalega ke kaunsi file transform karni hai. |
| **...based on bucket's name and object's metadata** | Custom headers/metadata file fetch karne ka primary identifier nahi hote. Exact path ke liye **Object Key** zaroori hai. |

---

## 5. Exam Decision Matrix (S3 Data Filtering Cheat Sheet)

* **Transform / Filter S3 data on-the-fly with custom code:** $\rightarrow$ **S3 Object Lambda (Bucket Name + Object Key context)**
* **SQL Querying directly inside CSV/JSON in S3 without Lambda:** $\rightarrow$ **S3 Select**
* **Serverless Data Analytics across millions of files:** $\rightarrow$ **Amazon Athena**

### ✅ Correct answer

### 🔑 Key concept

**S3 Object Lambda** lets you modify/filter S3 data **as it is being retrieved**, so the application doesn't need to download the entire object.

The Lambda function receives information including:

* **Bucket name**
* **Object key** (which identifies the object)

Example:

```text
App → S3 Object Lambda → Lambda → S3 object
                         ↓
                  Filter/transform
                         ↓
                    Needed data
```

### 🔥 Exam shortcut

**S3 object + dynamically filter/transform before returning → S3 Object Lambda.**

And remember:

**Bucket + Object Key = identifies the S3 object.**
