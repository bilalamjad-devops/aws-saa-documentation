35. Question

Category: CSAA – Design High-Performing Architectures

A data analytics company is setting up an innovative checkout-free grocery store. The Solutions Architect developed a real-time monitoring application that uses smart sensors to collect the items that the customers are getting from the grocery’s refrigerators and shelves, then automatically deduct those items from customer accounts. The company wants to analyze the items that are frequently being bought and store the results in Amazon S3 for durable storage to determine the purchase behavior of its customers.

Which of the following must be used to easily capture, transform, and load streaming data into S3, Amazon OpenSearch Service, and Splunk?

- `Amazon Data Firehose`
- Amazon DynamoDB Streams
- Amazon Redshift
- Amazon SQS

Is question mein **Streaming Data Ingestion & Delivery (ETL Pipeline)** ka core concept test ho raha hai.

Aayein requirement ko Roman Urdu mein simple steps mein samajhte hain.

---

## 1. Question Ka Matlab (Simple Words)

* **Use Case:** Ek checkout-free grocery store mein smart sensors real-time streaming data generate kar rahe hain.
* **Requirement:** Is streaming data ko effortlessly **capture**, **transform** (convert/format), aur **load/deliver** karna hai Amazon S3, Amazon OpenSearch Service, aur Splunk par analytics/storage ke liye.
* **Goal:** Aisa tool choose karna hai jo direct streaming data ko in multiple destinations par load karne ka mechanism provide karta hai.

---

## 2. Core AWS Technical Concept: Amazon Data Firehose

**Amazon Data Firehose** (pehle *Amazon Kinesis Data Firehose* ke naam se jana jata tha) ek fully managed ETL service hai jo real-time streaming data ko load karne ke liye design ki gayi hai:

* **Automated Scaling & Management:** Is mein koi infrastructure manage nahi karna padta (serverless).
* **Built-in Transformations:** Data ko batch, compress (GZIP/Snappy), aur format convert (Parquet/ORC via AWS Lambda) kar ke destination par bhejta hai.
* **Native Destinations:** Amazon S3, Amazon Redshift, Amazon OpenSearch Service, Splunk, aur Snowflake jaise endpoints par direct load karta hai.

---

## 3. Correct Option Explanation

#### ✅ **Amazon Data Firehose**

* **Why it works:** Amazon Data Firehose streaming data ko captue aur transform karke directly **Amazon S3**, **Amazon OpenSearch Service**, aur **Splunk** par delivering karne ke liye exact native AWS service hai.

---

## 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **Amazon DynamoDB Streams** | Database tables mein hone wali CRUD operations ka change log event record karta hai. External generic sensors se direct streaming data capture and delivery to Splunk/OpenSearch ke liye use nahi hota. |
| **Amazon Redshift** | SQL Data Warehouse solution hai analytical queries run karne ke liye. Data ingestion engine ya streaming loader tool nahi hai. |
| **Amazon SQS** | Distributed Decoupling Message Queue system hai. Streaming data transform aur automatic S3/OpenSearch/Splunk sync capability isn't built natively. |

---

## 5. Exam Decision Matrix (Streaming Analytics Cheat Sheet)

* **Load streaming data into S3 / OpenSearch / Splunk / Redshift (Zero Management):** $\rightarrow$ **Amazon Data Firehose**
* **Real-time custom processing / multi-consumer stream (Replay capability):** $\rightarrow$ **Amazon Kinesis Data Streams**
* **SQL Querying directly on streaming data in motion:** $\rightarrow$ **Amazon Managed Service for Apache Flink**
