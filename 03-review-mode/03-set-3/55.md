55. Question

Category: CSAA – Design High-Performing Architectures

A solutions architect is designing an infrastructure for a serverless application. The application is packaged as a Docker image stored in Amazon Elastic Container Registry (Amazon ECR) and must be deployed on a fully managed serverless compute service. Additionally, the application requires 5 GB of ephemeral storage for temporary data processing.

Which deployment option meets these requirements?

- `Deploy the application in an AWS Lambda function with Container image support. Set the function’s storage to 5 GB.`
- Deploy the application in an AWS Lambda function with Container image support. Attach an Amazon Elastic File System (Amazon EFS) volume to the function.
- Deploy the application Amazon ECS cluster with Amazon EC2 worker nodes and attach a 5 GB Amazon EBS volume.
- Deploy the application to an Amazon ECS cluster that uses AWS Fargate tasks.

Is question mein **Serverless Container Deployment** aur **Lambda Ephemeral Storage (`/tmp`)** ka core concept test ho raha hai.

Aayein requirements ko Roman Urdu mein simple steps mein analyze karte hain.

---

## 1. Requirement Breakdown

1. **Packaging:** Application **Docker image** ke roop mein Amazon ECR mein stored hai.
2. **Compute Target:** Application ko **fully managed serverless** compute service par deploy karna hai (No EC2 instance management).
3. **Storage:** Temporary data processing ke liye **5 GB ephemeral storage** ki zaroorat hai.

---

## 2. Core AWS Technical Concept: AWS Lambda Container Image & Ephemeral Storage (`/tmp`)

* **Container Image Support:** AWS Lambda container images (up to 10 GB size) ko directly deploy karne support karta hai.
* **Ephemeral Storage Configuration:** AWS Lambda functions mein ephemeral storage (`/tmp` directory) ko **512 MB se 10,240 MB (10 GB)** tak scaling options milti hain. Is case mein 5 GB `/tmp` storage directly configure ki ja sakti hai without any external file system.

---

## 3. Correct Option Explanation

#### ✅ **Deploy the application in an AWS Lambda function with Container image support. Set the function’s storage to 5 GB.**

* **Why it works:** AWS Lambda fully managed serverless hai, ECR se Docker container images directly support karta hai, aur built-in ephemeral storage (`/tmp`) ko 5 GB tak scale karne ki option deta hai (least operational overhead).

---

## 4. Incorrect Options Breakdown (Elimination Strategy)

| Option | Why It Fails the Exam Requirement |
| --- | --- |
| **...Attach an Amazon EFS volume** | Over-engineering. EFS persistent network storage provide karta hai. Ephemeral (temporary) storage ke liye built-in 5 GB `/tmp` configuration hi sufficient hai. |
| **...ECS cluster with Amazon EC2 worker nodes** | Fails the **serverless** requirement (EC2 worker nodes manage aur patch karne padte hain). |
| **...ECS cluster that uses AWS Fargate tasks** | Fargate serverless hai, par question mein explicit 5 GB ephemeral storage request ki gayi hai jo Lambda built-in `/tmp` configuration ke sath exact match karti hai. |

---

## 5. Exam Decision Matrix (Serverless Compute Cheat Sheet)

* **Serverless Function + Container Image + Up to 10 GB `/tmp` Storage:** $\rightarrow$ **AWS Lambda Container Support**
* **Long-running Serverless Containers (Microservices/Web apps):** $\rightarrow$ **Amazon ECS with AWS Fargate**
* **Persistent Shared Storage for Lambda:** $\rightarrow$ **AWS Lambda + Amazon EFS**
