8. Question

Category: CSAA – Design Secure Architectures

A web application is hosted on an EC2 instance that processes sensitive financial information. The EC2 instance is launched in a private subnet, and all data is stored in an Amazon S3 bucket. Users access financial information over the Internet through pre-signed URLs generated by the web application. The company’s security team is concerned that internet connectivity to Amazon S3 poses a security risk.

In this scenario, what will you do to resolve this security vulnerability in the most cost-effective manner?

- Change the web architecture to access the financial data hosted in your S3 bucket by creating a custom VPC endpoint service.
- Change the web architecture to access the financial data in S3 through an interface VPC endpoint, which is powered by AWS PrivateLink.
- Change the web architecture to access the financial data in your S3 bucket through a VPN connection.
- `Change the web architecture to access the financial data through a Gateway VPC Endpoint.`


Excellent question. This is actually testing **one specific concept**:

> **Gateway Endpoint vs Interface Endpoint**

Once you know this, the question becomes easy.

---

# Step 1: Understand the architecture

```text
Users
   │
Internet
   │
EC2 (Private Subnet)
   │
   │ Reads/Writes
   ▼
Amazon S3
```

Notice something:

The **users** are on the Internet.

That is perfectly fine.

The problem is **NOT** users.

The problem is **EC2 → S3 communication**.

---

# What does the security team want?

They say:

> Internet connectivity to S3 is a security risk.

They want

```text
EC2  ------------>  S3
```

without using the Internet.

---

# Solution

Create a

✅ **Gateway VPC Endpoint**

Then traffic becomes

```text
EC2

↓

Route Table

↓

Gateway Endpoint

↓

Amazon S3
```

Traffic never leaves AWS's private backbone.

No Internet.

No NAT Gateway.

No Internet Gateway.

---

# Why not VPN?

A VPN looks like this.

```text
On-Prem

↓

Internet (Encrypted)

↓

AWS
```

A VPN is encrypted,

**but it still travels across the public Internet.**

The question specifically wants to avoid Internet connectivity.

So VPN is wrong.

---

# Why not Interface Endpoint?

Here is where AWS exams try to trick you.

There are **two endpoint types.**

---

## Gateway Endpoint

Supports only:

* ✅ S3
* ✅ DynamoDB

Benefits:

* FREE
* Route table entry
* Very common in exams

---

## Interface Endpoint (PrivateLink)

Supports:

* SNS
* SQS
* CloudWatch
* KMS
* Secrets Manager
* Lambda
* hundreds of AWS services

Benefits:

* Private IP (ENI)
* Uses AWS PrivateLink

BUT

It costs money.

---

# Since the question says

> **most cost-effective**

Gateway Endpoint wins.

---

# Memory Trick

Think of it like this.

## Gateway Endpoint

Only knows two friends.

```text
Gateway Endpoint

↓

S3

↓

DynamoDB
```

Nothing else.

---

## Interface Endpoint

Knows everybody.

```text
SNS

SQS

Secrets Manager

CloudWatch

KMS

Lambda

API Gateway

...

Nearly every AWS service
```

---

# Exam Shortcut

Whenever you see

> S3 privately

Immediately think

✅ Gateway Endpoint

Whenever you see

> DynamoDB privately

Again

✅ Gateway Endpoint

Whenever you see

> SNS privately

or

> SQS privately

or

> Secrets Manager privately

Think

✅ Interface Endpoint

---

# Small Comparison

| Feature          | Gateway Endpoint  | Interface Endpoint      |
| ---------------- | ----------------- | ----------------------- |
| Services         | S3, DynamoDB only | Most AWS services       |
| Cost             | ✅ Free            | ❌ Hourly + data charges |
| Uses PrivateLink | ❌ No              | ✅ Yes                   |
| Uses Route Table | ✅ Yes             | ❌ No (uses ENI)         |
| Creates ENI      | ❌ No              | ✅ Yes                   |

---

# Why the other options are wrong

### ❌ Custom VPC Endpoint Service

This is for **you providing a service** to other VPCs using AWS PrivateLink, not for accessing S3.

---

### ❌ Interface Endpoint

Technically works.

But:

* costs money
* S3 already supports Gateway Endpoint

Since the question says **most cost-effective**, it's not the best answer.

---

### ❌ VPN

Still uses the public Internet.

---

### ✅ Gateway Endpoint

* Private AWS network
* Free
* Built specifically for S3 and DynamoDB
* Most cost-effective

---

## ⭐ Exam Cheat Sheet

Whenever you see these services in an SAA question:

| Service         | Answer                 |
| --------------- | ---------------------- |
| Amazon S3       | ✅ Gateway VPC Endpoint |
| DynamoDB        | ✅ Gateway VPC Endpoint |
| SNS             | ✅ Interface Endpoint   |
| SQS             | ✅ Interface Endpoint   |
| Secrets Manager | ✅ Interface Endpoint   |
| KMS             | ✅ Interface Endpoint   |
| CloudWatch      | ✅ Interface Endpoint   |
| Lambda          | ✅ Interface Endpoint   |

If the exam asks for **private access to S3 or DynamoDB**, your first thought should almost always be **Gateway VPC Endpoint**. If it asks for private access to most other AWS services, think **Interface VPC Endpoint (AWS PrivateLink)**.
