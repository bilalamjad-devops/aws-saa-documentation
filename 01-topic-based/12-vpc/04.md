4. Question

Category: CSAA – Design Secure Architectures

A local bank has an in-house application that handles sensitive financial data in a private subnet. After the data is processed by the EC2 worker instances, they will be delivered to S3 for ingestion by other services.

How should you design this solution so that the data does not pass through the public Internet?

- Configure a Transit gateway along with a corresponding route entry that directs the data to S3.
- Provision a NAT gateway in the private subnet with a corresponding route entry that directs the data to S3.
- Create an Internet gateway in the public subnet with a corresponding route entry that directs the data to S3.
- `Configure a VPC Endpoint along with a corresponding route entry that directs the data to S3.`

This is one of the **most important VPC questions** in the SAA exam. Once you understand it, you'll answer many similar questions correctly.

The question is testing only **one concept**:

> **How can a private EC2 access S3 without using the Internet?**

---

# Step 1: The architecture

The bank has EC2 instances.

```text
Private Subnet

+------------------+
| EC2 Worker       |
| Processes data   |
+------------------+
```

After processing,

the EC2 uploads data to S3.

```text
EC2  ----------->  S3
```

---

# Step 2: The requirement

The question says:

> **The data must NOT pass through the public Internet.**

This sentence is the clue.

Whenever you see:

* S3
* DynamoDB
* Private connection
* No Internet

💡 Immediately think:

> **VPC Endpoint**

---

# What happens normally?

Without a VPC Endpoint:

```text
Private EC2
      │
      ▼
NAT Gateway
      │
      ▼
Internet
      │
      ▼
Amazon S3
```

Even though S3 belongs to AWS, the traffic leaves your VPC and uses Internet connectivity.

The bank says:

❌ We don't want that.

---

# The better solution

Create a **VPC Endpoint**.

```text
Private EC2
      │
      ▼
VPC Endpoint
      │
      ▼
Amazon S3
```

Now the traffic stays **inside AWS's private network**.

No Internet.

No NAT.

No Internet Gateway.

---

# Think of it like a tunnel

Without VPC Endpoint

```text
Office
   │
Public Road
   │
Warehouse
```

With VPC Endpoint

```text
Office
   │
Private Tunnel
   │
Warehouse
```

The private tunnel is much safer.

---

# What is a VPC Endpoint?

Imagine your VPC is a building.

Normally, to reach S3, you leave the building.

```text
Building
   │
Street
   │
S3
```

A VPC Endpoint creates a private door.

```text
Building
   │
Private Door
   │
S3
```

You never step outside.

---

# Why not NAT Gateway?

Many students choose NAT.

Remember:

NAT means

```text
Private EC2

↓

Internet
```

NAT **gives Internet access**.

The question says

> Don't use the Internet.

So NAT is immediately wrong.

---

# Why not Internet Gateway?

Internet Gateway is for:

```text
Public Subnet

↓

Internet
```

Again,

the question says

> Don't use the Internet.

Wrong.

---

# Why not Transit Gateway?

Transit Gateway is used to connect:

```text
VPC A

      \
       \
        Transit Gateway

       /

VPC B

On-premises
```

It connects **networks**.

It does **not** connect directly to S3.

---

# Easy Memory Rule

If you see:

```
Private EC2
        +
S3
        +
No Internet
```

Answer:

✅ **VPC Endpoint**
