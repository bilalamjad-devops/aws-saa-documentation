7. Question

Category: CSAA – Design High-Performing Architectures

A global news network created a CloudFront distribution for their web application. However, you noticed that the application’s origin server is being hit for each request instead of the AWS Edge locations, which serve the cached objects. The issue occurs even for the commonly requested objects.

What could be a possible cause of this issue?

- `The Cache-Control max-age directive is set to zero.`
- An object is only cached by CloudFront once a successful request has been made hence, the objects were not requested before, which is why the request is still directed to the origin server.
- The file sizes of the cached objects are too large for CloudFront to handle.
- There are two primary origins configured in your Amazon CloudFront Origin Group.

## 1. CloudFront = CDN

**Purpose:** Deliver content globally with low latency.

```
User (Pakistan)

      ▼

      │
      ▼

With CloudFront:

```
User → Nearby Edge → Origin (only if needed)

# 5. Cache-Control Header

Very important exam topic.

```
Cache-Control: max-age=3600
```

means

> Cache for one hour.

If

```
max-age = 0
```

CloudFront asks the origin every request.

Question 7 was exactly this.

> **Low max-age → More Origin Hits**

# 6. Signed URL vs Signed Cookies

One of the highest-yield CloudFront topics.

### Signed URL

Use when:

* one file
* temporary download

Example

```
Download report.pdf
```

Generate URL

```
https://abc.cloudfront.net/report.pdf?signature=...
```

Good for

* one movie
* one PDF
* one ZIP

---

### Signed Cookies

Use when

Many files

Example

Subscriber area

```
movie.ts
movie1.ts
movie2.ts
movie3.ts
movie4.ts
```

Instead of generating 500 URLs,

just send one cookie.

Browser automatically accesses all files.

Question keyword:

Answer:

> **Signed Cookies**

# 7. OAC (Origin Access Control)

One of the newest exam favorites.

Without OAC

```
User
 │
 ├────CloudFront
 │
 └────Direct S3 URL
```

Bad.

People bypass CloudFront.

---

With OAC

```
User
 │
 ▼
CloudFront
 │
 ▼
S3
```

S3 accepts requests **only from CloudFront**.

Direct S3 access is blocked.

---

Remember

Question says

> Users must only access through CloudFront

Answer:

> **Origin Access Control (OAC)**
