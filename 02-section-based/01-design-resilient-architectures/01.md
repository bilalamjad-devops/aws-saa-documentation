1. Question

Category: CSAA – Design Resilient Architectures

A financial analytics application that collects, processes, and analyzes stock data in real-time uses Amazon Kinesis Data Streams. The producers continually push data to Kinesis Data Streams while the consumers process the data in real time.

In Kinesis, where can the consumers store the results? (Select TWO.)

- AWS Glue
- Amazon EMR
- `Amazon S3`
- `Amazon Redshift`
- Amazon Athena

# Question 1

**Category:** Design Resilient Architectures

# 1. Easy English (What is the question asking?)

Let's simplify the scenario.

A financial company is receiving **stock market data continuously**.

```
Stock Market
      │
      ▼
Producers
      │
      ▼
Kinesis Data Streams
      │
      ▼
Consumers
      │
      ▼
Where should processed data be stored?
```

The question is asking:

> **After consumers finish processing data from Kinesis Data Streams, where can they save the processed results?**

Notice that AWS is **not** asking where data comes from.

It is asking:

> **Where do consumers STORE the processed data?**

# 6. Analyze Every Option

---

## A) AWS Glue

❌ **Wrong**

### What is AWS Glue?

Glue is an **ETL service**.

ETL means:

* Extract
* Transform
* Load

It helps move and transform data between systems.

Example:

```
S3
 │
 ▼
Glue cleans data
 │
 ▼
Redshift
```

Glue prepares data.

It does **not** store data.

---

## B) Amazon EMR

❌ **Wrong**

### What is EMR?

EMR stands for:

**Elastic MapReduce**

It runs:

* Hadoop
* Spark
* Hive
* Presto

It is used for **big data processing**.

Example:

```
Huge Dataset
      │
      ▼
EMR Cluster
      │
      ▼
Processed Data
```

EMR is a compute service.

It is **not** where you permanently store results.

---

## C) Amazon S3

✅ **Correct**

### Why?

S3 is AWS Object Storage.

Consumers can process data and save files like:

* JSON
* CSV
* Images
* Logs
* Reports

Example:

```
Consumer
     │
     ▼
S3 Bucket

stock-report.csv
analysis.json
logs.txt
```

S3 is one of the most common destinations for Kinesis output.

---

## D) Amazon Redshift

✅ **Correct**

### What is Redshift?

Redshift is AWS's data warehouse.

Companies use it for analytics.

Example:

```
Consumer
      │
      ▼
Redshift

Millions of records

SQL Analytics
Dashboards
BI Reports
```

Perfect place to store processed stock data for reporting.

---

## E) Amazon Athena

❌ **Wrong**

Many students confuse Athena.

Athena is **not storage**.

Athena only runs SQL queries.

Example:

```
S3
 │
 ▼
Athena

SELECT *
FROM stocks;
```

Athena reads data from S3.

It doesn't save consumer output.

---

# 7. Why These Are the Best Answers

The requirement is:

> **Store processed results**

S3 stores objects.

Redshift stores structured analytical data.

Exactly what consumers need after processing.

---

# 8. Real-World Example

Imagine you're building a stock analytics platform.

Every second:

```
AAPL 205.50

MSFT 430.11

AMZN 198.32
```

These prices enter Kinesis.

A consumer calculates:

* Average price
* Highest price
* Lowest price

Now where should these calculations go?

### Option 1

Save reports to S3.

```
daily-report.csv
```

### Option 2

Store everything in Redshift.

Then analysts run SQL:

```sql
SELECT AVG(price)
FROM stock_prices;
```

Perfect use case.

---

# 9. Interview Tip

**Interviewer:**

"Why would you store Kinesis consumer output in Redshift instead of Athena?"

Good answer:

> "Redshift is the storage layer (data warehouse). Athena is only a query engine that queries data already stored in S3. Athena does not store processed data."
