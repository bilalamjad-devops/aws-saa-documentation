15. Question

Category: CSAA – Design Resilient Architectures

A company plans to migrate its on-premises workload to AWS. The current architecture is composed of a Microsoft SharePoint server that uses a Windows shared file storage. The Solutions Architect needs to use a cloud storage solution that is highly available and can be integrated with Active Directory for access control and authentication, and must be accessible from on-premises via a direct connection.

Which of the following options can satisfy the given requirement?

- `Provision an Amazon FSx for Windows File Server file system and join it to an AWS Active Directory domain.`
- Create a file system using Amazon EFS and join it to an Active Directory domain.
- Launch an Amazon EC2 Windows Server to mount a new Amazon S3 bucket as a file volume.
- Create a Network File System (NFS) file share using AWS Storage Gateway.

### Question 15 — Easy explanation

The important clues are:

* **SharePoint / Windows**
* **Windows shared file storage**
* **Active Directory authentication**
* **Highly available**
* **Accessible from on-premises through a direct connection**

The key is **Windows + SMB + Active Directory**.

### ✅ Correct answer

**Amazon FSx for Windows File Server + Active Directory**

Think of it as:

```text
On-Premises
   │
   │ Direct Connect
   ↓
AWS
   │
   ↓
FSx for Windows File Server
   │
   └── Active Directory
```

FSx for Windows is designed specifically for **Windows file shares** and uses **SMB (Server Message Block)**. It also integrates with Microsoft Active Directory for authentication and permissions.

### Why the others are wrong

**❌ EFS**
EFS is primarily for **Linux workloads** and uses NFS. For Windows file shares, think **FSx for Windows**.

**❌ EC2 + S3**
S3 is **object storage**, not a native Windows SMB file share. This adds unnecessary complexity and doesn't satisfy the AD requirement in this scenario.

**❌ Storage Gateway NFS share**
NFS points you toward **Linux/Unix** workloads. The question specifically says **Windows shared file storage**, so you want **SMB**.

### 🧠 SAA memory rule

Remember this pair:

| Requirement                                 | AWS service                     |
| ------------------------------------------- | ------------------------------- |
| Windows file share + SMB + Active Directory | **FSx for Windows File Server** |
| Linux file system + NFS                     | **EFS**                         |
| Object storage                              | **S3**                          |
| On-premises ↔ AWS storage integration       | **Storage Gateway**             |

**Exam shortcut:**
If you see **Windows + SMB + Active Directory → FSx for Windows**.
