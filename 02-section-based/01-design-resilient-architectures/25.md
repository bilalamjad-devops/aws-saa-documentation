25. Question

Category: CSAA – Design Resilient Architectures

A company has a top priority requirement to monitor certain database metrics and send email notifications to the Operations team if any issues occur.

Which combination of AWS services can accomplish this requirement? (Select TWO.)

- Amazon Simple Email Service
- Amazon Simple Queue Service (SQS)
- Amazon EC2 Instance with a running Berkeley Internet Name Domain (BIND) Server.
- `Amazon Simple Notification Service (SNS)`
- `Amazon CloudWatch`


## 25. Question — Easy Explanation

The company wants to do **two things**:

1. **Watch/monitor database metrics** → Is the database healthy? CPU high? Connections too high? Storage low?
2. **Send an email when something goes wrong** → Notify the Operations team.

So think of it as:

**Monitor → Detect problem → Notify**

### Step 1: Who monitors?

👉 **Amazon CloudWatch**

CloudWatch monitors AWS resources and collects **metrics, logs, and events**.

For example:

> RDS CPU Utilization > 80%

CloudWatch can detect that using an alarm.

### Step 2: Who sends the notification?

👉 **Amazon SNS (Simple Notification Service)**

SNS can send notifications to subscribers, including **email**.

So the flow is:

```text
Amazon RDS
    ↓
CloudWatch monitors metrics
    ↓
CloudWatch Alarm detects problem
    ↓
Amazon SNS
    ↓
Email → Operations Team
```

### ✅ Correct Answers

* **Amazon CloudWatch**
* **Amazon Simple Notification Service (SNS)**

---

### Why not SES?

This is an important exam distinction.

**SES = Email sending service**

**SNS = Notification service**

For this question, we're not building an email application. We want to **notify the Operations team when a monitoring alarm occurs**.

Therefore:

> **CloudWatch → SNS → Email**

is the standard pattern.

### Quick memory trick 🧠

| Requirement                       | Service              |
| --------------------------------- | -------------------- |
| Monitor metrics                   | **CloudWatch**       |
| Detect threshold/problem          | **CloudWatch Alarm** |
| Send notification                 | **SNS**              |
| Queue/store messages              | **SQS**              |
| Send application/marketing emails | **SES**              |
| DNS                               | **Route 53**         |

### 🎯 Exam Rule

Whenever you see:

> **"Monitor something and send an alert/notification when there is a problem"**

Think:

**CloudWatch + SNS**

That's the key concept you should remember from this question.
