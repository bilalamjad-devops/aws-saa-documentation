16. Question

Category: CSAA – Design Resilient Architectures

A Solutions Architect is designing a highly available environment for an application. She plans to host the application on EC2 instances within an Auto Scaling Group. One of the conditions requires data stored on root EBS volumes to be preserved if an instance terminates.

What should be done to satisfy the requirement?

- Use AWS DataSync to replicate root volume data to Amazon S3.
- Configure ASG to suspend the health check process for each EC2 instance.
- Enable the Termination Protection option for all EC2 instances.
- `Set the value of DeleteOnTermination attribute of the EBS volumes to False.`

### Question 16 — Easy explanation

The key phrase is:

> **"Data on the root EBS volume must be preserved when the EC2 instance terminates."**

Normally:

```text
EC2 instance
   │
   └── Root EBS
          │
          ↓
     Instance terminates
          │
          ↓
     Root EBS deleted ❌
```

By default, the **root EBS volume is deleted** when its EC2 instance is terminated.

### ✅ Correct answer

**Set `DeleteOnTermination = False` for the root EBS volume.**

Then:

```text
EC2 instance
   │
   └── Root EBS
          │
          ↓
     Instance terminates
          │
          ↓
     EBS remains ✅
```

### 🧠 Very important exam distinction

**Termination Protection ≠ EBS preservation**

* **Termination Protection** → prevents the EC2 instance from being terminated.
* **`DeleteOnTermination = False`** → allows the EBS volume to remain **after** the instance terminates.

So if the question says:

> **"Instance terminates, but EBS data must remain."**

Immediately think:

> **`DeleteOnTermination = False`**

### Why the other options?

* ❌ **DataSync** → doesn't replicate EBS volumes directly to S3.
* ❌ **Suspend ASG health checks** → can prevent ASG from replacing unhealthy instances; hurts availability.
* ❌ **Termination Protection** → prevents termination; it doesn't preserve the volume after termination.

**SAA memory rule:**

> **Root EBS + instance termination + preserve data → `DeleteOnTermination = False`**.
