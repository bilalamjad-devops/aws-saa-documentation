9. Question

Category: CSAA – Design Secure Architectures

A Solutions Architect is working for a fast-growing startup that just started operations during the past 3 months. They currently have an on-premises Active Directory and 10 computers. To save costs in procuring physical workstations, they decided to deploy virtual desktops for their new employees in a virtual private cloud in AWS. The new cloud infrastructure should leverage the existing security controls in AWS but can still communicate with their on-premises network.

Which set of AWS services will the Architect use to meet these requirements?

- AWS Directory Services, VPN connection, and ClassicLink
- `AWS Directory Services, VPN connection, and Amazon Workspaces`
- AWS Directory Services, VPN connection, and AWS Identity and Access Management
- AWS Directory Services, VPN connection, and Amazon S3

Yes bro. This one is mainly testing whether you can identify **three separate requirements** and map each requirement to the correct AWS service.

## 1. What is the question asking?

Let's simplify the story.

The company has:

* An **existing Active Directory on-premises**
* 10 physical computers currently
* They don't want to buy more physical computers
* They want **virtual desktops in AWS**
* Those AWS desktops must still communicate with the **on-premises network**
* They want to use AWS security controls

So mentally convert the question into:

```text
Existing On-Premises Network
        │
        │ VPN
        │
        ▼
      AWS VPC
        │
        ├── AWS Directory Services
        │       │
        │       └── Existing Active Directory
        │
        └── Amazon WorkSpaces
                │
                ├── Employee Desktop 1
                ├── Employee Desktop 2
                └── Employee Desktop ...
```

The answer needs to provide **three things**:

1. Connect AWS ↔ on-premises
2. Integrate with Active Directory
3. Provide virtual desktops

---

# 2. Service #1 — VPN

### Requirement:

> "can still communicate with their on-premises network"

You need connectivity between:

```text
On-premises
     ↕
    AWS
```

A **VPN connection** can provide that connectivity.

So:

**On-premises network → VPN → AWS VPC**

---

# 3. Service #2 — AWS Directory Services

The company already has:

> **On-premises Active Directory**

They want AWS resources/users to work with that existing directory.

That's where **AWS Directory Service** comes in.

A particularly important option here is **AWS Managed Microsoft AD**, which can establish trust relationships with an existing on-premises Microsoft AD.

Think:

```text
On-prem AD
     ↕
AWS Directory Service
     ↕
AWS resources
```

So don't confuse Directory Service with IAM.

### IAM

IAM manages:

> **AWS identities and permissions**

For example:

```text
User → IAM policy → S3
```

It isn't your company's Microsoft Active Directory replacement/integration solution in this scenario.

---

# 4. Service #3 — Amazon WorkSpaces

This is the biggest clue:

> **"deploy virtual desktops for their new employees"**

That's exactly what **Amazon WorkSpaces** is designed for.

Instead of buying:

```text
Physical PC
Monitor
CPU
RAM
Storage
```

employees can have:

```text
              AWS
               │
         Amazon WorkSpaces
               │
        Virtual Desktop
               │
          Employee
```

The employee connects to their WorkSpace from a laptop/PC/thin client.

---

# ⭐ Therefore

The three requirements map perfectly:

| Requirement                              | AWS service               |
| ---------------------------------------- | ------------------------- |
| Connect AWS to on-premises               | **VPN**                   |
| Integrate with existing Active Directory | **AWS Directory Service** |
| Provide virtual desktops                 | **Amazon WorkSpaces**     |

Therefore:

> ✅ **AWS Directory Services + VPN connection + Amazon WorkSpaces**

---

## Why the other answers?

### ❌ Directory Services + VPN + ClassicLink

**ClassicLink is obsolete/retired technology** and, more importantly, it isn't a virtual desktop service.

The requirement is:

> "I need virtual desktops."

That's **WorkSpaces**.

---

### ❌ Directory Services + VPN + IAM

IAM is for **AWS access control and permissions**.

It doesn't provide virtual desktops.

So:

```text
IAM ≠ Virtual Desktop
```

---

### ❌ Directory Services + VPN + S3

S3 is:

> **Object storage**

It doesn't provide virtual desktops.

---

# 🧠 Exam shortcut

Whenever you see:

> **"Virtual desktops in AWS"**

Think:

### **Amazon WorkSpaces**

Whenever you see:

> **"Existing on-premises Microsoft Active Directory"**

Think:

### **AWS Directory Service**

Whenever you see:

> **"Connect on-premises network to AWS VPC"**

Think:

### **VPN / Direct Connect**

So this question becomes almost automatic:

**AD + VPN + Virtual Desktop**

➡️ **Directory Service + VPN + WorkSpaces**.
