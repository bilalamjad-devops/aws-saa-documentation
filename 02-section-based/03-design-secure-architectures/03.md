3. Question

Category: CSAA – Design Secure Architectures

A company has a web application hosted on a fleet of EC2 instances located in two Availability Zones that are all placed behind an Application Load Balancer. As a Solutions Architect, you have to add a health check configuration to ensure your application is highly-available.

Which health checks will you implement?

- TCP health check
- FTP health check
- `HTTP or HTTPS health check`
- ICMP health check

Exactly. This one is testing **which health-check types are supported by which Load Balancer**.

### What is the question asking?

You have:

```text
Users
   ↓
Application Load Balancer (ALB)
   ↓
┌──────────┐  ┌──────────┐
│ EC2 AZ-1 │  │ EC2 AZ-2 │
└──────────┘  └──────────┘
```

The ALB needs to determine:

> "Is this EC2 instance actually healthy and able to serve my web application?"

So it performs a **health check** on each target.

For an **ALB**, the health check is:

* ✅ HTTP
* ✅ HTTPS
* ❌ TCP
* ❌ ICMP
* ❌ FTP

Therefore:

> **HTTP or HTTPS health check**

### Why HTTP/HTTPS?

Because ALB operates at **Layer 7 (application layer)** and is designed for web/application traffic.

For example, you could configure:

```text
Health check protocol: HTTP
Health check path: /health
Port: 80
```

The ALB asks:

```text
GET /health
```

If the application returns something like:

```text
HTTP 200 OK
```

➡️ ALB considers the instance **healthy**.

If it repeatedly fails:

```text
HTTP 500
timeout
connection failure
```

➡️ ALB considers it **unhealthy** and stops sending new requests to that instance.

---

## Very important SAA table

| Load Balancer  | Health checks            |
| -------------- | ------------------------ |
| **ALB**        | HTTP / HTTPS             |
| **NLB**        | TCP / TLS / HTTP / HTTPS |
| **Classic LB** | HTTP / HTTPS / TCP / SSL |

So when you see:

> **ALB + health check**

Immediately think:

**HTTP/HTTPS**

---

### Don't confuse health checks with the traffic protocol

For example, an ALB might receive:

```text
HTTPS request
      ↓
ALB
      ↓
HTTP health check
      ↓
EC2
```

That's perfectly possible.

The **health-check protocol** is independently configured from the listener/application traffic.

### Exam shortcut 🧠

Remember:

> **ALB = Application = HTTP/HTTPS**

> **NLB = Network = TCP/TLS (+ HTTP/HTTPS health checks)**

And:

> **ICMP is not an ELB health-check option.**

This question is much easier once you identify **ALB first**.
