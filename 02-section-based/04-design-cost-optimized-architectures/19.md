19. Question

Category: CSAA – Design Cost-Optimized Architectures

A company is looking to store its confidential financial files in AWS, which are accessed every week. The Architect was instructed to set up the storage system, which uses envelope encryption and automates key rotation. It should also provide an audit trail that shows who used the encryption key and by whom for security purposes.

Which combination of actions should the Architect implement to satisfy the requirement in the most cost-effective way? (Select TWO.)

- `Use Amazon S3 to store the data.`
- Use Amazon S3 Glacier Deep Archive to store the data.
- `Configure Server-Side Encryption with AWS KMS Keys (SSE-KMS).`
- Configure Server-Side Encryption with Amazon S3-Managed Keys (SSE-S3).
- Configure Server-Side Encryption with Customer-Provided Keys (SSE-C).

### Q19 — What is this question really testing?

This one is mainly testing **S3 encryption choices + AWS KMS + envelope encryption + auditability**.

The answer is:

* ✅ **Amazon S3**
* ✅ **SSE-KMS**

### Why?

The requirements are:

| Requirement                       | Best fit                  |
| --------------------------------- | ------------------------- |
| Store files                       | **S3**                    |
| Files accessed every week         | S3 Standard is reasonable |
| Envelope encryption               | **KMS**                   |
| Automatic key management/rotation | **KMS**                   |
| Know who used the encryption key  | **KMS + CloudTrail**      |
| Audit key usage                   | **KMS + CloudTrail**      |

So the mental shortcut is:

> **Need encryption + key control + key usage auditing → SSE-KMS**

### The 3 S3 encryption options

**1. SSE-S3**
AWS manages the encryption keys.

Think:

> "I want encryption, but I don't need to manage/audit the KMS key myself."

Very simple and generally lower operational complexity.

---

**2. SSE-KMS ⭐**

AWS KMS manages the keys.

Think:

> **"I need encryption + control + auditing."**

You get features such as:

* KMS key management
* permissions around key usage
* key rotation capabilities
* auditability through CloudTrail

This is exactly what Q19 is looking for.

---

**3. SSE-C**

You provide and manage the encryption key yourself.

Think:

> **"I want to bring/manage my own encryption key."**

More operational responsibility, and it doesn't give you the KMS-based key-usage audit trail this question is asking for.

---

### Important: S3 vs Glacier Deep Archive

Don't automatically choose the cheapest storage class.

The question says:

> **"accessed every week"**

That's relatively frequent access for an archive class.

So:

**Weekly access → S3**

Whereas:

**Rarely accessed + long-term archive → Glacier / Glacier Deep Archive**

---

### 🔑 Exam shortcut

Remember these three:

**SSE-S3 → AWS manages keys**

**SSE-KMS → KMS manages keys + auditing/control**

**SSE-C → YOU provide/manage keys**

And:

**Need to know WHO used the encryption key? → KMS**

So when you see:

> **financial data + encryption + key rotation + audit trail**

Your brain should immediately go:

> **S3 + SSE-KMS** ✅

One small correction to the provided explanation: **KMS automatic rotation depends on the type of KMS key and configuration**; don't memorize "SSE-KMS always automatically rotates keys." For the exam, the important discriminator here is **KMS + key-use auditing/control**.
