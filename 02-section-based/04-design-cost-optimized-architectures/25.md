25. Question

Category: CSAA – Design Cost-Optimized Architectures

A company has stored 200 TB of backup files in Amazon S3. The files are in a vendor-proprietary format. The Solutions Architect needs to use the vendor’s proprietary file conversion software to retrieve files from an S3 bucket, convert the files to an industry-standard format, and re-upload the converted files to S3. The solution must minimize the data transfer costs.

Which of the following options can satisfy the given requirement?

- Use AWS DataSync to copy the data to an on-premises server. Install the file conversion software on the server. Transform the data and re-upload it to S3.
- Install the file conversion software in S3. Use S3 Batch Operations to perform data transformation.
- Deploy the Amazon EC2 instance in a different Region. Install the file conversion software on the instance. Perform data transformation and re-upload it to S3.
- `Deploy the Amazon EC2 instance in the same Region as S3. Install the file conversion software on the instance. Perform data transformation and re-upload it to S3.`

Absolutely. This question looks complicated because of the **vendor software + 200 TB + S3 + data transfer** wording, but the actual question is very simple.

## First: What are they asking?

They are saying:

> "We have **200 TB sitting in S3**. We need to take each file, run a special conversion program on it, and put the converted file back into S3. How can we do this while minimizing data-transfer cost?"

The important part is:

**The conversion software needs to run somewhere.**

S3 **cannot run your software**.

So we need a compute machine, such as EC2.

---

## The architecture

The correct solution is:

```text
                 Same AWS Region
                      
             ┌──────────────────┐
             │   Amazon S3      │
             │    200 TB        │
             └────────┬─────────┘
                      │
                 download
                      ↓
             ┌──────────────────┐
             │   EC2 Instance   │
             │                  │
             │ Vendor Software  │
             │      ↓           │
             │   Conversion     │
             └────────┬─────────┘
                      │
                   upload
                      ↓
             ┌──────────────────┐
             │   Amazon S3      │
             │ converted files  │
             └──────────────────┘
```

The key is:

> **EC2 and S3 must be in the same AWS Region.**

---

# Why does Region matter?

Imagine your S3 bucket is in:

**us-east-1**

### ❌ EC2 in another Region

```text
S3 us-east-1
     ↓
     ↓ 200 TB across Regions 💰
     ↓
EC2 eu-west-1
     ↓
conversion
     ↓
     ↓ 200 TB across Regions 💰
     ↓
S3 us-east-1
```

You're moving huge amounts of data between Regions.

That's expensive.

---

### ✅ EC2 in same Region

```text
S3 us-east-1
     ↓
     ↓
EC2 us-east-1
     ↓
conversion
     ↓
     ↓
S3 us-east-1
```

The data stays within the same AWS Region, avoiding the relevant S3-to-EC2 data-transfer charge.

**That's the entire trick of this question.**

---

# Why not DataSync?

You might think:

> "DataSync moves data. Why not use it?"

Because DataSync would involve moving the 200 TB **out to an on-premises server**, converting it there, then sending it back.

```text
S3
 ↓
200 TB
 ↓
On-premises
 ↓
conversion
 ↓
200 TB
 ↓
S3
```

That's unnecessary movement.

The question specifically says:

> **minimize data transfer costs**

So keep the processing **inside AWS and close to S3**.

---

# Why not S3 Batch Operations?

This is another trap.

S3 Batch Operations can perform operations on lots of S3 objects, such as:

* Copy objects
* Restore objects
* Delete objects
* Invoke Lambda
* etc.

But you **cannot install arbitrary vendor software inside S3**.

S3 is **storage**, not a server where you install applications.

---

# Why not EC2 in another Region?

Because:

> **Cross-Region data transfer costs money.**

With **200 TB**, that could become very expensive.

Therefore:

> **S3 + EC2 in same Region** ✅

---

# 🧠 The SAA pattern to memorize

Whenever you see:

> **"Process/transform a large amount of data already stored in S3 and minimize data transfer costs."**

Think:

### **Put compute in the same Region as S3.**

```text
S3
 ↕
EC2
```

**Same Region → avoid unnecessary data-transfer charges.**

---

### One more important distinction

Don't interpret this as:

> "S3 → EC2 is always free."

The exam's relevant rule here is that **data transferred from S3 to EC2 in the same AWS Region has no S3 data-transfer charge**. Other applicable AWS charges can still exist.

So for Q25, your mental answer should be:

> **"The software needs compute → use EC2. The data is already in S3 → put EC2 in the same Region → process locally → upload back to S3."**

✅ **Option 4**.
