1. Question

Category: CSAA – Design Cost-Optimized Architectures

A Solutions Architect is working for a financial company. The manager wants to have the ability to automatically transfer obsolete data from their S3 bucket to a low-cost storage system in AWS after a certain period of time.

What is the best solution that the Architect can provide to them?

- Use an EC2 instance and a scheduled job to transfer the obsolete data from their S3 location to Amazon S3 Glacier.
- `Use Lifecycle Policies in S3 to move obsolete data to Glacier.`
- Use Amazon Timestream.
- Use Amazon SQS.

Exactly bro — **this one is easy**, and it's testing a very common SAA pattern.

## What is the question asking?

In simple words:

> "I have old/obsolete files in S3. After some time, automatically move them to cheaper storage."

For example:

```text
Day 0
↓
S3 Standard
active data

        ↓ 90 days

S3 Glacier
old data
cheaper storage
```

The important word is **automatically**.

You don't want to build a server, script, cron job, Lambda, etc.

---

## ✅ Correct answer: S3 Lifecycle Policy

S3 Lifecycle rules can automatically transition objects between storage classes based on age.

For example:

```text
0 days
S3 Standard
     ↓
30 days
S3 Standard-IA
     ↓
90 days
S3 Glacier Flexible Retrieval
     ↓
365 days
Delete
```

You define the rules once, and **S3 manages the transitions**.

---

## Why the other answers are wrong

### ❌ EC2 + scheduled job

Technically possible, but unnecessary.

You would have to:

```text
EC2
 ↓
cron/scheduled job
 ↓
script
 ↓
move objects
```

That's extra:

* infrastructure
* maintenance
* cost
* operational overhead

AWS already provides Lifecycle Policies for exactly this.

---

### ❌ SQS

SQS is:

> **Message queue**

Think:

```text
Application → SQS → Worker
```

It's for **decoupling applications**, not storage lifecycle management.

---

### ❌ Timestream

Timestream is for:

> **Time-series data**

Examples:

* IoT sensor data
* metrics
* application telemetry

It isn't used to move old S3 objects to cheaper storage.

---

# 🧠 SAA Exam Shortcut

Whenever you see:

> **"Automatically move old S3 objects to cheaper storage based on age"**

Immediately think:

### **S3 Lifecycle Policy**

And remember:

**Lifecycle = Transition + Expiration**

```text
Lifecycle
├── Transition → move to cheaper storage
└── Expiration → delete objects
```

This is one of those questions where **don't overthink it**. The moment you see *S3 + age/time + automatic transition + cheaper storage*, choose **Lifecycle Policy**.
