24. Question

Category: CSAA – Design Cost-Optimized Architectures

A company is building an automation tool for generating custom reports on its AWS usage. The company must be able to programmatically access and forecast usage costs on specific services.

Which of the following would meet the requirements with the LEAST amount of operational overhead?

- `Use the AWS Cost Explorer API with pagination to programmatically retrieve the usage cost-related data.`
- Configure AWS Budgets to send usage cost data to the company via Amazon SNS.
- Utilize the downloadable AWS Cost Explorer report .csv files to access the cost-related data. Predict usage costs using AWS Budgets.
- Generate AWS Budgets reports for usage cost data and deliver them via Amazon Simple Queue Service (SQS).

Q24 is testing a very useful distinction:

> **Cost Explorer = analyze/retrieve/forecast costs**
> **AWS Budgets = set limits and alert when you approach/exceed them**

So the answer is:

### ✅ AWS Cost Explorer API with pagination

---

## What is Cost Explorer?

Think of **Cost Explorer** as your AWS **cost analytics engine**.

It can answer things like:

> "How much did EC2 cost last month?"

> "How much did DynamoDB cost?"

> "What are my daily costs?"

> "What do AWS expect my future costs to be?"

And importantly for this question:

> **You can access Cost Explorer programmatically through its API.**

So you can build:

```text id="y3v6x2"
Your Custom Report Tool
        ↓
Cost Explorer API
        ↓
AWS Cost & Usage Data
        ↓
Your application
        ↓
Custom report / dashboard
```

No manual CSV downloads. ✅

---

# Cost Explorer vs AWS Budgets

This distinction is extremely important for your SAA exam.

| Service                       | Main purpose                | Think                              |
| ----------------------------- | --------------------------- | ---------------------------------- |
| **Cost Explorer**             | Analyze costs and usage     | 📊 "Where is my money going?"      |
| **AWS Budgets**               | Set budgets + alerts        | 🚨 "Am I spending too much?"       |
| **Cost & Usage Report (CUR)** | Detailed cost/usage dataset | 📄 "Give me detailed billing data" |

### Cost Explorer

```text
"Show me my EC2 spending."
"Forecast my future spending."
"Compare this month's costs."
"How much did S3 cost?"
```

→ **Cost Explorer**

### AWS Budgets

```text
"My monthly budget is $1,000."
"Alert me when I reach 80%."
"Alert me when forecasted costs exceed my budget."
```

→ **AWS Budgets**

---

## Why not AWS Budgets in Q24?

The option says:

> Configure AWS Budgets to send usage cost data via SNS.

That's not what Budgets is primarily for.

Budgets says:

> **"You've reached your threshold."**

It doesn't function as your general-purpose programmatic cost-analysis API.

---

## Why pagination?

This is a small but important detail.

Suppose your application requests a lot of Cost Explorer data:

```text
API request
    ↓
Page 1
    ↓
NextToken
    ↓
Page 2
    ↓
NextToken
    ↓
Page 3
    ↓
...
```

Pagination allows your application to retrieve large result sets efficiently.
