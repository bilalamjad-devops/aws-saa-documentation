13. Question

Category: CSAA – Design Cost-Optimized Architectures

To save costs, your manager instructed you to analyze and review the setup of your AWS cloud infrastructure. You should also provide an estimate of how much your company will pay for all of the AWS resources that they are using.

In this scenario, which of the following will incur costs? (Select TWO.)

- `A running EC2 Instance`
- A stopped On-Demand EC2 Instance
- Using an Amazon VPC
- Public Data Set
- `EBS Volumes attached to stopped EC2 Instances`

This is testing a very common AWS billing distinction:

> **"If I stop something, does AWS stop charging me completely?"**

The answer is **not always**.

## The two things that incur cost

### ✅ 1. Running EC2 instance

A running EC2 instance incurs **compute charges**.

```text
EC2
 ↓
RUNNING
 ↓
💰 Compute charge
```

So:

> **Running EC2 = charged**

---

### ✅ 2. EBS volume attached to a stopped EC2

This is the important trick.

When you **stop** an EC2 instance:

```text
EC2 instance
     ↓
   STOP
     ↓
Compute charge stops
     ↓
But EBS remains
     ↓
💰 EBS storage charge continues
```

So:

> **Stopped EC2 = no instance compute charge**

but:

> **EBS volume = still charged**

---

# ❌ Stopped On-Demand EC2

Once you stop an On-Demand instance:

```text
RUNNING
  ↓
STOP
  ↓
No EC2 compute charge
```

However, its EBS storage is still billed.

So don't say:

> "Stopped EC2 is completely free."

Instead remember:

### **Stopped EC2 → no compute charge, but attached EBS still costs money.**

---

# ❌ Amazon VPC

Creating a VPC itself doesn't have a separate charge.

```text
VPC
 ↓
Free
```

But resources **inside/associated with it** can cost money:

```text
VPC
├── EC2 → 💰
├── NAT Gateway → 💰
├── Transit Gateway → 💰
├── VPC Endpoint → depends on type
└── etc.
```

So don't confuse:

> **VPC is free**

with:

> **Everything inside the VPC is free.**

---

# ❌ Public Data Sets

AWS provides certain public datasets without charging you for simply accessing/storing the public dataset itself.

The important exam concept is:

> **The dataset isn't what you're being charged for; your own AWS resource usage can be.**

---

# 🧠 Quick EC2 billing cheat sheet

| EC2 state/resource       | Compute charge? |                                                      Storage charge? |
| ------------------------ | --------------: | -------------------------------------------------------------------: |
| **Running EC2**          |           ✅ Yes |                                                                ✅ EBS |
| **Stopped EC2**          |            ❌ No |                                                                ✅ EBS |
| **Terminated EC2**       |            ❌ No | ❌ Its EBS is normally deleted if configured to delete on termination |
| **EBS volume by itself** |               — |                                                                ✅ Yes |

### ⭐ SAA memory trick:

> **STOP EC2 → stops compute billing, NOT EBS billing.**

And for this question:

**Correct TWO:**

✅ **Running EC2 Instance**
✅ **EBS Volumes attached to stopped EC2 Instances**
