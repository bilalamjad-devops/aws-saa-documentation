Category: CSAA – Design High-Performing Architectures

A Solutions Architect is migrating several Windows-based applications to AWS that require a scalable file system storage for high-performance computing (HPC). The storage service must have full support for the SMB protocol and Windows NTFS, Active Directory (AD) integration, and Distributed File System (DFS).

Which of the following is the MOST suitable storage service that the Architect should use to fulfill this scenario?

- `Amazon FSx for Windows File Server`
- Amazon S3 Glacier Deep Archive
- Amazon FSx for Lustre
- AWS DataSync

Yes. This is the **High-Performing Architectures** section now, and this question is testing one very specific decision:

### Q1 — FSx for Windows vs FSx for Lustre

Look at the keywords:

> **Windows applications**
> **SMB**
> **NTFS**
> **Active Directory**
> **DFS**

These keywords immediately point to:

✅ **Amazon FSx for Windows File Server**

### The exam trick

Don't get distracted by **HPC** in the question.

The question says:

> "Windows-based applications ... SMB ... Windows NTFS ... Active Directory ... DFS"

Those are much stronger clues than the word HPC.

So:

**Windows → FSx Windows**
**HPC/compute-intensive → FSx Lustre**

That's the key distinction you need for SAA.
