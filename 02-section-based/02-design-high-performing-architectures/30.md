30. Question

Category: CSAA – Design High-Performing Architectures

A startup plans to develop a multiplayer game that uses UDP as the protocol for communication between clients and game servers. The data of the users will be stored in a key-value store. As the Solutions Architect, you need to implement a solution that will distribute the traffic across a number of servers.

Which of the following could help you achieve this requirement?

- Distribute the traffic using Application Load Balancer and store the data in Amazon DynamoDB.
- Distribute the traffic using Application Load Balancer and store the data in Amazon RDS.
- `Distribute the traffic using Network Load Balancer and store the data in Amazon DynamoDB.`
- Distribute the traffic using Network Load Balancer and store the data in Amazon Aurora.


Yes — this question is testing **two separate clues**. Once you identify them, the answer becomes very easy.

### 1. UDP → Network Load Balancer

The game communicates using **UDP**.

Think:

| Requirement                  | AWS service    |
| ---------------------------- | -------------- |
| HTTP/HTTPS, URL/path routing | **ALB**        |
| TCP/UDP, Layer 4             | **NLB**        |
| Key-value database           | **DynamoDB**   |
| Relational SQL database      | **RDS/Aurora** |

So:

**UDP → NLB**

ALB is Layer 7 and is designed around HTTP/HTTPS. NLB works at Layer 4 and supports TCP/UDP/TLS.

### 2. Key-value store → DynamoDB

The question says:

> "The data of the users will be stored in a key-value store."

That's a huge clue.

**DynamoDB supports key-value and document models.**

RDS/Aurora are relational databases, so they don't fit the requirement.

Therefore:

**UDP → NLB**
**Key-value → DynamoDB**

### 🧠 Exam shortcut

When you see:

* **UDP** → NLB
* **TCP** → NLB
* **HTTP/HTTPS + path/host/header routing** → ALB
* **Key-value** → DynamoDB
* **Relational/SQL** → RDS/Aurora

So the answer is:

> ✅ **Distribute the traffic using Network Load Balancer and store the data in Amazon DynamoDB.**

One important correction to the Tutorials Dojo explanation: **NLB is not necessarily "better" simply because it's Layer 4**; the key reason here is that **the application requires UDP**, which ALB doesn't support.
