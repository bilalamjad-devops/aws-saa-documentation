5. Question

Category: CSAA – Design High-Performing Architectures

A company plans to launch an application that tracks the GPS coordinates of delivery trucks in the country. The coordinates are transmitted from each delivery truck every five seconds. The must be able to process coordinates from multiple consumers in real-time. The aggregated data will be analyzed in a separate reporting application.

Which AWS service should you use for this scenario?

- Amazon Elastic MapReduce (EMR)
- `Amazon Kinesis`
- Amazon AppStream
- Amazon Simple Queue Service

This one is straightforward and **very important for SAA**.

### Q5 — GPS coordinates every 5 seconds

Look at the clues:

* GPS coordinates
* continuously generated
* every 5 seconds
* **real-time**
* multiple consumers
* streaming data

These scream:

> ✅ **Amazon Kinesis**

```text id="k4p6n2"
Delivery Trucks
     │
     │ GPS coordinates
     ↓
Amazon Kinesis
     │
     ├── Consumer 1
     │
     ├── Consumer 2
     │
     └── Reporting / Analytics
```

### 🧠 Memorize this distinction

| Requirement                             | Think         |
| --------------------------------------- | ------------- |
| **Real-time streaming data**            | **Kinesis**   |
| Messages between application components | **SQS**       |
| Publish/subscribe notifications         | **SNS**       |
| Big-data batch processing               | **EMR**       |
| Stream desktop applications             | **AppStream** |

### Kinesis vs SQS — very important

You'll probably see this comparison many times in SAA.

**SQS:**

> "I have a job/message that needs to be processed."

Example:

```text
Order → SQS → Worker → Process order
```

**Kinesis:**

> "I have a continuous stream of data that multiple consumers need to process/analyze."

Example:

```text
GPS → Kinesis → Analytics
             → Monitoring
             → Reporting
```

The phrase **"multiple consumers"** is an especially useful clue for Kinesis in questions like this.

### Exam shortcut

When you see:

> **real-time + continuous stream + telemetry/GPS/IoT/clickstream**

Immediately think:

**Kinesis.**
