11. Question

Category: CSAA – Design High-Performing Architectures

A Solutions Architect needs to set up the required compute resources for the application which have workloads that require high, sequential read and write access to very large data sets on local storage.

Which of the following instance type is the most suitable one to use in this scenario?

- General Purpose Instances
- Compute Optimized Instances
- `Storage Optimized Instances`
- Memory Optimized Instances

This is mainly testing **EC2 instance families**. The key phrase is:

> **"high sequential read and write access to very large data sets on local storage"**

### ✅ Answer: Storage Optimized

Think:

> **Storage Optimized = lots of data + very fast disk I/O**

For example:

```text
Huge Dataset
     ↓
Very fast local storage
     ↓
High read/write IOPS
     ↓
Storage Optimized EC2
```

### 🧠 Memorize the 4 major families

| Instance type         | Think       | Typical workload                  |
| --------------------- | ----------- | --------------------------------- |
| **General Purpose**   | ⚖️ Balance  | Web servers, normal applications  |
| **Compute Optimized** | 🧠 CPU      | Batch processing, video encoding  |
| **Memory Optimized**  | 🧠 RAM      | Large in-memory datasets, caching |
| **Storage Optimized** | 💾 Disk/I/O | Very high disk read/write         |

### Super-simple memory trick

**General → Everything balanced**

**Compute → CPU**

**Memory → RAM**

**Storage → Disk**

So when the question says:

> **"high read/write + very large data + local storage"**

Immediately choose:

**💾 Storage Optimized EC2** ✅

Don't get distracted by **"large data sets"**. If the question emphasizes **processing large data *in memory*** → Memory Optimized.

If it emphasizes **reading/writing large data on storage** → Storage Optimized.
