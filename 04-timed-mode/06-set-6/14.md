14. Question

A company is looking for a way to analyze the calls between customers and service agents. Each conversation is transcribed, JSON-formatted, and saved to an Amazon S3 bucket. The company’s solutions architect is tasked to design a solution for extracting and visualizing sentiments from the transcribed files.

Which solution meets the requirements while minimizing the amount of operational overhead?

- Analyze the JSON files with Amazon Textract. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using Amazon Managed Grafana.
- Create an Amazon Comprehend analysis job. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using Amazon Managed Grafana.
- Train a custom Natural Language Processing (NLP) model using Amazon SageMaker. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using the OpenSearch Dashboard.
- `Create an Amazon Comprehend analysis job. Index the sentiment along with the transcript to an Amazon OpenSearch cluster. Visualize the results using the OpenSearch Dashboard.`

Aap ne **Amazon Comprehend** ki application bilkul sahi samajhi—yeh text se sentiment (positive, negative, neutral) aur key phrases analyze karta hai.

---

### Amazon OpenSearch Kya Hai? 🔍

**Amazon OpenSearch Service** (pehle Amazon Elasticsearch Service) ek fully managed **search aur analytics engine** hai. Iska kaam badi miktadar mein unstructured text, logs, ya metadata ko rapidly **search, index, aur analyze** karna hai.

---

### SAA-C03 Ke Liye Essential Concepts 💡

* **Indexing & Search:**
Jab Amazon Comprehend har transcript se sentiment extract kar leta hai, toh yeh sara text, metadata, aur sentiment score OpenSearch ke andar ek **"Index"** (searchable database record) ke taur par save hota hai.
* **Real-time Querying:**
Agley hi second aap lakho call transcripts mein se specifically search kar sakte hain, jaise: *"Show all negative sentiment calls involving 'refund' from last week."*
* **OpenSearch Dashboard (Visualization):**
OpenSearch ke sath built-in UI dashboard milta hai (jo pehle Kibana kehlaata tha). Is se aap direct graphs, pie charts, aur live monitoring dashboards bana sakte hain bina kisi extra tool (jaise Grafana) ko set up kiye—jo operational overhead ko sab se kam rakhta hai.
