63. Question

A company deployed a web application to an EC2 instance that adds a variety of photo effects to a picture uploaded by the users. The application will put the generated photos to an S3 bucket by sending PUT requests to the S3 API.

What is the best option for this scenario considering that you need to have API credentials to be able to send a request to the S3 API?

- Store the API credentials in the root web application directory of the EC2 instance.
- Encrypt the API credentials and store in any directory of the EC2 instance.
- Store your API credentials in Amazon S3 Glacier.
- `Create a role in IAM. Afterwards, assign this role to a new EC2 instance.`

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) ❓

* **Scenario:** Ek web application EC2 instance par chal rahi hai jo users ki photos par effects apply karke generated images ko Amazon S3 bucket mein PUT requests ke zariye upload karti hai.
* **Requirement:** S3 API ko requests bhejne ke liye API credentials chahiye. **Best security practice** aur **operational efficiency** ke tehat credentials kaise handle kiye jane chahiye?

---

### 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answer) 💡

* **Option:** *Create a role in IAM. Afterwards, assign this role to a new EC2 instance.*
* **Wazahat:**
* **IAM Roles for EC2:** AWS ki sab se ahem security practice yeh hai ke EC2 instances ya kisi bhi AWS compute resource ke andar long-term Access Keys / API Credentials ko kabhi bhi hardcode ya local storage par save na kiya jaye.
* EC2 instance ko ek IAM Role assign kar dene se AWS instance ko automatically short-term temporary credentials (via Instance Metadata Service / IMDS) provide karta hai, jo self-rotate hote hain aur application safely S3 API ko authenticate kar sakti hai.



*Kyunki baqi options ghalat aur unsafe hain:*

* *Directory mein credentials store karna (plain ya encrypted):* Credentials leak hone ka sab se bara risk hota hai (hardcoded credentials anti-pattern).
* *Amazon S3 Glacier mein store karna:* Glacier archival storage ke liye hai, runtime application credentials fetch karne ke liye nahi.
