65. Question

A Solutions Architect is trying to enable Cross-Region Replication to an Amazon S3 bucket but this option is disabled. The bucket has been configured with a Multi-Region Access Point to manage incoming requests.

Which of the following options is a valid reason for this?

- `In order to use the Cross-Region Replication feature in S3, you need to first enable versioning on the bucket.`
- The Cross-Region Replication feature is only available for S3 – Infrequent Access.
- The Cross-Region Replication feature is only available for S3 – One Zone-IA.
- This is a premium feature which is only for AWS Enterprise accounts.

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) ❓

* **Scenario:** Ek Solutions Architect Amazon S3 bucket par **Cross-Region Replication (CRR)** enable karne ki koshish kar raha hai, lekin yeh option greyed out / disabled aaraha hai. Bucket par Multi-Region Access Point pehle se configured hai.
* **Problem:** Cross-Region Replication option disabled hone ki asal wajah kya hai?

---

### 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answer) 💡

* **Option:** *In order to use the Cross-Region Replication feature in S3, you need to first enable versioning on the bucket.*
* **Wazahat:**
* **S3 Replication (CRR & SRR) Prerequisites:** AWS S3 mein Replication (chahe Cross-Region ho ya Same-Region) setup karne ki **pehli shart (prerequisite)** yeh hai ke **Source bucket aur Destination bucket dono par S3 Versioning mandatory (enabled) honi chahiye**.
* Agar Versioning disable hogi, toh S3 Console par Replication settings setup karne ki option disabled rehti hai.



*Kyunki baqi options ghalat hain:*

* *S3 Storage Class restriction:* Cross-Region Replication tamam standard storage classes (Standard, Standard-IA, One Zone-IA, Glacier) ke sath kaam karta hai, yeh kisi aik specific class ke liye restricted nahi hai.
* *AWS Enterprise account:* CRR tamam AWS accounts (Free Tier, Developer, Enterprise) ke liye available feature hai, yeh koi Enterprise-only feature nahi hai.

### 3. Keyword Scanning Cheat Sheet 🔑

| Question Keyword / Phrase | Direct Exam Mapping | Logic / Wajah |
| --- | --- | --- |
| **"Cross-Region Replication (CRR) option disabled / greyed out"** | **Enable S3 Versioning** | S3 Replication ke liye Source aur Destination dono buckets par S3 Versioning active hona zaroori hai. |
| **"Only available for S3 - IA / Enterprise" (Trap Options)** | **Incorrect Limitations** | CRR S3 ke core features mein se hai jo tamaam valid storage classes aur normal accounts par support hota hai. |
