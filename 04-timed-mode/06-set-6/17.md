17. Question

A cryptocurrency company wants to go global with its international money transfer app. Your project is to make sure that the database of the app is highly available in multiple regions.

What are the benefits of adding Multi-AZ deployments in Amazon RDS? (Select TWO.)

- Provides SQL optimization.
- `Provides enhanced database durability in the event of a DB instance component failure or an Availability Zone outage.`
- Significantly increases the database performance.
- `Increased database availability in the case of system upgrades like OS patching or DB Instance scaling.`
- Creates a primary DB Instance and synchronously replicates the data to a standby instance in a different Availability Zone (AZ) in a different region.

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) ❓

* **Scenario:** Ek cryptocurrency company apni global money transfer app ke liye database ko highly available banana chahti hai.
* **Requirement:** Sawal seedha yeh pooch raha hai ke Amazon RDS mein **Multi-AZ deployments** enable karne ke **fayde (benefits)** kya hain? (Select TWO).

---

### 2. Sahi Jawabat Kya Keh Rahe Hain? (Correct Answers - Select TWO) 💡

1. **Provides enhanced database durability in the event of a DB instance component failure or an Availability Zone outage.**
* *Wazahat:* Multi-AZ mein data synchronously replicate ho raha hota hai. Agar koi hardware kharab ho jaye ya poora Availability Zone (AZ) down ho jaye, toh data safe rehta hai aur automatic failover ho jata hai.


2. **Increased database availability in the case of system upgrades like OS patching or DB Instance scaling.**
* *Wazahat:* Jab aap database ki patching ya scaling karte hain, toh RDS pehle standby instance ko update karta hai aur phir failover kar deta hai, jis se downtime bohot kam ho jata hai aur availability barqarar rehti hai.



*Kyunki baqi options ghalat hain:*

* *SQL optimization:* Multi-AZ ka SQL queries ya performance se koi talluq nahi hai (yeh standby passive hota hai).
* *Significantly increases database performance:* Traditional Multi-AZ performance barhane ke liye nahi hota (read performance ke liye hum **Read Replicas** use karte hain).
* *Different region:* Akhiri option mein kaha gaya hai ke "different region" mein replicate karta hai — jabkay hum ne pehle hi pada hai ke Multi-AZ hamesha **ek hi region ke andar alag-alag AZs** ke darmiyan hota hai, doosre region mein nahi!
