22. Question

A Solutions Architect is building a cloud infrastructure where Amazon EC2 instances require access to various AWS services, such as Amazon S3 and Amazon Redshift. The Architect will also need to provide access to system administrators so that the system administrators can deploy and test changes.

Which configuration should be used to ensure that access to the resources is secured and not compromised? (Select TWO.)

- Store the AWS Access Keys in the EC2 instance.
- `Enable Multi-Factor Authentication.`
- `Assign an IAM role to the EC2 instance.`
- Store the AWS Access Keys in ACM.
- Assign an IAM user for each EC2 Instance.


### Keywords Scan 🔍

1. **"Amazon EC2 instances require access to various AWS services, such as Amazon S3 and Amazon Redshift"**
* **Trigger:** EC2 instance ko baki AWS services se securely connect karwana -> **IAM Role attached to EC2**.


2. **"provide access to system administrators so that the system administrators can deploy and test changes"**
* **Trigger:** Admin users/human access protection -> **Multi-Factor Authentication (MFA)**.



---

### Correct Answers (Select TWO)

1. **Assign an IAM role to the EC2 instance.**
2. **Enable Multi-Factor Authentication.**

---

### Roman Urdu Explanation 💡

* **1. EC2 ke liye IAM Role:**
* EC2 instances ko kisi bhi AWS service (S3, Redshift) par request bhejne ke liye **hardcoded Access Keys** ya credentials instance ke andar save nahi karne chahiyen.
* Sab se secure aur recommended tarika yeh hai ke aap ek **IAM Role** banayein aur usay EC2 instance ke sath attach kar dein. Instance temporary credentials use kar ke S3 aur Redshift ko securely access kar lega.


* **2. Admins ke liye Multi-Factor Authentication (MFA):**
* System administrators jo cloud environment mein deployment aur testing karte hain, unke accounts boht sensitive hote hain. Unki login security ko enhance karne ke liye **MFA (Multi-Factor Authentication)** enable karna zaroori hai taake agar password compromise bhi ho jaye toh account safe rahe.



---

### Baqi Options Ghalt Kyun Hain? ❌

* **Store AWS Access Keys in EC2 instance / ACM:** Access keys ko instance ke andar plain text ya kisi file mein store karna boht bara security risk hai. Access Key Manager (ACM) SSL/TLS certificates ke liye hota hai, keys store karne ke liye nahi.
* **Assign an IAM user for each EC2 Instance:** EC2 instances **Applications/Services** hain, insaan (Users) nahi. AWS mein services ko IAM Users nahi diye jaate, balki **IAM Roles** assign kiye jaate hain.
