A media company has two VPCs: VPC-1 and VPC-2 with peering connection between each other. VPC-1 only contains private subnets, while VPC-2 only contains public subnets. The company uses a single AWS Direct Connect connection and a virtual interface to connect its on-premises network with VPC-1.

Which of the following options increases the fault tolerance of the connection to VPC-1? (Select TWO.)

- `Establish a hardware VPN over the Internet between VPC-1 and the on-premises network.`
- Establish a hardware VPN over the Internet between VPC-2 and the on-premises network.
- `Establish a separate Direct Connect connection and private virtual interface in the same AWS region as VPC-1.`
- Use the AWS VPN CloudHub to create a new Direct Connect connection and private virtual interface in the same region as VPC-2.
- Establish a separate Direct Connect connection and private virtual interface in the same AWS Region as VPC-2.

### Direct Connect vs VPN (Simple Summary)

1. **Direct Connect (DX) = Physical Cable (Taar / Dedicated Fiber):**
* Yeh air signals ya public internet **nahi** hai.
* Yeh ek physical, dedicated fiber-optic cable hoti hai jo aap ke On-Premises Data Center se AWS Data Center tak seedhi lati hai. Isme maximum speed, low latency, aur zero internet fluctuation milti hai.


2. **Hardware VPN = Internet Signals (Encrypted Tunnel):**
* Yeh aap ke regular public internet connection ke ooper ek secure, encrypted tunnel banata hai. Iske liye koi alag se tar (cable) nahi bichani padti.



---

### Zero Risk Architecture (Redundancy / Fault Tolerance)

To prevent any network failure between **On-Premises** and **VPC-1**:

```
                                  ┌─── Physical Dedicated Fiber (Primary DX) ───┐
                                  │                                             │
[ On-Premises Data Center ] ──────┼─────────────────────────────────────────────┼──────> [ AWS VPC-1 ]
                                  │                                             │
                                  └─── Internet Hardware VPN (Backup Tunnel) ───┘

```

* **Primary Path:** **Direct Connect (Physical Cable)** se sara high-speed heavy traffic jata hai.
* **Backup Path:** Agar raste mein kisi wajah se wo physical tar (cable) cut ho jaye, toh traffic minute ke andar automatic switched hokar **VPN (Internet Tunnel)** ke raste **VPC-1** pohnch jata hai.

Is tarah connection bilkul **Zero Risk** aur **Fault-Tolerant** ban jata hai!
