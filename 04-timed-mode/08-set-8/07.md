7. Question

A company is developing a scheduled job that copies a backup of its virtual machines (VMs) to an Amazon S3 bucket. To avoid tampering, these backups must be protected against overwrites. They should also be retained for 20 days before being automatically deleted.

Which combination of actions will meet these requirements? (Select TWO.)

- `Make a new S3 bucket and enable S3 Object Lock. Set a 20-day retention period.`
- Create an automated solution that tags objects to be covered by a 20-day retention policy.
- Make a new S3 bucket and enable Versioning.
- `Set the objects to expire after 20 days using an S3 Lifecycle policy.`
- Make a new S3 bucket and enable S3 Object Lock. Set a 20-day legal hold.

Aapne bilkul theek point raise kiya hai, aur TutorialDojo ka answer is context mein **100% correct** hai!

Aaiye samajhte hain ke TutorialDojo ne Versioning ke bajaye Lifecycle Policy kyun select ki aur iska asli technical concept kya hai:

---

### 🔍 Asli Concept Kya Hai? (Kyunki Versioning toh Object Lock ka hissa hai)

1. **Object Lock ki Requirement:** Jab aap S3 bucket par **Object Lock** enable karte hain, toh AWS **automatically** us bucket par S3 Versioning ko enable kar deta hai (behind the scenes). Is liye separately "Enable Versioning" select karne ki zaroorat nahi parti kyunki Object Lock khud hi versioning ko mandate/enable karta hai.
2. **Deletion / Expiration ka Masla:**
* Question mein kaha gaya hai ke backups ko **20 days ke baad automatically delete** hona chahiye.
* Jab aap Object Lock mein 20-day retention period set karte hain, toh uska matlab yeh hota hai ke *agle 20 dino tak koi us file ko delete ya overwrite nahi kar sakta* (WORM protection).
* Lekin 20 din poore hone ke baad file automatically delete ho jaye, iske liye aapko **S3 Lifecycle Policy** (Expire objects action) lagani parti hai taake retention period khatam hote hi purane backups khud-ba-khud clean up ho jayein aur storage cost barhe na.



Isi liye TutorialDojo ne in dono ka combination chuna:

1. **S3 Object Lock with 20-day retention** (tamper aur overwrite se bachane ke liye).
2. **S3 Lifecycle policy to expire objects after 20 days** (20 din baad unhein automatically delete karne ke liye).
