6. Question

A global enterprise leverages AWS to manage its operations. The organization’s application stores sensitive information across multiple Amazon S3 buckets distributed across various AWS Regions. Every day, the organization handles thousands of objects in these S3 buckets. The organization needs a solution to determine all S3 buckets that do not have versioning enabled.

Which approach will satisfy this requirement?

- Implement an AWS CloudTrail event to automatically determine all S3 buckets without versioning enabled.
- Set up an IAM Access Analyzer to identify all S3 buckets that do not have versioning enabled by using an external access analyzer to analyze bucket policies.
- Create an Amazon S3 Multi-Region Access Point to aggregate and analyze the versioning status of S3 buckets across multiple regions.
- `Utilize Amazon S3 Storage Lens to detect all S3 buckets that do not have versioning enabled.`

---

### 🧠 Question kya keh raha hai? (Scenario Breakdown)

1. **Global Scale:** Ek global enterprise ke paas mukhtalif AWS Regions mein bohat saare **Amazon S3 buckets** hain jahan rozana hazaaron objects store hote hain.
2. **Main Requirement:** Company ko ek aisa solution chahiye jo yeh pata laga sakay ke **kaun kaun se S3 buckets par "Versioning" enable nahi hai**.

---

### 🔍 Options ka Tajziya (Analysis):

* **Option 1 (AWS CloudTrail):** CloudTrail API calls aur user activity ko track karta hai (jaise kis ne kaun sa API run kiya), yeh bucket ki configuration ya versioning status check karne ke liye nahi hota.
* **Option 2 (IAM Access Analyzer):** Yeh resource policies ko analyze karta hai taake pata chal sakay ke koi bucket public ya external accounts ke liye open toh nahi hai. Yeh versioning status detect nahi karta.
* **Option 3 (S3 Multi-Region Access Point):** Yeh multi-region buckets ke sath applications ki connectivity aur global routing ke liye hota hai, monitoring ya posture check ke liye nahi.
* **Option 4 (Amazon S3 Storage Lens):** **S3 Storage Lens** AWS ki ek aisi powerful analytics service hai jo poori organization (ya multiple accounts aur regions) ke S3 buckets ki visibility, storage usage, cost trends, aur **security best practices (jaise bucket versioning status)** ko ek hi dashboard par dikhati hai. Iske zariye easily pata chal jata hai ke kahan versioning enable nahi hai.

---

### ✅ Correct Answer:

* **Utilize Amazon S3 Storage Lens to detect all S3 buckets that do not have versioning enabled.**
