A startup wants to improve service availability and fault tolerance by distributing incoming traffic across multiple servers. The company uses Auto Scaling Group (ASG) of Amazon EC2 instances in the us-east-1 region. They plan to deploy the same setup in the us-west-2 region.

The company wants to automatically redirect traffic away from unhealthy instances, irrespective of their region.

Which of the following policies fulfills the company’s needs?

- Use Amazon Route 53's geoproximity routing policy to distribute incoming traffic to the other region.
- `Configure Route 53 and opt for a multivalue answer routing policy.`
- Launch an Application Load Balancer within the us-east-1 region. Configure the target group to include the IP addresses of Amazon EC2 instances across the two regions.
- Set up an Application Load Balancer in the us-east-1 region and configure it with a target group containing EC2 instances from both regions, identified by their instance IDs.
