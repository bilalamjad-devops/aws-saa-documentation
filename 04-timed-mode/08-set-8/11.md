11. Question

A company uses Amazon EC2 instances, Amazon RDS, and Amazon S3 to run its application. During a recent review of its infrastructure costs, the company noticed unusual spending patterns.

The company wants to monitor usage costs and send alerts to the appropriate departments when there is unusual spending from its workload.

Which option will meet these requirements?

- Enable Amazon CloudWatch to monitor costs and detect unusual spending.
- Create a zero spend budget template in AWS Budgets.
- `In the AWS Billing and Cost Management console, create a cost monitor using AWS Cost Anomaly Detection.`
- Use AWS Cost Explorer and enable multi-year data at monthly granularity.

Is question aur iske sahi jawab ko asan Roman Urdu mein step-by-step samajhte hain:

---

### 1. Question Kya Keh Raha Hai? (Question ki Wazahat)

Company apni application teen main AWS services par chala rahi hai: **EC2**, **RDS**, aur **S3**.

Recent billing review mein unhon ne dekha ke unke kharchay (spending patterns) mein sudden spikes ya **unusual spending** aane lagi hai (jaise koi server bhool kar bada size ka on kar diya gaya ho ya suddenly traffic barhne se zyadatar bill aa gaya ho).

**Requirement:**

1. Workload ke kharchon par nazar rakhi jaye.
2. Jab bhi achanak koi ghair-mamooli (unusual) spending nazar aaye, toh **automatically mutalliqah departments ko alert/notification chala jaye**.

---

### 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answer Breakdown)

**Correct Option:**

> *In the AWS Billing and Cost Management console, create a cost monitor using AWS Cost Anomaly Detection.*

**Sahi jawab ki samjh:**

* **AWS Cost Anomaly Detection** ek machine-learning based feature hai jo AWS Billing console ke andar milta hai.
* Yeh service aapke purane billing history ko seekhti hai (learn karti hai). Jab bhi koi aisi cost aati hai jo aapke normal pattern se alag ho (unusual spike), toh yeh usay **anomaly** keh kar detect kar leti hai.
* Phir yeh **Amazon SNS** ya email ke zariye aapki team/department ko foran **alert** bhej deti hai taake bill aane se pehle hi masla hal ho jaye.

---

### 3. Baaqi Options Kyun Sahi Nahi Hain?

* **CloudWatch:** Yeh CPU utilization, memory ya performance metrics ko monitor karta hai, ML-based billing anomalies ke alerts ke liye native cost service nahi hai.
* **AWS Budgets (Zero Spend):** Zero spend budget sirf tab trigger hota hai jab pehli baar $0.01 ka bill bano (yani free tier cross ho). Yeh regular running infrastructure mein unusual spikes ko alert nahi karta.
* **Cost Explorer (Multi-year granularity):** Yeh purane bills ke graphs aur analytics dekhne ke liye hota hai, yeh automated anomaly detection alerts nahi bhejta.

**Anomaly** (انوملی) ka Urdu mein matlab hota hai **"ghair-mamooli baat"**, **"anokhi cheez"**, ya **"normal pattern se hut kar hone wala koi badlao"**.

Easy words mein samajhte hain:

* **Normal Situation:** Aapka rozana ka internet usage 2 GB hai.
* **Anomaly:** Achanak ek din aapka usage 50 GB ho jaye bina kisi wajeh ke — yeh ek **anomaly** (unusual spike) hai.

### AWS Cloud Context Mein:

AWS billing mein **Cost Anomaly** ka matlab hota hai **"Achanak bill ka ghair-mamooli tor par barh jana"**.

For example:
Aapka monthly EC2 bill normally **$100** aata hai. Lekin kisi glitch ya ghalti ki wajah se 2 din mein bill **$800** par pohnch jata hai. AWS **Cost Anomaly Detection** is sudden spike ko pehchan leta hai aur aapko alert bhej deta hai ke *"bhai dekh lo, kuch gadbad hai!"*
