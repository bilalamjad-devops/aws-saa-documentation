15. Question

A logistics company manages a fleet of delivery trucks equipped with GPS devices that periodically upload location data to an Amazon S3 bucket. Historically, the company used an Amazon EC2 Spot Fleet to process the GPS data in batches every night.

The processing typically takes 3 minutes to complete and requires at least 64 MB of memory. The company’s solutions architect is tasked with modifying the application to process GPS data as it is uploaded to the S3 bucket.

Which modification will achieve this objective in the MOST cost-effective manner?

- Set S3 Event Notifications to transmit GPS data files to an Amazon Kinesis Data Stream. Create a Lambda Function to periodically pull and process the data from the stream.
- Enable S3 Event Notifications to automatically forward the details of the GPS data file to an Amazon SNS topic. Set up an application in AWS Elastic Beanstalk wherein it processes the data files as they are uploaded after subscribing to the topic.
- `Configure S3 Event Notifications to populate an Amazon SQS queue with details of uploaded GPS data files. Assign an AWS Lambda function to process the data by retrieving the queue's messages.`
- Configure S3 Event Notifications to send GPS data files to an Amazon SNS topic. Establish an Amazon ECS service that processes data by subscribing to the topic.
