28. Question

An organization uses a Microsoft SQL Server database to support its suite of applications. The organization plans to transition to an Amazon Aurora PostgreSQL database while minimizing application code modifications.

Which combination of actions will achieve these objectives? (Select TWO.)

- Use Amazon Kinesis Data Streams for real-time data replication to Aurora PostgreSQL.
- `Turn on Babelfish on Aurora PostgreSQL to allow applications to continue using existing SQL queries`
- `Use AWS Schema Conversion Tool (AWS SCT) to convert the database schema and AWS Database Migration Service (AWS DMS) to migrate the data.`
- Use AWS AppConfig to manage configuration updates during the migration.
- Use AWS Glue to transform the SQL queries from the applications for compatibility with Aurora PostgreSQL.

### Question Kya Keh Raha Hai? ❓

* **Scenario:** Ek organization apni Microsoft SQL Server database ko **Amazon Aurora PostgreSQL** par shift karna chahti hai.
* **Requirement:** Migration ke doran **application code mein kam se kam modifications** karni paren. (Yani purani queries wese hi chalti rahein).
* **Task:** Aap ko **2 options** select karne hain jo is requirement ko sab se behtareen tareeqey se poora karein.

---

### Correct Answers Kya Keh Rahe Hain? 💡

Is sawal ke 2 sahi jawab yeh hain:

1. **Turn on Babelfish on Aurora PostgreSQL to allow applications to continue using existing SQL queries**
2. **Use AWS Schema Conversion Tool (AWS SCT) to convert the database schema and AWS Database Migration Service (AWS DMS) to migrate the data.**

---

### Wajah / Key Concepts 🔍

* **Babelfish for Aurora PostgreSQL:** Yeh ek zabardast feature hai jo Aurora PostgreSQL ko T-SQL (Microsoft SQL Server ki language) samajhne ke qabil banata hai. Is ki wajah se aap ko apni application ki SQL queries change nahi karni partiin, aur application seedha Aurora ke sath connect ho jati hai.
* **SCT aur DMS:** Jab bhi database migrate karna ho, **AWS Schema Conversion Tool (SCT)** database ke structure (schema) ko ek database engine se dusre mein convert karta hai, aur **AWS Database Migration Service (DMS)** data ko securely aur safely purane database se naye database mein transfer karta hai. Yeh AWS ke standard database migration tools hain.

**Babelfish for Aurora PostgreSQL** database ko is qabil banati hai ke woh **Microsoft SQL Server ki apni language (T-SQL)** ko direct samajh sake!

Isay mazeed asan lafzon mein samjhein:

* **Masla (Problem):** Aam tor par jab aap Microsoft SQL Server se PostgreSQL par shift karte hain, toh aap ko apni application ka saara SQL code aur queries change karni parti hain, kyunke SQL Server ki language (`T-SQL`) aur PostgreSQL ki language (`PL/pgSQL`) aapas mein milti nahi hain. Isme bohat waqt aur mehnat lagti hai.
* **Babelfish ka Solution:** Babelfish ek **translator** ka kaam karta hai. Jab aap Aurora PostgreSQL par Babelfish on kar dete hain, toh woh SQL Server ki queries aur wire protocol ko seedha accept aur execute karne ke qabil ho jata hai.
* **Faida:** Iska sab se bara faida yeh hai ke aap ko apni application ki queries ya code ko change kiye baghair seedha MS SQL Server se Aurora PostgreSQL par migrate karne ki ijazat mil jati hai.
