44. Question

A company has a web application hosted in AWS cloud where the application logs are sent to Amazon CloudWatch. Lately, the web application has been encountering some errors which can be resolved simply by restarting the instance.

What will you do to automatically restart the EC2 instances whenever the same application error occurs?

### Question Kya Keh Raha Hai? ❓

* **Scenario:** Ek web application ke logs **Amazon CloudWatch** mein ja rahe hain. Application mein kuch errors aa rahe hain jo sirf instance ko **restart (reboot)** karne se theek ho jate hain.
* **Requirement:** Aap chahte hain ke jab bhi wohi specific application error dobara aaye, toh EC2 instance **automatically restart** ho jaye.

---

### Correct Answer Kya Keh Raha Hai? 💡

* **First, look at the existing CloudWatch logs for keywords related to the application error to create a custom metric. Then, create a CloudWatch alarm for that custom metric which invokes an action to restart the EC2 instance.**

---

### Wajah aur Key Concepts 🔍

Is sawal ko hal karne ke liye do (2) simple baatein zehen mein rakhni hain:

1. **CloudWatch Logs vs. Flow Logs:**
* Application ke errors **CloudWatch Logs** mein record hote hain.
* *(Ghalat options mein "Flow logs" likha hai, jabke VPC Flow Logs sirf network traffic yani IPs aur packets ke liye hote hain, application errors ke liye nahi).*


2. **CloudWatch Alarm Actions:**
* Jab aap CloudWatch logs se custom metric bana lete hain, toh aap **CloudWatch Alarm** set karte hain.
* CloudWatch Alarm ke paas direct built-in action hota hai ke woh EC2 instance ko **Reboot (Restart)** kar sake, is liye isme kisi extra Lambda function ki zaroorat nahi parti.
