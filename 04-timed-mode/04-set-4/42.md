42. Question

A startup is planning to set up and govern a secure, compliant, multi-account AWS environment in preparation for its upcoming projects. The IT Manager requires the solution to have a dashboard for continuous detection of policy non-conformance and non-compliant resources across the enterprise, as well as to comply with the AWS multi-account strategy best practices.

Which of the following offers the easiest way to fulfill this task?

- Launch new AWS member accounts using the AWS CloudFormation StackSets. Use AWS Config to continuously track the configuration changes and set rules to monitor non-compliant resources. Set up a Multi-Account Multi-Region Data Aggregator to monitor compliance data for rules and accounts in an aggregated view
- Use AWS Service Catalog to launch new AWS member accounts. Configure AWS Service Catalog Launch Constraints to continuously track configuration changes and monitor non-compliant resources. Set up a Multi-Account Multi-Region Data Aggregator to monitor compliance data for rules and accounts in an aggregated view
- Establish connectivity to AWS through an AWS Direct Connect Partner to securely link on-premises environments to the new AWS accounts. Use AWS Organizations to manage and govern multiple accounts. Set up AWS Config to monitor non-compliant resources across the enterprise.
- `Use AWS Control Tower to launch a landing zone to automatically provision and configure new accounts through an Account Factory. Utilize the AWS Control Tower dashboard to monitor provisioned accounts across your enterprise. Set up preventive and detective guardrails for policy enforcement.`


### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Ek startup ek secure, compliant, aur multi-account AWS environment set up karna chahti hai.
* **Requirements:**
1. Ek aisa dashboard chahiye jo puri enterprise mein non-compliant resources aur policy violations ko continuously detect kar sake.
2. AWS multi-account strategy ke best practices ko follow karte hue isay **sab se asan tareeqay (easiest way)** se implement karna hai.



---

### Correct Answer Kya Keh Raha Hai? 💡

* **Use AWS Control Tower to launch a landing zone to automatically provision and configure new accounts through an Account Factory. Utilize the AWS Control Tower dashboard to monitor provisioned accounts across your enterprise. Set up preventive and detective guardrails for policy enforcement.**

---

### Asan Alfaz Mein Wazahat (Explanation) 🔍

* **AWS Control Tower:** Jab bhi exam mein **"multi-account environment"**, **"landing zone"**, **"Account Factory"**, aur **"guardrails (preventive/detective)"** ke sath-sath sab se asan/automated setup ki baat ho, toh baghair kisi shak ke **AWS Control Tower** select karna hai!
* Control Tower ek aisi service hai jo poori enterprise ke liye ek ready-made secure environment (Landing Zone) set kar deti hai. Isme Account Factory ke zariye naye accounts banana aasan hota hai, aur iska apna dashboard hota hai jo guardrails ke zariye compliance monitor karta hai.

---

### Baqi Options Ghalat Kyun Hain? ❌

* **CloudFormation StackSets ya Service Catalog ke zariye manual setup:** Yeh sab cheezein alag-alag configure karni parti hain (jaise AWS Config aggregators manually banana), jo ke bohot lamba aur complex process hai. Jabke **Control Tower** in sab ko automatically integrate karke ek single solution provide karta hai jo sab se asan ("easiest way") hai.
