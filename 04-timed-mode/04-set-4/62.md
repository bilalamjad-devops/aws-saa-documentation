62. Question

A newly hired Solutions Architect is checking all of the security groups and network access control list rules of the company’s AWS resources. For security purposes, the MS SQL connection via port 1433 of the database tier should be secured. Below is the security group configuration of their Microsoft SQL Server database:

<img width="905" height="280" alt="2020-01-11_08-59-07-8cf0adda84f8f9ecd6201220e6901cc5 (2)" src="https://github.com/user-attachments/assets/9cc61f6f-2e53-4087-838b-642c833fb14b" />



The application tier hosted in an Auto Scaling group of EC2 instances is the only identified resource that needs to connect to the database. The Architect should ensure that the architecture complies with the best practice of granting least privilege.

Which of the following changes should be made to the security group configuration?


- `For the MS SQL rule, change the Source to the security group ID attached to the application tier.`
- For the MS SQL rule, change the Source to the Network ACL ID attached to the application tier.
- For the MS SQL rule, change the Source to the EC2 instance IDs of the underlying instances of the Auto Scaling group.
- For the MS SQL rule, change the Source to the static AnyCast IP address attached to the application tier.

### Is Image Mein Kya Dikha Raha Hai? 📸

Yeh image ek **AWS Security Group Inbound Rules** ka edit screen hai (jo pichle sawal se related hai). Isme do rules nazar aa rahe hain:

1. **Pehla Rule (RDP):** Port 3389 par admin access ke liye ek specific IP (`125.84.117.80/32`) di gayi hai.


2. **Dusra Rule (MS SQL):** Port 1433 par source **"Anywhere (`0.0.0.0/0, ::/0`)"** set hai.



---

### Yeh Image Aap Ko Kya Sikha Rahi Hai? 💡

Yeh image aap ko ek **bohat bara security mistake** dikha rahi hai aur uska hal sikha rahi hai:

* **Masla (The Flaw):** MS SQL ka source `Anywhere` hone ka matlab hai ke **puri duniya (internet par koi bhi) aap ke database ko access kar sakti hai!** Yeh ek bohot dangerous security risk hai.
* **Sahi Tareeqa (The Lesson / Least Privilege):**
Kyunke database ko sirf hamari Application Tier (ASG) ne access karna hai, is liye humein `Anywhere` ko hata kar wahan **Application tier ki Security Group ID** lagani chahiye.
Is se yeh hoga ke sirf wahi servers database se connect ho sakenge jo hamari app tier mein hain, baqi puri duniya ke liye database band ho jayega.
