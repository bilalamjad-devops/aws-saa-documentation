61. Question

A company has a fixed set of Amazon EC2 instances inside a VPC in the AWS cloud. The instances run a mission-critical application. In a recent incident, one of the EC2 instances suddenly powered down which affected the availability of the application. To avoid this incident in the future, the management wants to get notified of any upcoming AWS events that may affect these EC2 instances.

Which of the following options is the recommended action to meet the above requirements?

- `Create an Amazon EventBridge rule to check for AWS Health Dashboard events that are related to EC2 instances. To send notifications, set an Amazon SNS topic as a target for the rule.`
- Set up an Amazon EventBridge rule to check for any status change for EC2 instances. Set the target to an AWS Lambda function that will send a notification and restart the affected EC2 instances.
- Configure an Amazon CloudWatch alarm to monitor the status check metrics of the EC2 instances. Set an Amazon SNS topic as the alarm action to notify the operations team when an instance fails a status check.
- Create an Amazon EventBridge rule that is scheduled to run every 24 hours. Set the target to an AWS Lambda function that will check AWS Health Dashboard and send notifications for any events that may affect EC2 instances.
