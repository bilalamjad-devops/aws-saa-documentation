45. Question

A food company bought 50 licenses of Windows Server to be used by developers when launching Amazon EC2 instances to deploy and test applications. The company recently adopted AWS Systems Manager Application Manager to group and monitor EC2-based workloads by team.

The developers are free to provision EC2 instances as long as a license is available. The licenses are tied to the total CPU count of each virtual machine. The company wants to ensure that developers won’t be able to launch new instances once the licenses are exhausted, and wants to receive notifications when all licenses are in use.

Which of the following options is the recommended solution to meet the company’s requirements?

- `Define licensing rules on AWS License Manager to track and control license usage. Enable the option to “Enforce license limit” to prevent going over the number of allocated licenses. Add an Amazon SNS topic to send notifications and alerts.`
- Configure AWS Resource Access Manager (AWS RAM) to track and control the licenses used by AWS resources. Configure AWS RAM to provide available licenses for EC2 instances. Set up an Amazon SNS to send notifications and alerts once all licenses are used.
- Define license configuration rules on AWS Certificate Manager to track and control license usage. Enable the option to “Enforce certificate limit” to prevent going over the number of allocated licenses. Add an Amazon SQS queue with ChangeVisibility Timeout configured to send notifications and alerts.
- Upload the licenses on AWS Systems Manager Fleet Manager to be encrypted and distributed to EC2 instances. Attach an IAM role on the EC2 instances to request a license from the Fleet Manager. Set up an Amazon SNS to send notifications and alerts once all licenses are used.

### Question Kya Keh Raha Hai? ❓

* **Scenario:** Ek company ne Windows Server ke **50 licenses** kharide hain jo developers EC2 instances banate waqt use karte hain.
* **Requirements:**
1. Jab sab licenses khatam ho jayein, toh developers mazeed instances launch na kar sakein (**Enforce license limit**).
2. Jaise hi licenses khatam hon, team ko **notification** mil jaye (Amazon SNS ke zariye).



---

### Correct Answer Kya Keh Raha Hai? 💡

* **Define licensing rules on AWS License Manager to track and control license usage. Enable the option to “Enforce license limit” to prevent going over the number of allocated licenses. Add an Amazon SNS topic to send notifications and alerts.**

---

### Wajah aur Key Concepts 🔍

* **AWS License Manager:** AWS mein software licenses (jaise Microsoft Windows Server, SQL Server, Oracle) ko manage, track aur control karne ke liye specially **AWS License Manager** service bani hai.
* Isme aap rules set kar sakte hain ke maximum kitne licenses use ho sakte hain. Agar aap "Enforce license limit" on kar dein, toh limit poori hone ke baad AWS naye instances launch nahi hone deta, aur aap **Amazon SNS** ke sath connect karke alerts bhi hasil kar sakte hain.
* *(Dusre options galat kyun hain? AWS RAM resources share karne ke liye hota hai, Certificate Manager SSL certificates ke liye hai, aur Fleet Manager OS-level management ke liye hota hai).*
