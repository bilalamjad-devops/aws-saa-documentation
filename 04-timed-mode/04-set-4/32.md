32. Question

A Solutions Architect is designing a monitoring application that generates audit logs of all operational activities of the company’s cloud infrastructure. The IT Security and Compliance team mandates that the application retain the logs for 5 years before the data can be deleted.

How can the Architect meet the above requirement?

- Store the audit logs in an Amazon S3 bucket and enable Multi-Factor Authentication Delete (MFA Delete) on the S3 bucket.
- Store the audit logs in an Amazon EFS volume and use Network File System version 4 (NFSv4) file-locking mechanism.
- `Store the audit logs in an Amazon S3 bucket with versioning and S3 Object Lock enabled in Compliance mode.`
- Store the audit logs in an Amazon EBS volume and then take EBS snapshots every month.

### Question Kya Keh Raha Hai? ❓

* **Scenario:** Ek monitoring application cloud infrastructure ke audit logs generate kar rahi hai.
* **Requirement:** IT Security aur Compliance team ki strict policy hai ke **logs ko 5 saal tak retain kiya jaye** aur koi bhi unhein 5 saal se pehle delete na kar sake.
* **Goal:** Is strict compliance aur retention requirement ko poora karne ka sab se behtareen tareeqa konsa hai?

---

### Correct Answer Kya Keh Raha Hai? 💡

* **Store the audit logs in an Amazon S3 bucket with versioning and S3 Object Lock enabled in Compliance mode.**
* **Wajah (Reason):** **S3 Object Lock** ka **Compliance mode** WORM (Write Once, Read Many) model par kaam karta hai. Iska matlab yeh hai ke jab aap retention period (jaise 5 saal) set kar dete hain, toh koi bhi user—yahan tak ke AWS account ka **root user** bhi—us data ko delete ya overwrite nahi kar sakta jab tak woh muddat poori na ho jaye. Yeh regulatory compliance aur audit logs ke liye ek mandatory feature hai.
* *(Note: MFA Delete sirf accidental deletion ko roknay ke liye hota hai, yeh enforce nahi karta ke 5 saal tak koi delete na kar sakay).*
