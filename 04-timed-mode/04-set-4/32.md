32. Question
A Solutions Architect is designing a monitoring application that generates audit logs of all operational activities of the company’s cloud infrastructure. The IT Security and Compliance team mandates that the application retain the logs for 5 years before the data can be deleted.

How can the Architect meet the above requirement?

Store the audit logs in an Amazon S3 bucket and enable Multi-Factor Authentication Delete (MFA Delete) on the S3 bucket.
Store the audit logs in an Amazon EFS volume and use Network File System version 4 (NFSv4) file-locking mechanism.
Store the audit logs in an Amazon S3 bucket with versioning and S3 Object Lock enabled in Compliance mode.
Store the audit logs in an Amazon EBS volume and then take EBS snapshots every month.
