54. Question

A startup plans to develop a multiplayer game that uses UDP as the protocol for communication between clients and game servers. The data of the users will be stored in a key-value store. As the Solutions Architect, you need to implement a solution that will distribute the traffic across a number of servers.

Which of the following could help you achieve this requirement?

- Distribute the traffic using Network Load Balancer and store the data in Amazon Aurora.
- Distribute the traffic using Application Load Balancer and store the data in Amazon RDS.
- Distribute the traffic using Application Load Balancer and store the data in Amazon DynamoDB.
- `Distribute the traffic using Network Load Balancer and store the data in Amazon DynamoDB.`

### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Ek startup ek multiplayer game bana rahi hai jisme clients aur game servers ke darmiyan communication ke liye **UDP protocol** use hoga.
* **Requirements:**
1. User ka data ek **key-value store** mein save hona chahiye.
2. Game servers par traffic distribute karne ke liye sahi load balancer choose karna hai.



---

### Correct Answer Kya Keh Raha Hai? 💡

* **Distribute the traffic using Network Load Balancer and store the data in Amazon DynamoDB.**

---

### Wajah aur Key Concepts (Asan Alfaz Mein) 🔍

Is sawal ko hal karne ke liye do (2) sab se baray clues hain:

1. **UDP Protocol ke liye Network Load Balancer (NLB):**
* **Application Load Balancer (ALB)** sirf web traffic (HTTP/HTTPS) ke liye hota hai aur **UDP support nahi karta**.
* Jab bhi UDP traffic (jaise gaming ya live streaming) ko distribute karna ho, toh hamesha **Network Load Balancer (NLB)** use hota hai jo Layer 4 (Transport layer) par kaam karta hai aur UDP ko easily handle kar leta hai.


2. **Key-Value Store ke liye Amazon DynamoDB:**
* Sawal mein specifically **"key-value store"** ka zikr hai. **Amazon DynamoDB** ek NoSQL key-value database hai.
* Dusre options mein Amazon RDS aur Aurora diya gaya hai, jo relational (SQL) databases hain, key-value store nahi.
