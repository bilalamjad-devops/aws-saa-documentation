46. Question

A company plans to migrate a NoSQL database to an EC2 instance. The database is configured to replicate the data automatically to keep multiple copies of data for redundancy. The Solutions Architect needs to launch an instance that has a high IOPS and sequential read/write access.

Which of the following options fulfills the requirement if I/O throughput is the highest priority?

- Use General purpose instances with EBS volume.
- Use Compute optimized instance with instance store volume.
- `Use Storage optimized instances with instance store volume.`
- Use Memory optimized instances with EBS volume.

### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Company ek NoSQL database ko EC2 instance par migrate kar rahi hai. Database **khud automatic replication** karta hai (yani data ki redundancy/copies application/database level par handle ho rahi hain).
* **Requirement:** Solutions Architect ko ek aisi instance chahiye jisme **high IOPS aur sequential read/write access** ho, aur **I/O throughput sab se highest priority** ho.

---

### Correct Answer Kya Keh Raha Hai? 💡

* **Use Storage optimized instances with instance store volume.**

---

### Asan Alfaz Mein Wazahat (Explanation) 🔍

* **Storage Optimized Instances (jaise `i3`, `i4i` families):** Yeh instances specifically heavy read/write workloads, NoSQL databases, aur data-intensive applications ke liye bani hoti hain.
* **Instance Store Volumes:** Instance store physical disk hoti hai jo seedha server ke hardware ke sath attached hoti hai (network-based nahi hoti). Iski wajah se yeh **extremely high IOPS, massive throughput, aur ultra-low latency** deti hai.
* **NoSQL Replication ka faida:** Kyunke NoSQL database khud data ki multiple copies doosre nodes par replicate kar raha hota hai, is liye local instance store ka data agar lost bhi ho jaye (instance band hone par), toh bhi data safe rehta hai. Is tarah hum speed aur throughput maximize karne ke liye instance store use kar sakte hain.
