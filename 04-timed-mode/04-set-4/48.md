48. Question

A company is looking to store its confidential financial files in AWS, which are accessed every week. The Architect was instructed to set up the storage system, which uses envelope encryption and automates key rotation. It should also provide an audit trail that shows who used the encryption key and by whom for security purposes.

Which combination of actions should the Architect implement to satisfy the requirement in the most cost-effective way? (Select TWO.)

- `Use Amazon S3 to store the data.`
- Configure Server-Side Encryption with Amazon S3-Managed Keys (SSE-S3).
- Use Amazon S3 Glacier Deep Archive to store the data.
- Configure Server-Side Encryption with Customer-Provided Keys (SSE-C).
- `Configure Server-Side Encryption with AWS KMS Keys (SSE-KMS).`

### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Company apne confidential financial files AWS mein store karna chahti hai jo **har hafte (every week)** access hoti hain.
* **Requirements:**
1. **Envelope encryption** use honi chahiye.
2. Encryption keys ki **automatic key rotation** honi chahiye.
3. Security ke liye ek **audit trail** milna chahiye jo yeh dikhaye ke key kisne aur kab use ki (CloudTrail integration).
4. Sab kuch **cost-effective** tareeqay se ho.



---

### Correct Answers (Select TWO) 💡

1. **Use Amazon S3 to store the data.**
2. **Configure Server-Side Encryption with AWS KMS Keys (SSE-KMS).**

---

### Asan Alfaz Mein Wazahat (Explanation) 🔍

* **Amazon S3 (Storage ke liye):** Kyunke files har hafte access hoti hain, is liye S3 Standard sab se behtareen aur cost-effective option hai. *Amazon S3 Glacier Deep Archive* bilkul cold storage ke liye hota hai jahan files saalon tak rakhi jati hain aur weekly access ke liye woh mehanga par jata hai.
* **SSE-KMS (Encryption aur Key Rotation ke liye):**
* **Envelope Encryption** aur **Automatic Key Rotation** sirf AWS KMS (Key Management Service) ke zariye milti hai.
* KMS automatically **AWS CloudTrail** ke sath integrate ho kar complete audit trail deta hai ke kis user ya service ne key ko kab use kiya.
* *SSE-S3* mein automatic key rotation ya user-level detailed CloudTrail audit trail is tarah customizable nahi hoti, aur *SSE-C* mein keys customer khud manage karta hai AWS automatically rotate nahi karta.
