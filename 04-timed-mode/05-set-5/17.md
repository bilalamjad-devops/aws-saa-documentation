17. Question

Amazon Elastic Kubernetes Service (Amazon EKS) with IAM Role for Service Accounts (IRSA) is used by an e-commerce company to deploy and manage its containerized applications. The website experiences a surge in traffic around the holidays, which significantly adds to the effort. The goal is to ensure that its underlying infrastructure automatically scales in and out in response to demand.

Which of the following would meet the requirements with the LEAST amount of operational overhead? (Select TWO.)

- `Install the Kubernetes Metrics Server on the EKS cluster and activate the Horizontal Pod Autoscaling.`
- Enable the Cluster Autoscaler for EKS to automatically manage the number of nodes based on the resource needs of the pods.
- `Set up Karpenter to automatically adjust the number of nodes in the EKS cluster when pods fail or are rescheduled onto other nodes.`
- Install the Kubernetes Metrics Server on the EKS cluster and activate Vertical Pod Autoscaler.
- Use Amazon CloudWatch Alarms to trigger scaling for containerized applications.

### Apologies & Correction! 🙏

Aap bilkul theek keh rahe hain! TutorialsDojo ki key ke mutabiq, yeh dono options hi **correct** hain:

1. **Install the Kubernetes Metrics Server on the EKS cluster and activate the Horizontal Pod Autoscaling.** (Pods ke liye)
2. **Set up Karpenter to automatically adjust the number of nodes in the EKS cluster when pods fail or are rescheduled onto other nodes.** (Nodes ke liye)

---

### Karpenter Is Question Mein Kyun Sahi Hai? 💡

* **Modern & Fast Scaling:** AWS mein ab traditional Cluster Autoscaler ke sath-sath **Karpenter** ko bohot recommend kiya jata hai kyunki yeh ek high-performance, open-source node autoscaler hai.
* Yeh pending ya unschedulable pods ko detect karke kuch hi seconds mein exact-fit EC2 nodes provision kar deta hai, jisse provisioning time aur operational overhead dono minimize ho jate hain.

Is liye **HPA (Metrics Server ke sath)** pods ko manage karta hai aur **Karpenter** underlying nodes ko fast tareeqay se scale karta hai—yeh ek complete modern EKS scaling combination hai. Good catch!
