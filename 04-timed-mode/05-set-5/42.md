42. Question

A business plans to deploy an application on EC2 instances within an Amazon VPC and is considering adopting a Network Load Balancer to distribute incoming traffic among the instances. A solutions architect needs to suggest a solution that will enable the security team to inspect traffic entering and exiting their VPC.

Which approach satisfies the requirements?

- Use the Network Access Analyzer service on the application’s VPC for inspecting ingress and egress traffic. Create a new Network Access Scope to filter and analyze all incoming and outgoing requests.
- Enable Traffic Mirroring on the Network Load Balancer and forward traffic to the instances. Create a traffic mirror filter to inspect the ingress and egress of data that traverses your Amazon VPC.
- `Create a firewall using the AWS Network Firewall service at the VPC level then add custom rule groups for inspecting ingress and egress traffic. Update the necessary VPC route tables.`
- Create a firewall at the subnet level using the Amazon Detective service. Inspect the ingress and egress traffic using the VPC Reachability Analyzer.

### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Ek business apna application Amazon VPC ke andar EC2 instances par deploy kar raha hai aur incoming traffic distribute karne ke liye Network Load Balancer (NLB) use kar raha hai.
* **Requirement:** Security team ki requirement yeh hai ke **VPC ke andar enter hone wale aur wahan se exit hone wale traffic (ingress and egress)** ko mukammal taur par **inspect (check)** kiya ja sakay.

---

### Correct Answer Kya Keh Raha Hai? 💡

* **Create a firewall using the AWS Network Firewall service at the VPC level then add custom rule groups for inspecting ingress and egress traffic. Update the necessary VPC route tables.**

---

### Asan Alfaz Mein Wazahat (Explanation) 🔍

* **AWS Network Firewall:** Yeh ek fully managed service hai jo aap ko apne VPCs par network protections deploy karne ki ijazat deti hai. Iske zariye aap custom rule groups (Stateless aur Stateful rules) bana kar VPC ke andar aane wale (ingress) aur bahar jane wale (egress) traffic ko live inspect aur filter kar sakte hain. Isko implement karne ke liye VPC ke route tables ko update kiya jata hai taake traffic firewall se hokar guzrey.

---

### Baqi Options Ghalat Kyun Hain? ❌

* **Network Access Analyzer:** Yeh ek static configuration analysis tool hai jo yeh check karta hai ke aap ke resources tak kahan se access mil sakti hai, lekin yeh live traffic inspection ya firewall nahi hai.
* **Traffic Mirroring on NLB:** Traffic mirroring network packets ki copy banakar kisi third-party security appliance ko bhejti hai, lekin yeh khud ek inline firewall ya traffic inspection service nahi hai jo rule-based filtering kar sakay.
* **Amazon Detective & Reachability Analyzer:** Amazon Detective security investigations aur findings analyze karne ke liye hota hai, aur Reachability Analyzer sirf network path reachability test karne ke liye use hota hai—yeh dono firewall ya traffic inspection ke liye nahi hain.
