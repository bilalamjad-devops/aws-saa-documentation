57. Question

A Solutions Architect is migrating several Windows-based applications to AWS that require a scalable file system storage for high-performance computing (HPC). The storage service must have full support for the SMB protocol and Windows NTFS, Active Directory (AD) integration, and Distributed File System (DFS).

Which of the following is the MOST suitable storage service that the Architect should use to fulfill this scenario?

- Amazon S3 Glacier Deep Archive
- `Amazon FSx for Windows File Server`
- Amazon FSx for Lustre
- AWS DataSync

**HPC (High-Performance Computing)** ka keyword dekh kar yahan **FSx for Lustre** ka khayal ana bilkul aam hai, lekin is question mein Lustre isliye ghalat ho jata hai kyunke sawal ki **core requirements** kuch aisi hain jo sirf Windows File Server hi pori kar sakta hai:

### Lustre Kyun Nahi Choose Kar Sakte? ❌

1. **OS aur Protocol ka Farq (Linux vs. Windows):**
* **FSx for Lustre** aik **POSIX-compliant** file system hai jo bunyadi tor par **Linux** environments ke liye design kiya gaya hai.
* Jabke sawal mein saaf bataya gaya hai ke application **Windows-based** hai aur usay **SMB protocol** aur **Windows NTFS** ki mukammal support chahiye. Lustre native Windows NTFS ACLs ko support nahi karta.


2. **Active Directory (AD) aur DFS Support:**
* Sawal ki requirement hai ke **Active Directory (AD) integration** aur **Distributed File System (DFS)** ka hona lazmi hai.
* **FSx for Lustre** Microsoft Active Directory ya DFS (Distributed File System) ko support **nahi** karta. Yeh features sirf **Amazon FSx for Windows File Server** ke paas hain.



---

### Sahi Jawab Kaun Sa Hai Phir? ✅

* **Amazon FSx for Windows File Server** halanke enterprise Windows workloads ke liye hai, lekin yeh high-performance storage capability bhi rakhta hai aur sath hi sath **SMB, Windows NTFS, Active Directory integration, aur DFS** ki 100% native support bhi deta hai. Is liye exam mein jab bhi Windows-based file shares aur AD/DFS ki baat ho, hamesha FSx for Windows File Server hi select kiya jata hai.
