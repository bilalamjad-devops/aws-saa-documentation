47. Question

A company has multiple research departments that independently provision AWS resources for its projects. As resource usage continues to increase, the company wants to proactively monitor AWS service quota utilization and prevent unexpected disruptions caused by reaching service quota limits.
The solution must automatically monitor supported service quotas, notify cloud administrators when utilization approaches the configured thresholds, and minimize operational overhead. The company does not require automatic quota increases.

Which combination of actions should a Solutions Architect implement to meet these requirements? (Select TWO.)

- `Configure AWS User Notifications with the preferred notification channels to alert cloud administrators when AWS Service Quotas Automatic Management detects quota utilization thresholds being reached.`
- Utilize the AWS managed rule on AWS Config to monitor AWS resource service quotas. Schedule this checking using an AWS Lambda function.
- Create an Amazon Simple Notification Service (Amazon SNS) topic and configure it as a target for notifications.
- Query the AWS Trusted Advisor Service Limits check every 24 hours by calling the DescribeTrustedAdvisorChecks API operation. Ensure that your AWS account has a Business Support+ plan.
- `Enable AWS Service Quotas Automatic Management in Notify Only mode to continuously monitor supported service quota utilization and identify when configured thresholds are reached.`

### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Ek company ke mukhtalif research departments independently AWS resources provision kar rahe hain. Resource usage barhne ki wajah se company proactively **AWS service quotas** ko monitor karna chahti hai taake limits reach hone par unexpected disruptions se bacha ja sakay.
* **Requirements:**
1. Supported service quotas ko automatically monitor karna hai.
2. Jab utilization configured thresholds ke kareeb pohnche toh cloud administrators ko **notify** karna hai.
3. **Operational overhead ko minimum** rakhna hai.
4. **Automatic quota increases ki zaroorat nahi hai**. (Select TWO options).



---

### Correct Answers (Select TWO) 💡

1. **Create an Amazon Simple Notification Service (Amazon SNS) topic and configure it as a target for notifications.**
2. **Query the AWS Trusted Advisor Service Limits check every 24 hours by calling the DescribeTrustedAdvisorChecks API operation. Ensure that your AWS account has a Business Support+ plan.** *(Note: AWS Trusted Advisor automatically monitors service limits against thresholds and can send notifications via SNS).*

---

### Asan Alfaz Mein Wazahat (Explanation) 🔍

* **AWS Trusted Advisor & SNS:** AWS Trusted Advisor mein built-in **Service Limits** (Service Quotas) ke checks hotay hain jo aap ke account mein resource usage ko monitor karte hain aur batate hain ke aap current limits ke kitne kareeb hain. Isko **Amazon SNS** ke sath configure karne par, jab bhi koi quota threshold breach hone lagti hai ya warning aati hai, administrators ko foran notification mil jata hai. Business ya Enterprise support plan hone par yeh API/automated monitoring easily set up ho jati hai baghair kisi complex custom code ke.

---

### Baqi Options Ghalat Kyun Hain? ❌

* **AWS Config Managed Rule + Lambda:** AWS Config aur Lambda ke zariye khud custom rules likh kar checking schedule karna bohot zyadah **operational overhead** paida karta hai, jabke Trusted Advisor ek managed service hai jo yeh kaam out-of-the-box karti hai.
* **Automatic Management / User Notifications options:** Service Quotas ki standard monitoring ke liye Trusted Advisor aur CloudWatch/SNS ka combination standard AWS best practice hai.
