59. Question

A health organization is using a large Dedicated Amazon EC2 instance with multiple Amazon EBS volumes to host its health records web application. To ensure compliance and consistency, the organization uses AWS Systems Manager State Manager to automatically enforce baseline configurations.

The EBS volumes must be encrypted to protect the confidentiality of the data and to comply with the HIPAA (Health Insurance Portability and Accountability Act) standard.

In EBS encryption, which of the following does AWS use to secure data at rest on the volume? (Select TWO.)

- By using Amazon S3 Server-Side Encryption and S3 Client-Side Encryption.
- By using the SSL certificates provided by the AWS Certificate Manager (ACM).
- `By using Amazon-managed keys in AWS Key Management Service (KMS).`
- `By using your own keys in AWS Key Management Service (KMS).`
- By using a password stored in AWS CloudHSM.

### Sawal Kya Keh Raha Hai? ❓

* **Scenario:** Ek health organization Amazon EC2 instance aur multiple EBS volumes par health records web application host kar rahi hai. HIPAA compliance ke mutabiq EBS volumes ka data at rest **encrypted** hona lazmi hai.
* **Requirement:** EBS encryption mein AWS data ko secure karne ke liye kis cheez ka istemal karta hai? **(Select TWO)**

---

### Correct Answers (Select TWO) 💡

1. **By using Amazon-managed keys in AWS Key Management Service (KMS).**
2. **By using your own keys in AWS Key Management Service (KMS).**

---

### Asan Alfaz Mein Wazahat (Explanation) 🔍

* **AWS KMS (Key Management Service):** Amazon EBS ki encryption mukammal tor par **AWS KMS** par depend karti hai.
* Aap ya toh AWS ki taraf se di gayi default key (**Amazon-managed key**, jiska alias `aws/ebs` hota hai) use kar sakte hain.
* Ya phir apni khud ki custom keys (**Customer-managed keys / your own keys**) KMS mein create kar ke EBS volume encryption ke liye select kar sakte hain.


* Baqi options (jaise S3 encryption ya ACM SSL certificates) ka EBS volumes ki encryption se koi taluq nahi hai.
