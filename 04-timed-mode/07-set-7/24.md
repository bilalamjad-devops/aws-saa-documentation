24. Question

A company conducted a surprise IT audit on all of the AWS resources being used in the production environment. During the audit activities, it was noted that you are using a combination of Standard and Convertible Reserved EC2 instances in your applications.

Which of the following are the characteristics and benefits of using these two types of Reserved EC2 instances? (Select TWO.)

- Unused Convertible Reserved Instances can later be sold at the Reserved Instance Marketplace.
- `Unused Standard Reserved Instances can later be sold at the Reserved Instance Marketplace.`
- It runs in a VPC on hardware that's dedicated to a single customer.
- It can enable you to reserve capacity for your Amazon EC2 instances in multiple Availability Zones and multiple AWS Regions for any duration.
- `Convertible Reserved Instances allow you to exchange for another convertible reserved instance of a different instance family.`

Aaiye is sawal ko apne crisp, fast-track aur keyword-focused breakdown ke sath samajhte hain! 🚀

---

### 🎯 1. Sawal Kya Keh Raha Hai? (Question Breakdown)

Aap ke production environment mein **Standard Reserved Instances (RIs)** aur **Convertible Reserved Instances (RIs)** ka combination use ho raha hai.

* **Requirement:**
Dono Reserved Instance types (Standard vs Convertible) ke sahi characteristics aur benefits select karne hain (**Select TWO**).

---

### ✅ 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answers)

> 1. **Unused Standard Reserved Instances can later be sold at the Reserved Instance Marketplace.**
> 2. **Convertible Reserved Instances allow you to exchange for another convertible reserved instance of a different instance family.**
> 
> 

#### **Deep-Dive Explanation:**

1. **Standard RIs ➔ Marketplace Selling:** Agar aap ke paas **Standard RIs** unused reh jayen (maslan workload khatam ho jaye), toh aap unhein **AWS Reserved Instance Marketplace** par doosre AWS customers ko sell kar sakte hain. (Convertible RIs sell nahi ho sakte).
2. **Convertible RIs ➔ Flexibility to Change Family:** **Convertible RIs** aap ko yeh flexibility dete hain ke aap instance family, OS, ya tenancy change/exchange kar sakein (e.g., `t3.medium` se `m5.large` mein shift ho sakte hain), bashartay new instance ki value barabar ya zyada ho.

---

### ❌ 3. Baqi Options Kyun Ghalat Hain?

* **Unused Convertible Reserved Instances sold at Marketplace:**
* *Ghalat kyun?* Sirf **Standard RIs** Marketplace par sell ho sakte hain; Convertible RIs sell nahi ho sakte.


* **Runs in a VPC on hardware dedicated to a single customer:**
* *Ghalat kyun?* Yeh **Dedicated Instances / Dedicated Hosts** ki definition hai, Reserved Instances ki nahi.


* **Reserve capacity in multiple AZs & AWS Regions for any duration:**
* *Ghalat kyun?* Reserved Instances specific AZ (Capacity Reservation ke sath) ya Region (Regional RI without capacity reservation) par bind hote hain; multi-region cross-reservation directly work nahi karti aur duration fixed (1-year ya 3-year) hoti hai, "any duration" nahi.



---

### 🔍 4. Keyword Scanning & Exam Shortcut

| Question Key Phrases | Direct AWS Mapping | Reason / Logic |
| --- | --- | --- |
| **"Unused RIs" + "Sell to others"** | **Standard Reserved Instances** | Sirf Standard RIs Marketplace par sell ho sakte hain. |
| **"Exchange instance family"** | **Convertible Reserved Instances** | Convertible RIs allow changing instance type/family. |

---

### 🧠 One-Line Memory

> **Sell on Marketplace ➔ Standard RI | Exchange Instance Family ➔ Convertible RI**
