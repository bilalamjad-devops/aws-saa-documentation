11. Question

A digital company is using EC2 instances to host editing software that is remotely accessed by their teams. Due to licensing restrictions, the application cannot be deployed in the ap-southeast-1 (Singapore) region. A team based in the Philippines needs to access the application, requiring connectivity with latency in the single-digit millisecond range.

Which of the following solutions addresses these requirements?

- Launch the applications in the ap-southeast-1 region. Then, use AWS Outposts to extend the company’s VPC to an on-premises network in the Philippines.
- Use Amazon CloudFront’s edge locations to extend the company’s VPC to other countries in Asia. Launch the applications to the ap-southeast-1 region.
- Enable AWS Wavelength Zones within the ap-southeast-1 region. Extend the company's VPC to the selected Wavelength Zones and launch the applications in that zone.
- Enable AWS Local Zones within the ap-southeast-1 region. Extend the company's VPC to the selected Local Zone and launch the applications in that zone.

Aaiye, is sawal ko bilkul aasan alfaz mein mukammal tor par tor kar samajhte hain!

---

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) 🛑

* **Scenario:** Ek company apna editing software EC2 instances par chala rahi hai jise team remotely access karti hai.
* **Sab se Bari Rukawat (Licensing Restriction):** Sawal mein saaf saaf likha hai ke **yeh application kisi bhi halat mein `ap-southeast-1` (Singapore) region ke andar deploy nahi ki ja sakti**.
* **Users ki Location:** Team **Philippines** mein baithi hai, aur unhein app chalane ke liye **single-digit millisecond latency (bilkul zero lag / super fast speed)** chahiye.
* **Goal:** Aisa tareeqa dhoondna hai jahan app Singapore mein deploy *bhi na ho*, aur Philippines ki team ko super-fast speed mil jaye.

---

### 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answer) 💡

* **Option:** *Launch the applications in the ap-southeast-1 region. Then, use AWS Outposts to extend the company’s VPC to an on-premises network in the Philippines.*
*(Note: Is option ka maqsad yeh hai ke AWS ka control plane Singapore se ho, lekin physical server/hardware **Philippines ke on-premises data center** mein lagaya jaye).*
* **Wazahat:** Kyunki application ko Singapore ke cloud datacenter mein rakhna mana hai, hum **AWS Outposts** use karte hain. Outposts ek aisi physical machine (rack) hoti hai jo AWS aap ko bhejta hai aur aap ise **Philippines ke apne local office ya data center** mein rakh lete hain. Is se app physical tor par Philippines mein chalti hai, is liye Singapore region ki licensing restriction bhi toot'ti nahi hai aur Philippines ki team ko ultra-low latency mil jati hai.

---

### 4. AWS Outposts Kya Hai? 📦☁️

**AWS Outposts** ek **hybrid cloud** service hai.

* **Asan Alfaz mein:** Yeh AWS ka ek aam server rack (machine) hota hai jo bilkul waise hi kaam karta hai jaise AWS ka apna datacenter kaam karta hai, lekin fark yeh hai ke yeh machine **aap ke apne office ya on-premises data center** mein fit ki jati hai.
* **Kyun Use Hota Hai?**
1. Jab aap ko **ultra-low latency** chahiye ho (jaise local factory machines, hospitals, ya remote countries jahan AWS ka region door ho).
2. Jab **Data Residency ya Licensing laws** ki wajah se aap apna data ya software public cloud (jaise Singapore region) par na rakh sakein, balkay use apne local mulk mein rakhna lazmi ho.
