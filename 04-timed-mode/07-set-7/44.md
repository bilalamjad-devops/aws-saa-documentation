44. Question
A Solution Architect is working on a cloud infrastructure project for a company that uses AWS services. The company uses multiple EC2 and Amazon RDS DB instances on various applications. As part of the task, the company asked to create a solution that automatically starts and stops the EC2 and DB instances based on a predetermined schedule.

Which option will enable the Solution Architect to fulfill the company’s requirements while minimizing cost and infrastructure maintenance?

Set up a crontab schedule to run shell scripts that start and stop EC2 and RDS instances at specific times, enabling automatic management of the instances based on the predetermined schedule.
Generate an AWS Lambda function to start and stop EC2 and RDS DB instances. Set up Amazon EventBridge (Amazon CloudWatch Events) to trigger the Lambda function based on a predefined schedule.
Utilize elastic resizing to scale the EC2 instances and automatically scale the DB instances to zero during periods outside the predetermined schedule.
Search various partner solutions on the AWS Marketplace that offer automated start and stop functionalities for EC2 and RDS instances according to predefined schedules.
