63. Question
A company discovered that a significant portion of their monthly bill in the AWS Cloud was due to unused Amazon Elastic Block Store (EBS) volumes and snapshots. Having checked AWS Cost Explorer, the company expects this monthly cost to increase. The company wants to mitigate and optimize these EBS costs.

Which solution will meet these requirements with the LEAST operational overhead?

Create a custom script that deploys an AWS CDK application that monitors the disk space usage of EBS volumes and utilizes Amazon EBS Elastic Volumes to reduce the size of the EBS volumes.
Check the logs through Amazon Cloudwatch Logs to monitor the storage used by Amazon EBS. Then, utilize Amazon EBS Elastic Volumes to reduce the size of the EBS volumes.
Delete all expired and unused snapshots. Then, utilize the Amazon Data Lifecycle Manager to manage new snapshots.
Delete all expired and unused snapshots using the AWS CLI.
