Which of the following options is the MOST cost-effective way to transfer this data?

Connect the on-premises data center to AWS Direct Connect to provide a faster and more reliable connection for transferring the data from the S3 bucket. Enable S3 Transfer Acceleration in the bucket to speed up data transfers.
Create an AWS Lambda function to compress the data. Download the data over the internet using AWS DataSync.
Create an Amazon CloudFront distribution for the objects in the existing S3 bucket. Download the objects through an AWS Global Accelerator standard accelerator that is integrated with the CloudFront distribution.
