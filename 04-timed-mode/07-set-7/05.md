5. Question

A company has both an on-premises data center and AWS cloud infrastructure. Multimedia assets, such as graphics, audio, and videos, are primarily stored in an on-premises storage server, with an Amazon S3 Standard storage class bucket used for backup. The data is heavily utilized for only one week (7 days), but after that period, it is infrequently accessed by customers. The Solutions Architect is tasked with saving storage costs in AWS while maintaining the ability to retrieve a subset of media assets within minutes for an annual data audit, which will be conducted on cloud storage.

Which of the following are valid options that the Solutions Architect can implement to meet the above requirement? (Select TWO.)

- `Set a lifecycle policy in the bucket to transition the data from Standard storage class to Glacier Flexible Retrieval after one week (7 days).`
- `Set a lifecycle policy in the bucket to transition the data to S3 Standard-IA storage class after one week (7 days).`
- Set a lifecycle policy in the bucket to transition the data to the S3 Glacier Deep Archive storage class after one week (7 days).
- Set a lifecycle policy in the bucket to transition to S3 Standard-IA after 30 days.
- Set a lifecycle policy in the bucket to transition the data to the S3 One Zone-Infrequent Access storage class after 30 days.

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) ❓

* **Scenario:** Ek company ke paas on-premises storage server hai aur AWS S3 Standard bucket backup ke taur par use ho raha hai.
* **Data Usage:** Data sirf **1 hafta (7 days)** tak heavy use hota hai, uske baad infrequently access hota hai.
* **Requirements:**
1. AWS par storage costs bachani hain.
2. Annual data audit ke liye aisi storage class chahiye jahan se media assets **within minutes** (kuch minutes ya ghanton mein - Glacier Flexible Retrieval / Standard-IA support) retrieve kiye ja sakein, aur data cloud par hi audit ho sake.
3. **Select TWO (2) options.**



---

### 2. Sahi Jawabat Kya Keh Rahe Hain? (Correct Answers) 💡

* **Options:**
1. *Set a lifecycle policy in the bucket to transition the data from Standard storage class to Glacier Flexible Retrieval after one week (7 days).*
2. *Set a lifecycle policy in the bucket to transition the data to S3 Standard-IA storage class after one week (7 days).*


* **Wazahat:**
* **Option 1 (Glacier Flexible Retrieval after 7 days):** Data 7 din tak frequent use hota hai, uske baad saal bhar sirf ek dafa audit ke liye chahiye. S3 lifecycle policy ke zariye aap ise Glacier Flexible Retrieval mein bhej sakte hain jahan retrieval minutes (Standard retrievals 3-5 minutes) mein ho jati hai aur cost bohot kam ho jati hai.
* **Option 2 (S3 Standard-IA after 7 days):** Standard-IA infrequent access data ke liye hai aur ise bhi lifecycle policy ke through 7 din baad transition kiya ja sakta hai. (Aap S3 lifecycle rules ke zariye Standard-IA ya Glacier mein 7 din ke andar transition kar sakte hain — minimum storage duration charge apply hota hai lekin transition ki restriction nahi hoti).



*Kyunki baqi options ghalat hain:*

* *Glacier Deep Archive after 7 days:* Deep Archive ka retrieval time 12 hours tak le sakta hai (bulk/standard), aur audit ke liye "within minutes" retrieval requirement ke liye Flexible Retrieval ya IA zyada behtar hain.
* *30 days options:* Data sirf 1 hafta (7 days) frequent use hota hai, isliye 30 days tak wait karne se cost zaya hogi jabke requirement 7 din baad transition karne ki hai.
