13. Question

A company has a two-tier environment in its on-premises data center which is composed of an application tier and database tier. You are instructed to migrate their environment to the AWS cloud, and to design the subnets in their VPC with the following requirements:

1. There is an application load balancer that would distribute the incoming traffic among the servers in the application tier.

2. The application tier and the database tier must not be accessible from the public Internet. The application tier should only accept traffic coming from the load balancer.

3. The database tier contains very sensitive data. It must not share the same subnet with other AWS resources and its custom route table with other instances in the environment.

4. The environment must be highly available and scalable to handle a surge of incoming traffic over the Internet.

How many subnets should you create to meet the above requirements?

- 4
- 3
- 6
- 2

Aaiye, is sawal ko bhi apne isi behtareen pattern ke sath step-by-step tor kar samajhte hain!

---

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) 🛑

Aap ko ek VPC ka network architecture design karna hai jiske andar 3 layers hain aur **High Availability (HA)** ki shart hai:

1. **High Availability (Multi-AZ):** High availability ke liye kam se kam **2 Availability Zones (AZs)** use honge.
2. **Requirement 1 (ALB):** Public Load Balancer ke liye **Public Subnets** chahiye.
3. **Requirement 2 (App Tier):** Application servers internet se chhupay hue hone chahiye (Private), aur sirf Load Balancer se traffic accept karein. Iske liye **Private Subnets** chahiye.
4. **Requirement 3 (DB Tier):** Database bohot sensitive hai — yeh baqi kisi resource ya route table ke sath subnet share nahi kar sakta. Iske liye **Dedicated Isolated Private Subnets** chahiye.

---

### 2. Subnets Ka Complete Calculation (Math) 🔢

Kyunki **High Availability** ke liye humein 2 Availability Zones (AZ-1 aur AZ-2) mein subnets divide karne hain, aaiye har AZ ka hisab lagate hain:

| Tier / Layer | AZ 1 Subnet | AZ 2 Subnet | Total Subnets |
| --- | --- | --- | --- |
| **Public Tier (ALB)** | 1 Public Subnet | 1 Public Subnet | **2** |
| **App Tier (EC2)** | 1 Private Subnet | 1 Private Subnet | **2** |
| **DB Tier (Dedicated DB)** | 1 Isolated DB Subnet | 1 Isolated DB Subnet | **2** |
| **Total** | **3 Subnets** | **3 Subnets** | **6 Subnets** |

**Sahi Answer:** **6**

---

### 3. Sahi Jawab Ka Deep-Dive Logic 💡

* **ALB Subnets (2 Public):** Application Load Balancer ko Multi-AZ chalane ke liye kam se kam 2 alag AZs mein public subnets chahiye hote hain.
* **App Tier Subnets (2 Private):** Application instances private subnets mein hongi jinka route table NAT Gateway se juda hota hai (agar internet access chahiye ho) ya sirf ALB se traffic leti hain.
* **DB Tier Subnets (2 Dedicated Private):** Requirement 3 ke mutabiq database apna subnet kisi aur resource se share nahi kar sakta. Isliye DB ke liye alag se 2 isolated private subnets banaye jayenge jinka apna dedicated Custom Route Table hoga.

---

### 🔑 Exam Keyword Memory Trick

| Question Requirement | Direct AWS Subnet Formula |
| --- | --- |
| **3 Tiers (Public ALB + Private App + Dedicated Private DB) × Multi-AZ (2 AZs)** | **3 Tiers × 2 AZs = 6 Subnets** |
