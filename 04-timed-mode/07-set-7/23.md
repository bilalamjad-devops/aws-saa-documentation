### 🎯 1. Sawal Kya Keh Raha Hai? (What is the Question Saying?)

Agila Corporation ki DevOps Team ek aisi **IAM Policy** lagana chahti hai jismein 3 main conditions poori honi chahiye:

1. **Actions:** Sirf EC2 instances ko **start, stop, aur terminate** karne ki permission ho.
2. **Region:** Yeh saare actions sirf **us-west-1** region ke andar hone chahiye.
3. **Network / IP Restriction:** Company ke apne network range (**192.158.1.0/24**) ke ilawa agar koi baahir se request kare, toh usko **strictly DENY** kar diya jaye.

---

### ✅ 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answer)

Yeh option sahi policy represent karta hai:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "ec2:TerminateInstances",
                "ec2:StartInstances",
                "ec2:StopInstances"
            ],
            "Resource": "*",
            "Condition": {
                "StringEquals": {
                    "aws:RequestedRegion": "us-west-1"
                }
            }
        },
        {
            "Effect": "Deny",
            "Action": "ec2:*",
            "Resource": "*",
            "Condition": {
                "NotIpAddress": {
                    "aws:SourceIp": "192.158.1.0/24"
                }
            }
        }
    ]
}

```

#### **Deep-Dive Explanation (Wajah):**

1. **Phla Statement (Allow):** Ismein specifically Start, Stop, aur Terminate actions ko allow kiya gaya hai, lekin sath hi `StringEquals` condition laga kar restrict kar diya gaya hai ke yeh sirf **us-west-1** region mein chal sakte hain.
2. **Doosra Statement (Deny + NotIpAddress):** Yeh security ka sab se best practice tareeqa hai. `NotIpAddress` ke sath `Deny` lagane ka matlab yeh hai ke: *"Agar request 192.158.1.0/24 IP range ke ilawa kisi aur IP se aayi, toh usko foran block (deny) kar do."*

---

### ❌ 3. Baqi Options Kyun Ghalat Hain?

* **Option 1:** Is mein Region check hi nahi hai aur Resource field khaali (`""`) hai jo ke invalid syntax hai.
* **Option 2:** Is mein `StringNotEquals` region ke sath use kiya gaya hai (jo ulta ho jata hai) aur Deny statement mein action `ec2:` likha hai jo ke syntax error / incomplete hai.
* **Option 4:** Is mein na koi Region restriction hai aur na hi koi IP / Network restriction hai, jab ke sawal mein strict network range maangi gayi thi.
