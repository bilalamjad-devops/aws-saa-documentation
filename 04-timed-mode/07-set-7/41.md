41. Question
An e-commerce company is redesigning the architecture of its application. The new architecture needs a more robust application layer and an online transactional processing (OLTP) relational database that can handle spiky traffic loads. The company also wants to ensure the application is always available while minimizing computing costs during idle periods.

As the company’s solution architect, which solution would be the most cost-effective to meet these requirements?

Use Amazon ECS on AWS Fargate to run the application in containers and opt for Amazon Aurora Serverless to host the database.
Utilize Amazon EC2 instances with a burstable instance type to operate the application and adopt Amazon Redshift as the database.
Utilize AWS Elastic Beanstalk to deploy the application, use a MySQL database on Amazon RDS, then configure Auto Scaling to scale down the number of EC2 instances during idle periods.
Use Amazon EC2 instances in an Auto Scaling group behind an Application Load Balancer. Implement Amazon RDS for MySQL for the database.
