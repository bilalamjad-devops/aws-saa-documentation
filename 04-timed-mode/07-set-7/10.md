10. Question

A company has a running m5ad.large EC2 instance with a default attached 75 GB SSD instance-store backed volume. You shut it down and then start the instance. You noticed that the data which you saved earlier on the attached volume is no longer available.

What might be the cause of this?

- The EC2 instance was using EBS backed root volumes, which are ephemeral and only live for the life of the instance.
- The volume of the instance was not big enough to handle all of the processing data.
- The EC2 instance was using instance store volumes, which are ephemeral and only live for the life of the instance.
- The instance was hit by a virus that wipes out all data.

### 1. Sawal Ki Asal Kahani (The Problem) 🛑

* **Scenario:** Ek company ke paas `m5ad.large` EC2 instance hai jiske sath default **75 GB SSD instance-store volume** attached tha.
* **Problem:** Jab us instance ko **Stop** karke dubara **Start** kiya gaya, toh pata chala ke pehle se saved data gayab ho chuka hai (available nahi hai).
* **Question:** Iski kya wajah ho sakti hai?

---

### 2. Sahi Jawab Ka Breakdown (The Solution) 💡

Sahi option yeh hai:

> **The EC2 instance was using instance store volumes, which are ephemeral and only live for the life of the instance.**

**Yeh kyun sahi hai?**

* **Instance Store Volumes kya hote hain?** Yeh physical disks hoti hain jo seedhi us host hardware ke sath judi hoti hain jis par aap ka EC2 instance chal raha hota hai.
* **Ephemeral Nature:** Instance store ka data **temporary (ephemeral)** hota hai. Jab tak instance *Running* state mein hai, data safe rehta hai. Lekin agar aap instance ko **Stop**, **Hibernate**, ya **Terminate** kar dete hain (aur hardware change ho jata hai), toh instance store ka saara data hamesha ke liye delete ho jata hai.
*(Note: Instance store data sirf tab tak rehta hai jab tak instance restart ho, lekin agar aap Stop karke Start karein aur hardware host badal jaye, ya terminate ho jaye, toh data loss ho jata hai).*

---

### 3. Baqi Options Kyun Ghalat Hain? ❌

* **Option 1 (EBS backed root volumes, which are ephemeral...):**
* *Ghalat kyun?* EBS (Elastic Block Store) volumes **ephemeral nahi hote**. EBS ka data instance ke stop ya terminate hone ke baad bhi safe rehta hai (jab tak aap khud delete na karein). Instance store ephemeral hota hai, EBS nahi.


* **Option 2 (Volume was not big enough...):**
* *Ghalat kyun?* Volume size ka data gayab hone ya delete hone se koi talluq nahi hai.


* **Option 4 (Hit by a virus...):**
* *Ghalat kyun?* Yeh exam ka ek classic "nonsense" distractor option hai.
