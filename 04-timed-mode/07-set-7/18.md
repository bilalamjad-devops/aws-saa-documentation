18. Question

A data center equipped with several physical servers is connected to AWS via a 10 Gbps AWS Direct Connect link. A solutions architect is tasked with rehosting all on-premises applications, data, and operating systems to AWS. Interruptions to business operations must be minimized as well.

Which solution meets the requirement?

- Create a migration plan using AWS DataSync via a scheduled periodic replication every hour
- Create a migration task using AWS Database Migration Service (AWS DMS).
- Create a migration plan using AWS Data Transfer Terminal to transfer the server data to AWS.
- Create a replication task using AWS Transform MGN.

Aaiye, is sawal ko bhi apne usi shandar pattern ke sath step-by-step tor kar samajhte hain!

---

### 1. Sawal Kya Keh Raha Hai? (Question Breakdown) 🛑

* **Scenario:** Ek on-premises data center hai jismein bohot saare **physical servers** hain, aur yeh AWS ke sath **10 Gbps AWS Direct Connect link** (ek bohot tez private network pipe) se connected hain.
* **Goal (Rehosting):** Saari applications, data, aur **operating systems (OS)** ko as-is AWS par migrate karna hai (ise **"Lift-and-Shift"** ya **Rehosting** kehte hain).
* **Requirement:** Business operations mein rukawat (downtime) kam se kam honi chahiye.

---

### 2. Sahi Jawab Kya Keh Raha Hai? (Correct Answer) 💡

> **Create a replication task using AWS Transform MGN (AWS Application Migration Service / AWS MGN).**

#### Deep-Dive Explanation:

1. **Rehosting / Lift-and-Shift:** Jab bhi aap ko poore ke poore servers (operating system aur applications ke sath) ko jaisa ka taisa AWS par utha kar rakhna ho, toh AWS ki official migration service **AWS Application Migration Service (AWS MGN)** use hoti hai.
2. **Minimal Interruption:** AWS MGN background mein continuous block-level replication karta rehta hai taake jab aap final cutover karein, toh business mein koi downtime ya interruption na aaye. Aur yahan 10 Gbps Direct Connect link hone ki wajah se data transfer bhi ultra-fast hoga!

---

### 3. Baqi Options Kyun Ghalat Hain? ❌

* **Option 1 (AWS DataSync):**
* *Ghalat kyun?* DataSync sirf **files aur storage data** (jaise NAS, S3, EFS) ko sync karne ke liye hota hai; yeh poore physical servers, OS, aur applications ko rehost nahi kar sakta.


* **Option 2 (AWS Database Migration Service / DMS):**
* *Ghalat kyun?* DMS sirf **databases** (jaise Oracle se MySQL ya Aurora) migrate karne ke liye hai, poore servers ya OS ke liye nahi.


* **Option 3 (AWS Data Transfer Terminal / Snowball):**
* *Ghalat kyun?* Snowball jaise physical devices tab use hote hain jab internet slow ho ya data bohot bara ho aur network na ho. Jab ke sawal mein pehle se **10 Gbps Direct Connect** maujood hai, toh physical device ki koi zaroorat nahi hai.
