3. Question


A FinTech startup deployed an application on an Amazon EC2 instance with attached Instance Store volumes and an Elastic IP address. The server is only accessed from 8 AM to 6 PM and can be stopped from 6 PM to 8 AM for cost efficiency using AWS Lambda with a script that automates this based on tags.

Which of the following will occur when the EC2 instance is stopped and started? (Select TWO.)

- `All data on the attached instance-store devices will be lost.`
- `The underlying host for the instance is possibly changed.`
- The Elastic IP address is disassociated with the instance.
- The ENI (Elastic Network Interface) is detached.
- There will be no changes.

### Keywords Scan 🔍

1. **"EC2 instance with attached Instance Store volumes... stopped and started"**
* **Trigger:** Ephemeral/temporary storage nature of Instance Store -> **All data on instance-store devices is lost** when an instance stops.


2. **"stopped and started"**
* **Trigger:** Virtual machine lifecycle on physical hardware -> **The underlying physical host for the instance is possibly changed**.



---

### Correct Answers (Select TWO)

* **All data on the attached instance-store devices will be lost.**
* **The underlying host for the instance is possibly changed.**

---

### Question Aur Answer Ka Breakdown 💡

#### Question Kya Keh Raha Hai? ❓

* Ek FinTech startup ne ek EC2 instance chalaya hua hai jiske sath **Instance Store volumes** aur **Elastic IP (EIP)** attached hain.
* Cost saving ke liye, AWS Lambda script shaam 6 baje instance ko **Stop** kar deti hai aur subah 8 baje dobara **Start** karti hai.
* Pucha gaya hai ke jab EC2 instance ko **Stop** karke dobara **Start** kiya jayega, toh kya do (2) cheezein wuqoo-pazeer (occur) hongi?

#### Answer Kya Keh Raha Hai? 💡

1. **Instance Store Data Loss:** Instance Store volumes **ephemeral (temporary)** hotay hain. Jab instance stop hota hai, wo jis physical hypervisor server par chal raha hota hai us se detached ho jata hai, aur uska sara data permanantly delete (erase) ho jata hai.
2. **Underlying Host Change:** Stop/Start karne se AWS instance ko kisi naye physical host server par launch kar sakta hai (AWS underlying physical host machine change kar deta hai).

---

### Baki Options Ghalt Kyun Hain? ❌

* **The Elastic IP address is disassociated:** **False.** Normal Static Public IPs stop karne par release ho jate hain, lekin **Elastic IP (EIP)** persistent hoti hai aur instance ke sath hi associated rehti hai (reboot/stop-start ke baad bhi change nahi hoti).
* **The ENI (Elastic Network Interface) is detached:** **False.** Primary ENI (`eth0`) instance ke stop aur start hone ke dauran hamesha attached rehti hai.
* **There will be no changes:** **False.** Instance Store ka data loss hota hai aur hardware host badal sakta hai.

### SAA-C03 Exam Quick Reference ⚡

| Feature | Elastic Block Store (EBS) | Instance Store |
| --- | --- | --- |
| **Storage Type** | Persistent (Network-attached disk) | Temporary / Ephemeral (Physically attached SSDs) |
| **Data on EC2 Stop/Start** | **Retained** (Data safe rehta hai) | **LOST** (Data hamesha ke liye gayab ho jata hai) |
| **Use Case** | Databases, OS boot volumes | High-speed temporary caches, scratchpads, buffers |

**Short Answer:** **Boht saari cheezon par bilkul farq nahi padta, lekin 2-3 specific cheezein hoti hain jin par farq padta hai.**

Aayein dekhte hain ke host badalne se kya impact hota hai aur kya nahi:

---

### 1. Kya Badalta Hai (Impacted) ⚠️

* **Ephemeral Data (Instance Store Data Loss):**
* Chunke naya host ek alag physical server machine hai, isliye purane host ke physical SSD drive par pada hua data (Instance Store) **puri tarah erase** ho jata hai.


* **Public IP Address (If NOT using Elastic IP):**
* Agar aap ne normal AWS-assigned Public IP use ki hui hai, toh stop/start ke baad naye host par instance ko ek **naya Public IP** milega.
* *(Lekin hamare question mein **Elastic IP** use hui thi, isliye IP change nahi hoga).*


* **Brief Downtime:**
* Stop aur Start hone mein 1–2 minutes ka time lagta hai kyunki AWS naye host machine par aap ka EC2 boot kar raha hota hai.



---

### 2. Kya NAI Badalta (Unchanged & Safe) ✅

* **EBS Volume Data (Safe):**
* Aap ki main Operating System drive (Root EBS Volume) aur extra EBS volumes network-attached storage hote hain. Server change hone ke bawajood EBS volume naye host se auto-attach ho jata hai aur **aap ka saara code, OS, aur files 100% safe rehti hain**.


* **Private IP & Elastic IP (Safe):**
* Aap ka internal **Private IP** aur associated **Elastic IP (EIP)** bilkul same rehte hain.


* **MAC Address & ENI (Safe):**
* Aap ka Elastic Network Interface (ENI) badal ke naye host par move ho jata hai, isliye network configurations change nahi hoti.
