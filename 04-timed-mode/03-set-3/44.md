44. Question


A company runs a multi-tier web application in the AWS Cloud. The application tier is hosted on Amazon EC2 instances and the backend database is hosted on an Amazon Aurora for MySQL DB cluster. For security compliance, all of the application variables such as DB hostnames, environment settings, product keys, and database passwords must be stored securely with encryption.

Which of the following options is the most cost-effective solution to meet the requirements?


- Store the values by creating secrets in AWS Secrets Manager. Use AWS Key Management Service (AWS KMS) for the encryption. Use the BatchGetSecretValue API to retrieve multiple secrets efficiently. Update the application to retrieve the values of the secrets.
- Store the values as key-value pairs in AWS Systems Manager OpsCenter. By default, the key-value pairs will be encrypted at rest. Configure the application to retrieve the variables when it starts.
- `Store the values by creating SecureString type parameters in AWS Systems Manager Parameter Store. Use AWS Key Management Service (AWS KMS) for the encryption. Update the application to retrieve the parameter values.`
- Store the values in a file saved in an Amazon S3 bucket. Enable encryption on the S3 bucket. Configure the application to download the file contents when it starts.

### Keywords Scan 🔍

1. **"application variables such as DB hostnames, environment settings, product keys, and database passwords... stored securely with encryption"**
* **Trigger:** Secure configuration parameters and credentials storage $\rightarrow$ **AWS Systems Manager Parameter Store** or **AWS Secrets Manager**.


2. **"most cost-effective solution"**
* **Trigger:** Parameter Store Standard parameters are **completely free** (no hourly charge), whereas Secrets Manager charges per secret per month. Therefore, Parameter Store is the most cost-effective choice for bulk general configuration variables and keys.



---

### Correct Answer

**Store the values by creating SecureString type parameters in AWS Systems Manager Parameter Store. Use AWS Key Management Service (AWS KMS) for the encryption. Update the application to retrieve the parameter values.**

---

### Question Aur Answer Ka Breakdown 💡

#### Question Kya Keh Raha Hai? ❓

* Ek company multi-tier application AWS par chala rahi hai jisme EC2 aur Aurora MySQL database hain.
* Security compliance ki requirement hai ke **database passwords, hostnames, environment settings, aur product keys ko securely encrypt kar ke store kiya jaye**.
* Sab se **ziada cost-effective (kam kharchay wala)** tareeqa konsa hai?

#### Answer Kya Keh Raha Hai? 💡

1. **AWS Systems Manager Parameter Store (`SecureString`):** Parameter Store ke andar jab aap `SecureString` type parameters banate hain, toh wo automatic **AWS KMS** encryption use karte hain, jo data ko at-rest secure rakhta hai.
2. **Cost-Effectiveness:** Parameter Store ke **Standard parameters bilkul free** hotay hain. Jabke Secrets Manager mein har secret ka monthly cost hota hai ($0.40 per secret/month). Isliye multiple environment settings aur config variables ke liye Parameter Store sab se economical choice banta hai.

---

### Baki Options Ghalt Kyun Hain? ❌

* **AWS Secrets Manager:** Secrets Manager database credentials aur automatic rotation ke liye boht behtareen hai, lekin yahan sari application environment variables aur product keys store karni hain aur question ne **"most cost-effective"** pucha hai, jahan Secrets Manager ki monthly fee zaya hoti hai.
* **AWS Systems Manager OpsCenter:** OpsCenter operational issues, operational work items, aur alarms ke liye hota hai—yeh key-value secure parameter storage service nahi hai.
* **Amazon S3 Bucket file with encryption:** S3 secure storage de sakta hai, lekin yeh runtime configuration variables aur secret management ke liye standard secure cloud architecture pattern nahi hai.

---

### Quick Comparison Table ⚡

| Feature | Systems Manager Parameter Store (`SecureString`) | AWS Secrets Manager |
| --- | --- | --- |
| **Pricing (Standard)** | **Free** (No monthly fee per parameter) | $0.40 per secret / month |
| **Automatic Rotation** | Manual / Custom Lambda | **Built-in automated rotation** (e.g., RDS passwords) |
| **Best For** | General config data, environment variables, API keys | Credentials requiring frequent automated rotation |
