27. Question


A call center wants to use Artificial Intelligence(AI) to extract insights from audio recordings to assess the quality of its customer service. The calls are available in both English and Hindi. A sentiment analysis report in English must be generated for each recording to assess whether or not the customer had a positive experience. Once the solution is completed, new languages will eventually be supported, such as Arabic, Mandarin, and Spanish.

How can the solutions architect build the solution without maintaining any machine learning model?

- `Convert audio recordings into text using Amazon Transcribe. Set up Amazon Translate to translate Hindi texts into English and use Amazon Comprehend for sentiment analysis.`
- Utilize the Amazon Lex service to convert audio recordings into text. Call the Amazon Translate API to translate Hindi texts into English and use Amazon SageMaker Clarify for sentiment prediction and analysis.
- Transcribe audio recordings into text using Amazon Polly’s StartSpeechSynthesisTask operation. Set up Amazon Rekognition to recognize and automatically translate Hindi texts into English. Use the combination of Amazon Fraud Detector and Amazon SageMaker BlazingText algorithm for sentiment analysis.
- Set up Amazon Comprehend to convert audio recordings into text. Use Amazon Kendra to translate Hindi texts into English and utilize the Amazon Detective service to automatically detect negative user behaviors for sentiment analysis.


### Keywords Scan 🔍

1. **"extract insights from audio recordings... calls available in both English and Hindi"**
* **Trigger:** Convert Speech/Audio to Text -> **Amazon Transcribe** (supports multiple languages including English and Hindi).


2. **"translate Hindi texts into English"**
* **Trigger:** Language Translation -> **Amazon Translate**.


3. **"sentiment analysis report... assess whether or not customer had positive experience"**
* **Trigger:** Text Analytics & Sentiment Analysis -> **Amazon Comprehend**.


4. **"without maintaining any machine learning model"**
* **Trigger:** Use Fully Managed / Pre-trained AI Services (No custom ML training/hosting needed).

### Correct Answer

**Convert audio recordings into text using Amazon Transcribe. Set up Amazon Translate to translate Hindi texts into English and use Amazon Comprehend for sentiment analysis.**

---

### Question Aur Answer Ka Breakdown 💡

#### Question Kya Keh Raha Hai? ❓

* Ek call center apne customer service audio recordings se insights aur **sentiment analysis** (pata lagana ke banda khush tha ya naraz) nikalna chahta hai.
* Calls filhal **English aur Hindi** mein hain, aur baad mein Arabic, Mandarin, wagaira bhi add hongi.
* Hindi calls ko pehle **English mein translate** karna hai, aur phir Sentiment Analysis report tayyar karni hai.
* **Condition:** Architect ko koi custom Machine Learning (ML) model khud maintain ya train **Nahi** karna.

#### Answer Kya Keh Raha Hai? 💡

Is pipeline mein teeno 100% Managed AWS AI Services ka chain banaya gaya hai:

$$\text{Audio File} \xrightarrow{\mathbf{\text{Amazon Transcribe}}} \text{Text} \xrightarrow{\mathbf{\text{Amazon Translate}}} \text{English Text} \xrightarrow{\mathbf{\text{Amazon Comprehend}}} \text{Sentiment Report}$$

1. **Amazon Transcribe:** Audio recording sun kar usay automatic **Speech-to-Text** (lahze/words ko text mein convert) kar deta hai.
2. **Amazon Translate:** Transcribe se milne wale Hindi text ko automatic **English** mein translate kar deta hai.
3. **Amazon Comprehend:** English text ko read karke bata deta hai ke customer ka sentiment **Positive, Negative, Neutral, ya Mixed** tha.

* Yeh teeno **API-based ML Services** hain—yani aap ko koi algorithm, model training, ya server manage karne ki zaroorat nahi parti.

---

### Baki Options Ghalt Kyun Hain? ❌

* **Amazon Lex + SageMaker Clarify:**
* **Lex** Chatbots/Voicebots ke liye use hota hai (call recordings transcribing ke liye Transcribe best hai).
* **SageMaker Clarify** custom ML models mein bias/explainability ke liye hota hai, jabke question mein custom ML model maintain karne se mana kiya gaya hai.


* **Amazon Polly + Amazon Rekognition + Fraud Detector:**
* **Polly** *Text-to-Speech* karta hai (awaaz banata hai), audio se text nahi banata!
* **Rekognition** *Images aur Videos* ke analysis ke liye hota hai, translation ke liye nahi.


* **Amazon Comprehend + Amazon Kendra + Amazon Detective:**
* **Comprehend** text/sentiment ke liye hai, audio-to-text convert nahi kar sakta.
* **Kendra** enterprise search engine hai (translation tool nahi).
* **Detective** security log analysis/investigation ke liye hota hai, sentiment analysis ke liye nahi.
