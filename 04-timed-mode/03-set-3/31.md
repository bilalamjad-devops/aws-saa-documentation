31. Question


A media company recently launched their newly created web application. Many users tried to visit the website, but they are receiving a 503 Service Unavailable Error. The system administrator tracked the EC2 instance status and saw the capacity is reaching its maximum limit and unable to process all the requests. To gain insights from the application’s data, they need to launch a real-time analytics service.

Which of the following allows you to read records in batches?

- Create an Amazon S3 bucket to store the captured data and use Amazon Redshift Spectrum to analyze the data.
- `Create a Kinesis Data Stream and use AWS Lambda to read records from the data stream.`
- Create a Data Firehose and use AWS Lambda to read records from the data stream.
- Create an Amazon S3 bucket to store the captured data and use Amazon Athena to analyze the data.

Aayein is question ko step-by-step simple Roman Urdu mein samajhte hain! 💡

---

### 1. Question Kya Keh Raha Hai? (Problem) ❓

* **Masla (Issue):** Ek media company ne website launch ki, par boht saare log aane par website ko **503 Service Unavailable** error aane laga (matlab server par load zaroorat se zyada ho gaya aur wo crash ho raha hai).
* **Zaroorat (Requirement):** Admin ne dekha ke EC2 instances ki capacity full ho gayi hai. Unhe ab ek aisa system lagana hai jo real-time data ko handle kare aur **data ke records ko chhote chhote guchhon (batches) mein parh kar (read karke) process kar sake**.
* **Main Sawaal:** Niche diye gaye options mein se konsa option aap ko **"data ko batches mein read karne"** ki sahulat deta hai?

---

### 2. Answer Kya Keh Raha Hai? (Solution) 💡

> **Create a Kinesis Data Stream and use AWS Lambda to read records from the data stream.**

Is answer ka matlab yeh hai ke:

1. **Kinesis Data Stream:** Live data ko continuous stream ki shakal mein collect karta rehta hai (jaise paani ka pipe).
2. **AWS Lambda (Batch Processing):** Lambda function Kinesis Stream se jud kar data ko ek ek karke uthane ke bajaye **100 ya 500 records ke "Batches" (Group)** ki surat mein ek sath uthata hai aur process karta hai. Is se system par load nahi aata aur process boht tez ho jata hai.

---

### Real-Life Analogy 🏭📦

Socho ek bakery hai jahan tray par **garam biscuits (data records)** continuous aa rahe hain:

* **Kinesis Data Stream:** Wo tray / conveyor belt hai jahan sare biscuits Jama ho rahe hain.
* **AWS Lambda (Batch Reader):** Wo worker hai jo ek ek biscuit uthane ke bajaye **10-10 biscuits ka Dabba (Batch)** ek sath utha kar packing ke liye bhejta hai.

### Duos / Cheat Sheet ⚡

| Requirement | AWS Service Combination |
| --- | --- |
| **Real-time Streaming + Batch Reading** | **Kinesis Data Streams + AWS Lambda** |
| **Stream to S3 / Redshift directly** | **Kinesis Data Firehose** |
| **SQL Queries on S3 Data** | **Amazon Athena** |
