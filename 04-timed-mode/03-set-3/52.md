52. Question

A company is using Amazon VPC that has a CIDR block of 10.31.0.0/27 that is connected to the on-premises data center. There was a requirement to create a Lambda function that will process massive amounts of cryptocurrency transactions every minute and then store the results to EFS. After setting up the serverless architecture and connecting the Lambda function to the VPC, the Solutions Architect noticed an increase in invocation errors with EC2 error types such as EC2ThrottledException at certain times of the day.

Which of the following are the possible causes of this issue? (Select TWO.)

- `Your Lambda function exceeds the VPC quota for Elastic Network Interfaces (ENIs) or available IP addresses in the subnet.`
- The associated security group of your function does not allow outbound connections.
- Your VPC does not have a NAT gateway.
- The attached IAM execution role of your function does not have the necessary permissions to access the resources of your VPC.
- `The Lambda function is placed in a VPC subnet with limited IP address capacity.`

Is question ka jawab aur uski mukammal wajah ye hai:

### Correct Answers (Select TWO) 💡

1. **Your Lambda function exceeds the VPC quota for Elastic Network Interfaces (ENIs) or available IP addresses in the subnet.**
2. **The Lambda function is placed in a VPC subnet with limited IP address capacity.**

---

### Is Question ki Wajah (Reason) Kya Hai? 🔍

1. **CIDR Block Ka Size (10.31.0.0/27):**
* `/27` subnet chota hota hai jis mein total sirf **32 IP addresses** hote hain. Is mein se 5 IPs AWS apne pas reserve rakhta hai, yani aap ke paas use karne ke liye sirf **27 IP addresses** bachte hain.


2. **Lambda in VPC & ENIs:**
* Jab bhi aap kisi Lambda function ko VPC ke andar connect karte hain, toh AWS har concurrent execution/instance ke liye VPC mein ek **Elastic Network Interface (ENI)** allocate karta hai (ya pre-allocate karta hai).


3. **Massive Transactions & IP Exhaustion:**
* Question mein likha hai ke Lambda har minute **massive amounts of cryptocurrency transactions** process kar raha hai (high concurrency). Jab concurrency barhti hai, toh boht sare ENIs create hote hain jinhain IPs ki zaroorat hoti hai.
* Kyun ke subnet ka CIDR block (`/27`) boht chota hai aur available IPs khatam ho jate hain (**limited IP address capacity**), is liye Lambda ko naye ENIs banane mein error aane lagta hai aur **EC2ThrottledException** throw ho jata hai.
