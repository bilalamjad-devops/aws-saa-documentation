43. Question


A company has clients all across the globe that access product files stored in several Amazon S3 buckets, which are behind each of the respective Amazon CloudFront web distributions. The company currently wants to deliver content to a specific client, ensuring that only that client can access the data. At present, all clients can access the S3 buckets directly using an S3 URL or through the CloudFront distribution. The Solutions Architect must serve the private content via CloudFront only, to secure the distribution of files.

Which combination of actions should the Architect implement to meet the above requirements? (Select TWO.)

- Generate an S3 presigned URL to ensure that only the client can access the files. Remove permission to use S3 URLs to read the files for anyone else.
- Enable the Origin Shield feature of the CloudFront distribution to protect the files from unauthorized access.
- `Require the users to access the private content by using special CloudFront signed URLs or signed cookies.`
- `Restrict access to files in the origin by creating an origin access control (OAC) and giving it permission to read the files in the bucket.`
- Create a custom CloudFront function to check and ensure that only their clients can access the files.

### Keywords Scan 🔍

1. **"serve the private content via CloudFront only"**
* **Trigger:** Restrict S3 bucket access so traffic only comes from CloudFront $\rightarrow$ **Origin Access Control (OAC)** or OAI.


2. **"ensuring that only that client can access the data... specific client"**
* **Trigger:** Restrict specific user/client file access via CloudFront $\rightarrow$ **CloudFront Signed URLs or Signed Cookies**.



---

### Correct Answers (Select TWO)

* **Require the users to access the private content by using special CloudFront signed URLs or signed cookies.**
* **Restrict access to files in the origin by creating an origin access control (OAC) and giving it permission to read the files in the bucket.**

---

### Question Aur Answer Ka Breakdown 💡

#### Question Kya Keh Raha Hai? ❓

* Company ke paas S3 buckets hain jo CloudFront distributions ke peeche chal rahe hain.
* Masla yeh hai ke abhi users direct **S3 URL** se bhi file utha sakte hain aur CloudFront se bhi, jabke company chahti hai ke:
1. Direct S3 access **band** ho jaye aur files **sirf CloudFront ke zariye** milein.
2. Sirf authorized/specific clients hi content ko access kar sakein.



#### Answer Kya Keh Raha Hai? 💡

1. **Origin Access Control (OAC):**
* Yeh S3 bucket par policy lagata hai taake public ya direct S3 URL se koi file na khol sake. Sirf aur sirf CloudFront distribution ka OAC hi S3 bucket se data read kar sakega. Is se requirement #1 pori ho jati hai ("serve via CloudFront only").


2. **CloudFront Signed URLs or Signed Cookies:**
* Jab aap ko kisi specific client ya user ko restricted content dena ho (jise har koi na dekh sake), toh hum CloudFront ke **Signed URLs** ya **Signed Cookies** use karte hain. Yeh cryptographic tokens hotay hain jo define karte hain ke koun user kis file ko dekh sakta hai aur kab link expire hoga. Is se requirement #2 pori ho jati hai.



---

### Baki Options Ghalt Kyun Hain? ❌

* **Generate an S3 presigned URL... Remove permission to use S3 URLs:** S3 presigned URLs direct S3 ko hit karte hain, jo CloudFront ko bypass kar deta hai—jabke question ki pehli requirement thi ke content **sirf CloudFront ke zariye** serve ho.
* **Enable the Origin Shield feature:** Origin Shield CloudFront ka caching layer optimization tool hai jo origin server par load kam karta hai; yeh access control ya security restriction ke liye nahi hota.
* **Create a custom CloudFront function:** CloudFront Functions boht lightweight header manipulation / URL rewrites ke liye hotay hain (e.g., viewers ki request ko modify karna). Yeh Signed URLs/Cookies jitni secure authentication ya cryptographic verification handle nahi kar sakte.

### CloudFront Security Cheat Sheet ⚡

| Security Requirement | AWS Feature to Use |
| --- | --- |
| **Block Direct S3 Access** | **Origin Access Control (OAC)** / OAI |
| **Restrict Access to Specific Users / Clients** | **CloudFront Signed URLs** or **Signed Cookies** |
| **Block Traffic by Country / IP / Bad Bots** | **AWS WAF** (Web Application Firewall) |
