64. Question

A media company recently launched their newly created web application. Many users tried to visit the website, but they are receiving a 503 Service Unavailable Error. The system administrator tracked the EC2 instance status and saw the capacity is reaching its maximum limit and unable to process all the requests. To gain insights from the application’s data, they need to launch a real-time analytics service.

Which of the following allows you to read records in batches?

- Create a Data Firehose and use AWS Lambda to read records from the data stream.
- `Create a Kinesis Data Stream and use AWS Lambda to read records from the data stream.`
- Create an Amazon S3 bucket to store the captured data and use Amazon Athena to analyze the data.
- Create an Amazon S3 bucket to store the captured data and use Amazon Redshift Spectrum to analyze the data.

Is question ko bilkul aasan alfaz mein samajhte hain:

---

### Question Kya Keh Raha Hai? ❓

* **Problem:** Website par traffic achanak boht barh gaya hai, servers full ho chuke hain, aur users ko **503 Service Unavailable Error** mil raha hai kyunki EC2 instances saari requests process nahi kar paa rahay.
* **Requirement:** Company ko real-time data parhna hai aur insights leni hain.
* **Core Question:** Sawal ka asal maqsad yeh pochna hai ke **"Batches ki shakal mein (chunks mein) data records ko read karne ke liye konsa option theek hai?"**

---

### Answer Kya Keh Raha Hai? 💡

* **Create a Kinesis Data Stream and use AWS Lambda to read records from the data stream.**
* **Wajah:** **Amazon Kinesis Data Streams** real-time streaming data ko collect aur store karta hai, aur **AWS Lambda** automatic tareeqay se Kinesis se data ko **batches** (chunks) ki surat mein uthata hai aur process karta hai. Yeh real-time analytics aur event-driven architectures ke liye standard aur sab se behtareen tareeqa hai!
