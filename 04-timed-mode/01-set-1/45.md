45. Question

A company collects atmospheric data such as temperature, air pressure, and humidity from different countries. Each site location is equipped with various weather instruments and a high-speed Internet connection. The average collected data in each location is around 500 GB and will be analyzed by a weather forecasting application hosted in Northern Virginia. The Solutions Architect must determine the fastest way to aggregate all the data. An AWS Direct Connect Partner would be too slow for a one-time aggregation.

Which of the following options can satisfy the given requirement?

- `Enable Transfer Acceleration in the destination bucket and upload the collected data using Multipart Upload.`
- Use AWS DataSync to transfer large amounts of data.
- Upload the data to the closest Amazon S3 bucket. Set up a cross-region replication and copy the objects to the destination bucket.
- Set up an AWS Site-to-Site VPN connection.

### Keywords Scan 🔍

1. **"collects data ... from different countries ... destination in Northern Virginia ... fastest way to aggregate"**
* **Trigger:** Long-distance, multi-location global uploads over the public internet $\rightarrow$ **Amazon S3 Transfer Acceleration**.


2. **"average data 500 GB ... high-speed Internet connection"**
* **Trigger:** **S3 Transfer Acceleration + Multipart Upload** (large files $> 100\text{ MB}$ / high throughput transfer speedup via AWS CloudFront Edge Locations).



---

### Correct Answer

**Enable Transfer Acceleration in the destination bucket and upload the collected data using Multipart Upload.**

---

### Roman Urdu Explanation 💡

* **S3 Transfer Acceleration (S3TA):**
* Jab global sites se data Northern Virginia (us-east-1) mein central S3 bucket par bhejna ho, toh public internet par routing network latency aur packet loss produce karti hai.
* **S3TA** Amazon CloudFront ke globally distributed **Edge Locations** use karta hai. Data pehle sab se qareebi AWS Edge Location par optimized path se pohnchta hai, aur wahan se AWS ki private high-speed backbone network ke zariye central bucket mein fast-track transfer hota hai.


* **Multipart Upload:**
* 500 GB jaisi badi files ko chunks/parts mein parallel upload karke transfer speed maximize aur retry handling resilient banati hai.



---

### Elimination Rules ❌

* **AWS DataSync:** Public internet connections par high long-distance latency ko optimize nahi karta; Direct Connect ya dedicated bandwidth par zada efficient hota hai.
* **Closest S3 Bucket + CRR:** Har country mein pehle S3 bucket banana, usme upload karna, aur phir Cross-Region Replication (CRR) setup karna architectural management overhead barha deta hai aur S3TA se slow hota hai.
* **AWS Site-to-Site VPN:** Encryption overhead aur public internet IPsec routing bounds ki waja se 500 GB bulk file transfers ke liye bohot slow rehta hai.
