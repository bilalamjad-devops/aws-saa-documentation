20. Question

A company has 3 DevOps engineers that are handling its software development and infrastructure management processes. One of the engineers accidentally deleted a file hosted in Amazon S3 which has caused disruption of service.

What can the DevOps engineers do to prevent this from happening again?

- Create an IAM bucket policy that disables delete operation.
- Set up a signed URL for all users.
- `Enable S3 Versioning and Multi-Factor Authentication Delete on the bucket.`
- Use S3 Infrequently Accessed storage to store the data.

### Keywords Scan 🔍

1. **"accidentally deleted a file in Amazon S3"**
* **Trigger:** Accidental deletion se recovery ke liye **S3 Versioning** zaroori hai (delete hone par **Delete Marker** banta hai, actual data lose nahi hota).


2. **"prevent this from happening again"**
* **Trigger:** Permanent deletion ko restrict karne ke liye **MFA Delete** chaiye hota hai.



---

### Correct Answer

**Enable S3 Versioning and Multi-Factor Authentication Delete on the bucket.**

---

### Quick Explanation 💡

* **S3 Versioning:** Files ko accidentally overwrite ya delete hone par restore karne ka feature deta hai.
* **MFA Delete:** Dedicated authentication code ke bina kisi bhi file version ko permanently delete karne se rokta hai.
