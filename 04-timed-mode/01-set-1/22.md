22. Question

A pharmaceutical company has resources hosted on both its on-premises network and in the AWS cloud. The company requires all Software Architects to access resources in both environments using on-premises credentials, which are stored in Active Directory, rather than through an Amazon Cognito identity pool.

In this scenario, which of the following can be used to fulfill this requirement?

- Use IAM users
- Use Amazon VPC
- `Set up SAML 2.0-Based Federation by using a Microsoft Active Directory Federation Service.`
- Set up SAML 2.0-Based Federation by using a Web Identity Federation.

### Keywords Scan 🔍

1. **"on-premises credentials, which are stored in Active Directory"**
* **Trigger:** **SAML 2.0-Based Federation via Microsoft ADFS** (Active Directory Federation Service).


2. **"rather than through Amazon Cognito / Web Identity"**
* **Trigger:** Enterprise corporate login ke liye **ADFS** use hota hai, public **Web Identity Federation** (Google, Facebook) nahi.



---

### Correct Answer

**Set up SAML 2.0-Based Federation by using a Microsoft Active Directory Federation Service.**

---

### Roman Urdu Explanation 💡

* **ADFS + SAML 2.0:** Single Sign-On (SSO) enable karta hai. Users apne purane Active Directory password se AWS login kar lete hain. AWS ko alag se account credentials dene ki zaroorat nahi parti.

---

### Elimination Rules ❌

* **IAM users:** Separate AWS credentials banane parain ge (Active Directory credentials ki requirement fail ho jaye gi).
* **Amazon VPC:** Networking service hai, authentication handle nahi karti.
* **Web Identity Federation:** Public apps / social logins (Google, Facebook) ke liye hoti hai, corporate Active Directory ke liye nahi.
