23. Question

A company is designing a banking portal that uses Amazon ElastiCache for Redis as its distributed session management component. To secure session data and ensure that Cloud Engineers must authenticate before executing Redis commands, specifically MULTI EXEC commands, the system should enforce strong authentication by requiring users to enter a password. Additionally, access should be managed with long-lived credentials while supporting robust security practices.

Which of the following actions should be taken to meet the above requirement?

- Generate an IAM authentication token using AWS credentials and provide this token as a password.
- Enable the in-transit encryption for Redis replication groups.
- Set up a Redis replication group and enable the AtRestEncryptionEnabled parameter.
- `Authenticate the users using Redis AUTH by creating a new Redis Cluster with both the --transit-encryption-enabled and --auth-token parameters enabled.`

### Keywords Scan 🔍

1. **"ElastiCache for Redis ... require users to enter a password ... MULTI EXEC commands"**
* **Trigger:** **Redis AUTH** (Redis token-based password authentication mechanism).


2. **"authenticating users ... password ... long-lived credentials"**
* **Trigger:** `--auth-token` parameter enable karna (jiske liye **Transit Encryption / TLS** mandatorily required hota hai).



---

### Correct Answer

**Authenticate the users using Redis AUTH by creating a new Redis Cluster with both the `--transit-encryption-enabled` and `--auth-token` parameters enabled.**

---

### Roman Urdu Explanation 💡

* **Redis AUTH:** ElastiCache for Redis mein password protection dene ke liye **Redis AUTH** use hota hai.
* **Requirement Rule:** ElastiCache mein `--auth-token` (password) tabhi enable ho sakta hai jab **Transit Encryption (`--transit-encryption-enabled`)** active ho, taaki password network par plain-text mein expose na ho.
* **IAM Tokens:** Redis mein IAM authentication short-lived dynamic tokens use karti hai, jabki sawal mein **long-lived credentials / password** ki shart rakhi gayi hai.

---

### Elimination Rules ❌

* **IAM authentication token:** Short-lived tokens ke zariye hoti hai, persistent password / long-lived credentials requirement ko violate karti hai.
* **In-transit encryption (Alone):** Traffic encrypt karega, par Redis commands ke liye user password prompt/AUTH enforce nahi karega.
* **AtRestEncryptionEnabled:** Disk par raw data encrypt karta hai, user authentication handle nahi karta.
