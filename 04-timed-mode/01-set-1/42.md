42. Question

A financial application consists of an Auto Scaling group of Amazon EC2 instances, an Application Load Balancer, and a MySQL RDS instance set up in a Multi-AZ Deployment configuration. To protect customers’ confidential data, it must be ensured that the Amazon RDS database is only accessible using an authentication token specific to the profile credentials of EC2 instances.

Which of the following actions should be taken to meet this requirement?

- Use a combination of IAM and STS to enforce restricted access to your RDS instance using a temporary authentication token.
- `Enable the IAM DB Authentication.`
- Configure SSL in your application to encrypt the database connection to RDS.
- Create an IAM Role and assign it to your EC2 instances which will grant exclusive access to your RDS instance.

### Keywords Scan 🔍

1. **"Amazon RDS database ... accessible using an authentication token"**
* **Trigger:** **IAM DB Authentication** (RDS login ke liye passwords ke bajaye short-lived temporary authentication tokens / IAM credentials use hote hain).


2. **"specific to the profile credentials of EC2 instances"**
* **Trigger:** EC2 Instance Profile / IAM Role ke zariye token generate karke RDS Database access karna.



---

### Correct Answer

**Enable the IAM DB Authentication.**

---

### Roman Urdu Explanation 💡

* **IAM Database Authentication:**
* Amazon RDS (MySQL/PostgreSQL) mein jab aap **IAM DB Authentication** enable karte hain, toh database users password ki jagah **AWS IAM temporary authentication token** ke zariye login karte hain.
* EC2 instance apna IAM Role use karke AWS STS se yeh short-lived token (jo 15 minutes tak valid hota hai) maangti hai aur DB connection establish karti hai. Is se DB passwords code ya config files mein hardcode karne ki zaroorat bilkul khatam ho jati hai.



---

### Elimination Rules ❌

* **Use IAM and STS directly:** IAM DB Auth feature enable karne se STS tokens ka background flow natively handoff ho jata hai; manual STS custom integration ki zaroorat nahi parti.
* **Configure SSL:** SSL connection transit encryption (in-transit security) ke liye hota hai, authentication token-based login provide nahi karta.
* **Assign IAM Role to EC2 without IAM DB Auth:** Purely EC2 par IAM role attach kar lene se tab tak RDS connect nahi ho sakta jab tak RDS end par *IAM DB Authentication* feature turn ON na kiya jaye.
