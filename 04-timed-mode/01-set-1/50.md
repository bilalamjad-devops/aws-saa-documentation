50. Question

A global IT company with offices around the world has multiple AWS accounts. To improve efficiency and drive costs down, the Chief Information Officer (CIO) wants to set up a solution that centrally manages their AWS resources. This will allow them to procure AWS resources centrally and share resources such as AWS Transit Gateways, AWS License Manager configurations, or Amazon Route 53 Resolver rules across their various accounts.

As the Solutions Architect, which combination of options should you implement in this scenario? (Select TWO.)

- Use the AWS Identity and Access Management service to set up cross-account access that will easily and securely share your resources with your AWS accounts.
- Use AWS Control Tower to easily and securely share your resources with your AWS accounts.
- Consolidate all of the company's accounts using AWS ParallelCluster.
- Consolidate all of the company's accounts using AWS Organizations.
- Use the AWS Resource Access Manager (RAM) service to easily and securely share your resources with your AWS accounts.

### Keywords Scan 🔍

1. **"centrally manages their AWS resources ... procurement and billing"**
* **Trigger:** **AWS Organizations** (multiple AWS accounts ko ek central place par manage aur consolidate karne ke liye).


2. **"share resources such as AWS Transit Gateways, Route 53 Resolver rules across their various accounts"**
* **Trigger:** **AWS Resource Access Manager (RAM)** (AWS accounts ke darmayan AWS resources easily aur securely share karne ke liye).



---

### Correct Answers (Select TWO)

* **Consolidate all of the company's accounts using AWS Organizations.**
* **Use the AWS Resource Access Manager (RAM) service to easily and securely share your resources with your AWS accounts.**

---

### Roman Urdu Explanation 💡

* **AWS Organizations:**
* Multiple AWS accounts ko ek sath combine/consolidate karne ke liye AWS Organizations standard service hai. Is se consolidated billing aur central management governance milta hai.


* **AWS Resource Access Manager (AWS RAM):**
* AWS RAM aapko permission deta hai ke aap ek AWS account mein bane hue resources (jaise **Transit Gateways**, **Route 53 Resolver Rules**, **Subnets**, **License Manager Configurations**) ko AWS Organizations ke baaqi accounts ke sath share kar sakein. Is se duplicate resources create nahi karne padte aur cost bachti hai.



---

### Elimination Rules ❌

* **Cross-account IAM roles:** IAM cross-account access roles users/services ko permissions dene ke liye hota hai, Transit Gateway ya Route 53 Resolver rules jaisey core infrastructure resources share karne ke liye nahi.
* **AWS Control Tower:** Multi-account setup ki landing zone automation aur governance ke liye hota hai, direct individual resources (like Transit Gateway/Resolver rules) share nahi karta.
* **AWS ParallelCluster:** High-Performance Computing (HPC) clusters deploy aur manage karne ka tool hai, account consolidation se iska koi taalluq nahi.
