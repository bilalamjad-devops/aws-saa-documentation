48. Question

A travel photo-sharing website is using Amazon S3 to serve high-quality photos to visitors. After a few days, it was discovered that other travel websites are linking to and using these photos. This has resulted in financial losses for the business. The team initially applied PutBucketPolicy with referrer restrictions, but found that referrer headers can be spoofed, rendering this approach insufficient.

What is the MOST effective method to mitigate this issue?

- `Configure your S3 bucket to remove public read access and use pre-signed URLs with expiry dates.`
- Use Amazon CloudFront distributions for your photos.
- Move the high-quality photos to Amazon WorkDocs to serve them privately.
- Block the IP addresses of the offending websites using NACL.


### Keywords Scan 🔍

1. **"prevent hotlinking / unauthorized direct access to S3 photos"**
* **Trigger:** Public read access ko remove karke temporary access mechanism implement karna.


2. **"referrer headers can be spoofed, rendering bucket policy insufficient"**
* **Trigger:** **Pre-signed URLs with expiry dates** (Har user request ke liye cryptographically signed, short-lived URL generate hoti hai jisko koi doosri site hotlink nahi kar sakti).



---

### Correct Answer

**Configure your S3 bucket to remove public read access and use pre-signed URLs with expiry dates.**

---

### Roman Urdu Explanation 💡

* **Pre-signed URLs:**
* Jab aap S3 bucket se **public read access remove** kar dete hain, toh koi bhi external site bucket URL ko direct hotlink nahi kar sakti.
* Application backend valid, authenticated users ke liye temporary **Pre-signed URLs** (e.g., 5-15 minutes expiry) generate karta hai. External unauthorized websites in URLs ki access timing pass hone ke baad hotlink nahi kar paatein, aur Referrer header spoofing ka rasta bhi completely band ho jata hai.



---

### Elimination Rules ❌

* **Use CloudFront distributions:** Direct CloudFront use karne se jab tak **Signed URLs / Signed Cookies** ya **Origin Access Control (OAC)** enforce na kiya jaye, tab tak CloudFront URL ko bhi direct hotlink kiya ja sakta hai.
* **Amazon WorkDocs:** Enterprise document sharing and collaboration tool hai; web-scale public image hosting/serving ke liye design nahi hua.
* **Block IP addresses using NACL:** HTTP Referrer hotlinking doosri websites ke visitors ki browsers se hoti hai (million of random user IPs), isliye limited static IPs ko NACL mein block karna impossible hai.
