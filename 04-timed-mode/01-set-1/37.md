37. Question

A company requires all the data stored in the cloud to be encrypted at rest. To easily integrate this with other AWS services, they must have full control over the encryption of the created keys and also the ability to immediately remove the key material from AWS KMS. The solution should also be able to audit the key usage independently of AWS CloudTrail.

Which of the following options will meet this requirement?

- `Use AWS Key Management Service to create a KMS key in a custom key store and store the non-extractable key material in AWS CloudHSM.`
- Use AWS Key Management Service to create AWS owned Keys and store the non-extractable key material in AWS CloudHSM.
- Use AWS Key Management Service to create a KMS key in a custom key store and store the non-extractable key material in Amazon S3.
- Use AWS Key Management Service to create AWS managed keys and store the non-extractable key material in AWS CloudHSM.

### Keywords Scan 🔍

1. **"ability to immediately remove the key material from AWS KMS"**
* **Trigger:** **KMS Custom Key Store backed by AWS CloudHSM** (jis mein HSM se key delete/disconnect karke instantly revocation possible hoti hai).


2. **"audit the key usage independently of AWS CloudTrail"**
* **Trigger:** **AWS CloudHSM** (is ke apne dedicated, independent audit logs hotay hain jo CloudTrail se completely alag aur tamper-proof hotay hain).



---

### Correct Answer

**Use AWS Key Management Service to create a KMS key in a custom key store and store the non-extractable key material in AWS CloudHSM.**

---

### Roman Urdu Explanation 💡

* **Custom Key Store + CloudHSM:** Jab aap KMS ko CloudHSM cluster se connect karke **Custom Key Store** banate hain, toh key material AWS-managed storage ke bajaye aapke dedicated CloudHSM hardware mein rehta hai.
* **Instant Key Material Removal:** Aap KMS ko HSM se disconnect kar sakte hain ya CloudHSM se keys zeroize/delete kar sakte hain for immediate revocation.
* **Independent Auditing:** CloudHSM ki apni direct audit logging hoti hai jo AWS CloudTrail se completely separated aur independent hoti hai.



---

### Elimination Rules ❌

* **AWS owned Keys / AWS managed Keys in CloudHSM:** AWS owned aur AWS managed keys AWS-controlled storage accounts mein hoti hain; Custom Key Store CloudHSM integration ke sath use nahi ho sakti (un par full control nahi milta).
* **Custom key store in Amazon S3:** Custom Key Store S3 mein store nahi hota, sirf single-tenant hardware security module (CloudHSM) ya external key manager mein integrate hota hai.
