60. Question

An application that records weather data every minute is deployed in a fleet of Amazon EC2 Spot instances and uses a MySQL RDS database instance. Currently, there is only one Amazon RDS instance running in one Availability Zone. The database needs to be improved to ensure high availability by enabling synchronous data replication to another RDS instance.

Which of the following performs synchronous data replication in RDS?

- `RDS DB instance running as a Multi-AZ deployment`
- RDS Read Replica
- Amazon CloudFront running as a Multi-AZ deployment
- Amazon DynamoDB Read Replica

### Keywords Scan 🔍

1. **"ensure high availability ... synchronous data replication to another RDS instance"**
* **Trigger:** **RDS Multi-AZ Deployment** (Primary DB se Secondary/Standby DB instance par real-time, **synchronous** block-level storage replication).



---

### Correct Answer

**RDS DB instance running as a Multi-AZ deployment**

---

### Roman Urdu Explanation 💡

* **Multi-AZ Deployment (Synchronous):**
* Jab aap RDS Multi-AZ enable karte hain, toh AWS doosre Availability Zone mein ek Standby replica banata hai.
* Har write operation pehle Primary DB par hota hai aur **synchronously** Standby DB par write hota hai. Jab tak dono par write confirm na ho jaye, transaction complete nahi hoti. Is se failover ke waqt Zero Data Loss hota hai.


* **Read Replicas (Asynchronous):**
* AWS RDS mein **Read Replicas** read-scaling/performance ke liye hote hain aur inki replication **Asynchronous** hoti hai (thoda replication lag ho sakta hai).



---

### Elimination Rules ❌

* **RDS Read Replica:** Read Replicas **asynchronous** replication use karte hain, synchronous nahi. High availability/disaster recovery ke liye main mechanism Multi-AZ hota hai.
* **Amazon CloudFront running as a Multi-AZ deployment:** CloudFront global Content Delivery Network (CDN) hai jo static/dynamic web content edge locations par cache karta hai, database replication nahi karta.
* **Amazon DynamoDB Read Replica:** Amazon DynamoDB NoSQL database hai, question mein MySQL Amazon RDS relational database ki baat ho rahi hai.
