16. Question

A company has a cloud architecture composed of Linux and Windows Amazon EC2 instances that process high volumes of financial data 24 hours a day, 7 days a week. To ensure high availability of the systems, the Solutions Architect must create a solution that enables monitoring of memory and disk utilization metrics for all instances.

Which of the following is the most suitable monitoring solution to implement?

- `Install the Amazon CloudWatch agent to all the EC2 instances that gather the memory and disk utilization data. View the custom metrics in the CloudWatch console.`
- Use the default Amazon CloudWatch configuration to EC2 instances where the memory and disk utilization metrics are already available. Install the AWS Systems Manager (SSM) Agent on all the EC2 instances and enable AWS Systems Manager Inventory to track instance configuration and metadata.
- Enable the Enhanced Monitoring option in EC2 and install Amazon CloudWatch agent to all the EC2 instances to be able to view the memory and disk utilization in the CloudWatch dashboard.
- Use Amazon Inspector and install the Inspector agent to all EC2 instances.

### Keywords Scan 🔍

1. **"memory and disk utilization metrics for all instances"**
* **Trigger:** EC2 basic/detailed monitoring standard metrics mein **CPU, Network, Disk I/O, aur Status Checks** shaamil hotay hain, lekin **Memory (RAM) aur Disk Space Utilization (OS-level metrics) default par nahi aate**.


2. **"most suitable monitoring solution"**
* **Trigger:** OS-level metrics (RAM & Disk space) collect karne ke liye OS ke andar **CloudWatch Agent** install karna parta hai, jo in metrics ko CloudWatch mein as **Custom Metrics** publish karta hai.



---

### Correct Answer

**Install the Amazon CloudWatch agent to all the EC2 instances that gather the memory and disk utilization data. View the custom metrics in the CloudWatch console.**

---

### Roman Urdu Explanation 💡

* **Default EC2 Metrics:** AWS Hypervisor level se EC2 ko monitor karta hai. Is liye AWS ko bahar se CPU usage, Network traffic, aur Disk Read/Write Operations (I/O) toh dikhte hain, lekin OS ke andar ki RAM (Memory) aur File System Storage (Disk Space utilization) dikhai nahi deti.
* **CloudWatch Agent Solution:** Jab aap EC2 instance ke andar **CloudWatch Agent** install karte hain, toh woh Operating System ke andar se Memory aur Disk Space ka usage read karke CloudWatch ko **Custom Metrics** ke tor par bhejta hai.

---

### Elimination Rules ❌

* **Default Amazon CloudWatch configuration:** Default CloudWatch metrics mein Memory aur Disk Space utilization hoti hi nahi hai.
* **Enhanced Monitoring:** Enhanced Monitoring **Amazon RDS** ke liye hoti hai, EC2 instances ke liye nahi.
* **Amazon Inspector:** Yeh Security Vulnerabilities aur Compliance assessment ke liye hota hai, Performance/Metric Monitoring ke liye nahi.
