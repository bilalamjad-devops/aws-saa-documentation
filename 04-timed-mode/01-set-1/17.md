17. Question

A company hosted an e-commerce website on an Auto Scaling group of Amazon EC2 instances behind an Application Load Balancer. The Solutions Architect noticed that the website is receiving a high number of illegitimate external requests from multiple systems with frequently changing IP addresses. To address the performance issues, the Solutions Architect must implement a solution that would block these requests while having minimal impact on legitimate traffic.

Which of the following options fulfills this requirement?

- Create a private connection using AWS PrivateLink to block the offending requests.
- Create a regular rule in AWS WAF and associate the web ACL to an Application Load Balancer.
- Create a custom network ACL and associate it with the subnet of the Application Load Balancer to block the offending requests.
- `Create a rate-based rule in AWS WAF and associate the web ACL to an Application Load Balancer.`


### Keywords Scan 🔍

1. **"frequently changing IP addresses"**
* **Trigger:** IP addresses lagataar badal rahe hain, is liye static IP blocking (NACLs ya simple IP match rules) yahan kaam nahi kare gi.


2. **"high number of illegitimate external requests ... minimal impact on legitimate traffic"**
* **Trigger:** Traffic volume/rate zyaada hai (DDoS ya scraping attack style). **Rate-based rule** IP-level request frequency track karta hai aur threshold cross hone par un specific IPs को temporarily block karta hai, jabki normal users (jo low rate par request kar rahe hain) un-impacted rehte hain.


3. **"behind an Application Load Balancer"**
* **Trigger:** ALB ke saath **AWS WAF** attach kiya jata hai.



---

### Correct Answer

**Create a rate-based rule in AWS WAF and associate the web ACL to an Application Load Balancer.**

---

### Roman Urdu Explanation 💡

* **Problem:** Attackers constantly apni IP address badal rahe hain aur bohot saari requests bhej rahe hain. Agar aap static IP block list banayenge, toh kabhi khatam nahi hogi.
* **Solution:** **AWS WAF ka Rate-based Rule** automatically monitor karta hai ki har 5-minute window mein ek IP address se kitni requests aa rahi hain. Jab kisi IP se request threshold (jaise 100 requests per 5 min) cross hoti hai, WAF us IP ko automatically block kar deta hai. Normal users (jo speed limit ke andar rehte hain) bina kisi masle ke site access kar sakte hain.

---

### Elimination Rules ❌

* **AWS PrivateLink:** PrivateLink AWS services ya third-party SaaS ko private VPC IPs ke zariye connect karne ke liye hota hai, internet attacks block karne ke liye nahi.
* **Regular rule in AWS WAF:** Regular rule static parameters (jaise exact IP ranges ya headers) dekhta hai. Dynamic IPs se aane wale high-volume traffic ko count karke rate-limit nahi kar sakta.
* **Custom Network ACL (NACL):** Subnet-level Network ACLs static IP rules handle karte hain. Changing IP addresses ke case mein hazaron dynamic IPs ko manual NACL mein maintain karna impossible hai, aur NACL ki rule limit bhi quickly hit ho jaye gi.
