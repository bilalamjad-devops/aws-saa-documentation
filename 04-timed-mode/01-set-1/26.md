26. Question

A suite of web applications is hosted in an Auto Scaling group of Amazon EC2 instances across three Availability Zones and is configured with default settings. There is an Application Load Balancer that forwards the request to the respective target group on the URL path. The scale-in policy has been triggered due to the low number of incoming traffic to the application.

Which EC2 instance will be the first one to be terminated by the Auto Scaling group?

- The EC2 instance which has the least number of user sessions
- The EC2 instance which has been running for the longest time
- The instance will be randomly selected by the Auto Scaling group
- `The EC2 instance launched from the oldest launch template.`

### Keywords Scan 🔍

1. **"configured with default settings"**
* **Trigger:** AWS Auto Scaling ki **Default Termination Policy** ka sequence apply hoga.


2. **"scale-in policy has been triggered ... which instance terminated first"**
* **Trigger:** Default flow: **AZ balance check $\rightarrow$ Oldest Launch Template/Configuration $\rightarrow$ Oldest Instance $\rightarrow$ Closest to next billing hour**.



---

### Correct Answer

**The EC2 instance launched from the oldest launch template.**

---

### Roman Urdu Explanation 💡

AWS Auto Scaling Default Termination Policy in steps ko order mein follow karti hai:

1. **AZ Selection:** Sab se pehle check karti hai ke kis Availability Zone (AZ) mein sab se zyada instances hain, taaki balance maintain ho.
2. **Oldest Template / Configuration:** Agar multi-AZ status equal ho, toh woh instance terminate hota hai jo **oldest launch template / launch configuration** se bana tha.
3. **Oldest Unprotected Instance:** Agar configurations bhi same hon, toh woh instance select hota hai jo **sab se purana (oldest instance)** ho.

---

### Elimination Rules ❌

* **Least number of user sessions:** Auto Scaling instance ke andar active application user sessions ko track nahi karti.
* **Running for the longest time:** Oldest launch configuration ke BAAD check hota hai, pehle nahi.
* **Randomly selected:** Random deletion nahi hoti, exact structured evaluation logic follow hota hai.
