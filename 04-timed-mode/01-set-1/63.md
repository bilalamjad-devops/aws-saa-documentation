63. Question

A company is experiencing repeated outages in the Availability Zone where its Amazon RDS database instance is deployed, resulting in a complete loss of access to the database during each incident. The team evaluated a multi-site active/active deployment but found that it requires cross-Region synchronization, whereas a simpler embedded solution would suffice.

Which solution should be implemented to prevent losing database access if this occurs again?

- `Enable Multi-AZ failover`
- Create a read replica
- Create a snapshot of the database
- Increase the database instance size

### Keywords Scan 🔍

1. **"repeated outages in the Availability Zone where RDS database is deployed"**
* **Trigger:** Single AZ failure risk (High Availability / Fault Tolerance issue).


2. **"prevent losing database access if an Availability Zone fails ... simpler embedded solution"**
* **Trigger:** **Multi-AZ failover** (Automatic failover to a Standby replica in a different Availability Zone during an AZ outage).



---

### Correct Answer

**Enable Multi-AZ failover**

---

### Roman Urdu Explanation 💡

* **RDS Multi-AZ Failover:**
* Jab aap Multi-AZ enable karte hain, toh AWS doosre Availability Zone (AZ) mein ek synchronous **Standby Replica** maintain karta hai.
* Agar main AZ mein outage aaye ya database host fail ho jaye, toh RDS **automatically CNAME DNS switch** kar ke traffic ko seconds mein Standby DB par point kar deta hai.
* Application ko bina kisi code change ke continuous database access milta rehta hai.



---

### Elimination Rules ❌

* **Create a read replica:** Read Replicas primarily read performance/scaling ke liye hote hain. Agar primary DB wala AZ fail ho jaye, toh automatic failover nahi hota—manual promotion karna padta hai jo downtime cause karta hai.
* **Create a snapshot of the database:** DB Snapshots static backups hote hain. Outage ke waqt snapshot se naya DB restore karne mein kaafi time lagta hai aur manual intervention chahiye hoti hai.
* **Increase the database instance size:** DB Instance size barhane (Vertical Scaling) se CPU/RAM toh mil jati hai, lekin agar pura Availability Zone hi down ho jaye toh size barhane se outage resolve nahi hota.
