34. Question

A company plans to host a web application in an Auto Scaling group of Amazon EC2 instances. The application will be used globally by users to upload and store several types of files. Based on user trends, files that are older than 2 years must be stored in a different storage class. The Solutions Architect of the company needs to create a cost-effective and scalable solution to store the old files yet still provide durability and high availability.

Which of the following approach can be used to fulfill this requirement? (Select TWO.)

- `Use Amazon S3 and create a lifecycle policy that will move the objects to S3 Glacier after 2 years.`
- Use Amazon EFS and create a lifecycle policy that will move the objects to EFS-IA after 2 years.
- Use a RAID 0 storage configuration that stripes multiple Amazon EBS volumes together to store the files. Configure the Amazon Data Lifecycle Manager (DLM) to schedule snapshots of the volumes after 2 years.
- `Use Amazon S3 and create a lifecycle policy that will move the objects to S3 Standard-IA after 2 years.`
- Use Amazon EBS volumes to store the files. Configure the Amazon Data Lifecycle Manager (DLM) to schedule snapshots of the volumes after 2 years.

### Keywords Scan 🔍

1. **"files that are older than 2 years must be stored in a different storage class ... cost-effective ... durability and high availability"**
* **Trigger:** **Amazon S3 Lifecycle Policy** (S3 Standard se low-cost archival/infrequent storage classes mein transitions).


2. **"upload and store several types of files ... 2 years"**
* **Trigger:** S3 lifecycle rules for transitioning to **S3 Standard-IA** or **S3 Glacier**.



---

### Correct Answers (Select TWO)

* **Use Amazon S3 and create a lifecycle policy that will move the objects to S3 Glacier after 2 years.**
* **Use Amazon S3 and create a lifecycle policy that will move the objects to S3 Standard-IA after 2 years.**

---

### Roman Urdu Explanation 💡

* **S3 Lifecycle Transitions:**
* **S3 Standard-IA (Infrequent Access):** Low-cost storage class jo immediate retrieval capabilities ke sath 99.999999999% (11 9s) durability aur high availability deti hai.
* **S3 Glacier Flexible/Deep Archive:** Ultra low-cost archival storage class jo rare access walay data ke liye best cost optimization aur high durability deti hai.



Dono S3 Lifecycle rules user ki requirement ("cost-effective storage class transition after 2 years while retaining durability and availability") ko properly satisfy karti hain.

---

### Elimination Rules ❌

* **Amazon EFS + EFS-IA:** EFS file storage hai jo object-based user file upload storage ke liye S3 jitni cost-effective aur scalable nahi hai.
* **RAID 0 EBS + DLM Snapshots:** RAID 0 mein ek bhi volume fail ho toh poora data lose ho jata hai (durability fail hoti hai). Snapshots EBS data storage classes ko transition nahi karte.
* **EBS Volumes + DLM Snapshots:** EBS block storage per-GB cost mein S3 se bohot mehngi hai aur global file upload platforms ke liye non-scalable hai.
