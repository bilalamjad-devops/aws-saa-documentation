58. Question


A company has a web application that uses Internet Information Services (IIS) for Windows Server. A file share is used to store the application data on the network-attached storage of the company’s on-premises data center. To achieve a highly available system, the company plans to migrate the application and file share to AWS. The team considered using Logical Volume Management (LVM) stripe on Amazon EC2, but this approach would not provide a managed, highly available SMB file service.

Which of the following can be used to fulfill this requirement?

- Migrate the existing file share configuration to Amazon EFS.
- Migrate the existing file share configuration to AWS Storage Gateway.
- `Migrate the existing file share configuration to Amazon FSx for Windows File Server.`
- Migrate the existing file share configuration to Amazon EBS.

### Keywords Scan 🔍

1. **"IIS for Windows Server ... network-attached storage / file share"**
* **Trigger:** Windows native file sharing protocol (**SMB / CIFS**).


2. **"managed, highly available SMB file service"**
* **Trigger:** **Amazon FSx for Windows File Server** (Fully managed native Microsoft Windows SMB file system).



---

### Correct Answer

**Migrate the existing file share configuration to Amazon FSx for Windows File Server.**

---

### Roman Urdu Explanation 💡

* **Amazon FSx for Windows File Server:**
* Windows IIS web applications ke data shares ke liye native **SMB (Server Message Block)** protocol support chahiye hota hai.
* Amazon FSx for Windows File Server fully managed, Multi-AZ highly available file system provide karta hai jo Windows SMB features (jaise Active Directory integration, ACLs, aur Shadow Copies) ko natively support karta hai.



---

### Elimination Rules ❌

* **Amazon EFS:** Amazon Elastic File System **NFS (Network File System)** protocol use karta hai, jo primarily Linux instances ke liye hota hai. Windows IIS ke native SMB shares ke liye suitable nahi hai.
* **AWS Storage Gateway:** Hybrid cloud storage integration service hai jo on-premises data ko AWS storage se connect karti hai. Complete cloud-native migration ke liye FSx direct choice hai.
* **Amazon EBS:** EBS block-level storage hai jo ek waqt mein single EC2 instance se attach hota hai (jab tak Multi-Attach enable na ho on specific nitro instances with cluster file systems). Yeh multiple IIS servers ke liye shared network file storage as a service provide nahi karta.
